## ما نُفّذ (TDD: RED → GREEN، محرك نقي بلا I/O)
1. **`ews_engine.js`** (37 اختبار وحدة، fail-closed):
   - `computeMEWS` — مقياس Subbe الكامل (SBP/HR/RR/حرارة/AVPU، 0–14) بنطاقات Low/Medium/High/Critical.
   - `computePEWS` — نمط Monaghan بثلاثة محاور (سلوك/دوران/تنفس 0–3) مع **معدلات حيوية معيارية حسب شرائح العمر (APLS)**؛ أي محور=3 يرفع `component_alert` ويفرض High على الأقل.
   - `computeQSOFA` — RR≥22 / SBP≤100 / تغيّم وعي (GCS<15 أو AVPU≠A)؛ ≥2 = خطر مرتفع.
   - `computeSIRS` — بمنطق أمان دقيق: البيانات الجزئية التي **بلغت** معيارين = إيجابي مُحدَّد (يُعلَّم ناقصًا)؛ الجزئي غير الإيجابي بعد = **Incomplete** — لا "سلبي زائف" أبدًا من علامات غير مقاسة.
   - `sepsisScreen` — دمج استشاري: اشتباه عدوى + (qSOFA≥2 أو SIRS≥2) → `SEPSIS_ALERT`؛ اضطراب بلا اشتباه → `DETERIORATION_ALERT`. **تنبيه إجرائي وليس تشخيصًا** (مصرّح به في النص).
   - `escalationFor` — تصعيد حتمي (ROUTINE → INCREASE_MONITORING → URGENT_REVIEW → RRT)، الأشد يفوز، sepsis يرفع لأعلى، غياب المدخلات = UNKNOWN لا "روتيني" صامت.
2. **نقطة نهاية stateless `POST /api/ews/assess`**: مصادقة + دور (تمريض/طبيب) + نطاق مستأجر + فحص IDOR للمريض + تدقيق (`EWS_ASSESS`)؛ تحسب من الملاحظات الخام وترفض أي مجموع من العميل؛ **بلا تخزين** حتى اعتماد DDL.
3. **Migration مرشّحة e48 (لم تُنفَّذ)**: توسيع `CHECK(score_type)` في `nursing_scores` بأنواع mews/pews/qsofa/sirs/sepsis_screen (up/down/validate) — جاهزة لبوابة DDL المعتمدة.
4. **إصلاح عرضي بنفس علّة Gate 1**: `nursing_assessments.gcs_score || 15` (افتراض مُطمئِن) → تحليل صارم (غائب=NULL، خردة=422).
