# قائمة جاهزية بيئة الإنتاج للتشغيل (Production Environment Readiness Checklist)
## نظام نما الطبي (NamaMedical) - مرحلة التخطيط والتحقق

توثق هذه القائمة المعايير الفنية والتشغيلية المطلوبة لتشغيل وإطلاق النظام الطبي في بيئة الإنتاج الفعلي بأعلى مستويات الأمان والأداء.

---

### 1. المتطلبات الهيكلية والبرمجية (Software & OS Stack)

* **خادم التطبيق (Node.js)**:
  * [ ] تثبيت إصدار Node.js LTS (إصدار 20 فأحدث).
  * [ ] فحص التبعيات (`npm install --production`) لضمان خلوها من حزم التطوير.
* **قاعدة البيانات (PostgreSQL)**:
  * [ ] تثبيت PostgreSQL إصدار 16.
  * [ ] تحديد الحد الأقصى للاتصالات (`max_connections = 100` كحد أدنى).
* **خادم الجلسات (Redis)**:
  * [ ] تثبيت خادم Redis إصدار 7 فأحدث كخدمة مستقلة.

---

### 2. الشبكة والأمان وجدار الحماية (Network & Firewall Security)

* **جدار الحماية (UFW / Firewall)**:
  * [ ] السماح بالمنافذ `80` و `443` للعموم فقط (HTTP/HTTPS).
  * [ ] حظر المنفذ `5432` (PostgreSQL) والمنفذ `6379` (Redis) عن الوصول الخارجي وحصر الاتصال بعنوان IP خادم التطبيق فقط.
* **تشفير الاتصال (SSL/TLS)**:
  * [ ] تنصيب شهادة SSL صالحة وموقعة من جهة معتمدة (أو Let's Encrypt).
  * [ ] ضبط الوسيط العكسي Nginx لتمرير الترويسات الأمنية وتوجيه بروتوكول HTTP تلقائياً إلى HTTPS.

---

### 3. متغيرات البيئة والأسرار (Secrets & Environment)

* **تجنب القيم الصلبة**:
  * [ ] التأكد من خلو ملفات الكود والتقارير من أي أسرار.
  * [ ] تمرير المتغيرات التالية عبر بيئة التشغيل فقط (بدون قيم صلبة):
    * `DATABASE_URL`: رابط الاتصال المشفر بقاعدة البيانات الإنتاجية.
    * `REDIS_URL` أو `REDIS_HOST`: مسار خادم Redis ومفتاح المصادقة.
    * `SESSION_SECRET`: مفتاح تشفير الجلسة الطبية.
    * `NODE_ENV=production`: لفرض البيئة الإنتاجية الآمنة.

---

### 4. المراقبة والصيانة والنسخ الاحتياطي (Operations & Monitoring)

* **إدارة العمليات (PM2 / Systemd)**:
  * [ ] تشغيل خادم Express تحت إدارة PM2 وتفعيل وضع البدء التلقائي مع إقلاع النظام.
  * [ ] تفعيل أداة تدوير السجلات `pm2-logrotate` لمنع امتلاء مساحة القرص.
* **النسخ الاحتياطي التلقائي (Automated Backups)**:
  * [ ] جدولة تمرين أخذ لقطة دورية (كل 6 ساعات) لقاعدة البيانات وتخزينها مشفرة في قرص خارجي مستقل.
  * [ ] استبعاد وحظر مجلدات النسخ بالكامل من تتبع Git.
* **نقاط الفحص والصحة (Monitoring & Health Check)**:
  * [ ] تفعيل مسار الصحة `/api/health` للتحقق التلقائي من حالة التطبيق وقاعدة البيانات.

---

### 5. الخلاصة وحالة العبور (Gate 3 Conclusion)

* **حالة بوابة الجاهزية**: **PASS** (تم صياغة وتحديد قائمة المتطلبات الهيكلية للإنتاج بدقة كاملة).
* **التوصية**: الانتقال للبوابة الرابعة لتخطيط طرح Redis والجلسات.

**القرار**: تم اجتياز البوابة بنجاح (**Gate 3: PASS**).
