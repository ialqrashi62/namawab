# Support

## For end users (clinicians, nurses, admins)
- In-app help icon → embedded chat bot (or contact your facility super-user).
- Patient questions: Patient Relations — patient-rights@nama.local
- Hospital 937 (KSA MoH) for clinical emergencies.

## For institutional admins
- Email: support@nama.local
- Sev1 outages: pager via your account manager.

## For developers / integrators
- API docs: `docs/openapi/`
- SDK examples: `docs/sdk/`
- Postman collection: `docs/postman/`
- GitHub Issues for bug reports and feature requests.
- Slack #nama-developers (invite via account manager).

## Operating hours
- Sev1: 24/7
- Sev2: 24/7
- Sev3: business hours (Sun–Thu 08:00–17:00 KSA)
- Sev4: best effort

## Languages
- Arabic, English. Other languages via institutional translator (G33).

## Escalation
- Account manager → CSM lead → COO (after 24h unresolved Sev2+).

## Status
- Status page: status.nama.local
- Public incidents: status.nama.local/incidents
