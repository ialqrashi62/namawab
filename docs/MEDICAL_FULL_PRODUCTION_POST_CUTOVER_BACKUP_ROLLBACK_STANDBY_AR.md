# تقرير الجاهزية للنسخ الاحتياطي وخطة التراجع (Backup and Rollback Standby Report)
## نظام نما الطبي (NamaMedical) - مرحلة مراقبة ما بعد العبور للإنتاج

يوثق هذا التقرير التحقق التشغيلي من توفر النسخ الاحتياطية خارج مستودع الأكواد، وجاهزية أوامر خطة التراجع السريع (Rollback) لحماية التطبيق وقاعدة البيانات في بيئة الإنتاج.

---

## 1. نتائج التحقق من النسخ الاحتياطي (Backup Status)

* **موقع النسخ الاحتياطي**: تم حفظ كافة النسخ الاحتياطية لقاعدة البيانات SQL وملفات التطبيق الحيوية في أدلة محلية آمنة ومعزولة خارج مستودع Git البرمجي (في المجلدات المحلية ومسار خادم الإنتاج المحمي).
* **التدقيق الهيكلي لمستندات Git**: تم تشغيل الفحص التفصيلي `git ls-files docs/sql/*backup*` وأكد خلو المستودع تماماً من أي ملفات نسخ احتياطي متتبعة أو مسربة في السجلات العامة.
* **الحالة**: **`PASS`**

---

## 2. خطة التراجع والجاهزية البرمجية (Rollback Readiness)

* **الالتزام المستقر الأخير (Previous Stable Commit)**: الالتزام الأب المعتمد هو `9e8c5a15dd6237795d00eb089ad5f10bb1cc4c65` والالتزام الفرعي لـ `namaweb` هو `7495fd53f4f24117741a9dd91de5b5ec19f4f248`.
* **الحاجة الفعلية للتراجع (Rollback Required)**: **`NO` (لا حاجة للتراجع)**
  * **السبب**: لم يتم إجراء أي تعديل برمجي أو كتابة أكواد إنتاجية جديدة أو إحداث ترحيلات لقواعد البيانات خلال هذه الجولة من المراقبة، وبالتالي يظل الكود الحالي متطابقاً تشغيلياً مع نسخة الإطلاق المستقرة دون تراجع.
* **الحالة**: **`PASS`**

---

## 3. أوامر التراجع والتعافي الجاهزة (Rollback Commands Reference)

في حال حدوث أي طارئ تشغيلي أو الحاجة لتصحيح البيئة وتطهيرها، تم توثيق وجاهزية الأوامر التالية للتنفيذ الفوري:

### 3.1 استعادة كود التطبيق المستقر (App Rollback)
```bash
# الانتقال لمجلد التطبيق والعودة للالتزام المستقر الأخير
cd /var/www/namaweb
git checkout 7495fd53f4f24117741a9dd91de5b5ec19f4f248
npm install
pm2 restart nama-medical-erp
```

### 3.2 استعادة قاعدة البيانات (Database Restore)
```bash
# إيقاف خادم التطبيق مؤقتاً
pm2 stop nama-medical-erp

# استعادة آخر نسخة احتياطية آمنة لقاعدة البيانات PostgreSQL
sudo -u postgres psql -d nama_medical_web -f /var/backups/nama_medical_db_pre_cutover.sql

# إعادة تشغيل التطبيق والتحقق من الاستجابة
pm2 start nama-medical-erp
```
