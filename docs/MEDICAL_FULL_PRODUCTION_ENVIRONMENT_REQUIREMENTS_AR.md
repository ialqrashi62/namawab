# متطلبات بيئة الإنتاج الكامل للعملاء (Full Production Environment Requirements Report)
## نظام نما الطبي (NamaMedical) - مرحلة التخطيط للترقية والعبور للإنتاج

يوثق هذا التقرير المتطلبات والضوابط الفنية اللازمة لتهيئة وتأمين بيئة الإنتاج الكامل الحقيقية لنظام نما الطبي قبل البدء الفعلي بأي عمليات ترقية أو عبور.

---

### 1. معايير البنية التحتية والشبكة (Network & Infrastructure Standards)

1. **النطاق الرسمي (Production Domain)**:
   - تخصيص نطاق رسمي معتمد لنظام نما الطبي (مثال: `medical.nama.com.sa`).
2. **بروتوكول التشفير الآمن (SSL/HTTPS)**:
   - إجبارية تفعيل HTTPS بنسخة TLS 1.3 أو TLS 1.2 كحد أدنى.
   - شهادة SSL معتمدة من جهة إصدار موثوقة (Let's Encrypt أو شهادة تجارية).
   - تفعيل رأس الأمان Strict-Transport-Security (HSTS) قسرياً.
3. **خادم الويب والوسيط العكسي (Reverse Proxy)**:
   - استخدام خادم Nginx كوسيط عكسي آمن لتوجيه الطلبات من منافذ الويب (80, 443) إلى منفذ التطبيق الداخلي (3000).
   - تكوين Nginx لتصفية الترويسات وحظر هجمات حجب الخدمة ومطابقة الأمان.
4. **جدار الحماية (Firewall / Security Groups)**:
   - السماح فقط بالمنافذ `80` (HTTP للتوجيه) و `443` (HTTPS الآمن) و `22` (SSH للإدارة بنطاق محدد) خارجياً.
   - إغلاق المنفذ `3000` (Node.js) والمنفذ `5432` (PostgreSQL) والمنفذ `6379` (Redis) بالكامل عن العالم الخارجي والوصول إليها عبر الشبكة الداخلية فقط.

---

### 2. خدمات قاعدة البيانات والجلسات في الإنتاج (Production DB & Redis Services)

1. **قاعدة بيانات PostgreSQL الإنتاجية**:
   - تثبيت قاعدة البيانات على خادم مستقل معزول عن خادم الويب لضمان كفاءة معالجة البيانات وعزل المخاطر.
   - تهيئة البارامترات الفنية للاتصال وعزل بركة الاتصالات (Connection Pool) بحد أقصى آمن.
   - فرض قسرية الـ `FORCE RLS` لجميع الجداول الـ 13 الحساسة (35 جدولاً إجمالياً بـ pg_policies).
2. **خادم Redis للجلسات الموزعة**:
   - خادم Redis إنتاجي مستقل يدعم الحفظ الدائم للبيانات (Persistence) وحظر تراجع الذاكرة الموضعّية MemoryStore تماماً.
   - تفعيل التحقق من الهوية (Authentication) وتشفير الاتصال بـ TLS بين خادم الويب وخادم Redis.

---

### 3. الإدارة والأمان والمراقبة (Security & Operations Governance)

1. **إدارة النسخ الاحتياطي (Backup Management)**:
   - إنشاء دليل نسخ احتياطي معزول تماماً وخارج مسار Git (مثل: `/var/backups/db/nama_medical_prod/`).
   - جدولة أخذ النسخ الاحتياطي التلقائي (Cron Jobs) يومياً مع تشفير الملفات ونقلها لخوادم تخزين سحابية معزولة وآمنة.
2. **إدارة الأسرار والمتغيرات البيئية (Secrets Management)**:
   - حظر تخزين أي كلمات مرور أو مفاتيح تشفير داخل السورس كود أو ملفات التوثيق.
   - حفظ ملف التكوين البيئي `.env` بصلاحيات قراءة محدودة للغاية (صلاحيات 600 لمستخدم التشغيل فقط).
   - استخدام أدوات إدارة أسرار معزولة (مثل Vault أو المتغيرات البيئية المباشرة للنظام).
3. **إدارة السجلات وسجل الأخطاء (Log Rotation)**:
   - تهيئة ميزة `logrotate` لتنظيف وتدوير السجلات البرمجية لـ PM2 و Nginx يومياً لمنع امتلاء مساحة القرص.
4. **نظام المراقبة والإنذار المبكر (Monitoring & Alerting)**:
   - تفعيل أدوات رصد الأداء (Prometheus + Grafana + Node Exporter) لمراقبة استهلاك الموارد (CPU / Memory / Disk).
   - جدولة رسائل إنذار مبكر تلقائية (Slack / Telegram / Email) عند تجاوز الموارد لـ 80% أو فشل اتصال Redis/DB.
5. **حوكمة الوصول الإداري (Admin Access)**:
   - تحديد وصول SSH عبر مفاتيح مشفرة معتمدة فقط وإلغاء تسجيل الدخول بكلمات المرور لـ root.
   - تمكين سجل التدقيق لعمليات sudo وتسجيل الإجراءات الإدارية.
