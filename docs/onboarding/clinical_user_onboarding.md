# Clinical User Onboarding (Doctor / Nurse / Therapist)
v1.0 — 90 minutes total over 1 week

## Day 0 (before first shift)
- [ ] Account provisioned (HR feed → IdP → NamaMedical via SCIM)
- [ ] Roles + privileges loaded per credentialing
- [ ] SCFHS license verified
- [ ] AUP + Privacy Policy acknowledged (e-signed)
- [ ] Mandatory training: BLS/ACLS valid, IPSG, infection control modules

## Hour 1 — Orientation (15 min)
- Watch: NamaMedical overview (5 min)
- Watch: Privacy + AI advisory + audit (5 min)
- Watch: Patient Bill of Rights (5 min)

## Hour 2 — Core navigation (20 min)
- Sandbox login + tour
- Patient search → patient header → vitals
- Place a routine order (lab + imaging)
- View results
- Sign a SOAP note using smart phrases

## Hour 3 — Department-specific (30 min)
Pick one based on role:
- **ED nurse**: triage form, AI CTAS, code activation buttons
- **ED MD**: bundle application, code STEMI/Stroke/Sepsis flows
- **Cardio fellow**: ECG reader, echo report, cath schedule
- **ICU**: vent settings, FAST-HUG-BID, sedation pad
- **Inpatient nurse**: care plans, observations, med admin barcode
- **Pharmacist**: order verification, compounding log, TDM
- **Lab tech**: result entry, critical value call-back
- **Surgeon**: pre-op checklist, time-out, op note

## Hour 4 — AI co-pilot (15 min)
- Ask the dept assistant a clinical question
- See confidence + citations
- Override and add reason
- Verify it appears in audit log

## Hour 5 — Practice case (10 min)
- Sandbox case end-to-end
- Quiz (5 questions): pass = 80%

## End of week — Sign-off
- Super-user observes 2 real shifts; signs competency form
- Access to advanced features (e.g., break-glass) granted

## Ongoing
- Monthly tip-of-the-month email
- Quarterly user satisfaction survey
- Annual refresher (mandatory)
