# قائمة الفحص والمراقبة الدورية للإنتاج (Production Monitoring Checklist)
## نظام نما الطبي (NamaMedical) - وثيقة التسليم النهائي

توثق هذه القائمة جداول وإجراءات المتابعة والتدقيق الدوري لبيئة الإنتاج للتأكد من استقرار وأمان النظام بصورة مستمرة.

---

## 1. الفحص والمراقبة اليومية (Daily Tasks)

| البند المراد فحصه | الإجراء الفني المطلوب | الحالة المتوقعة | تحقق (Done) |
| :--- | :--- | :--- | :---: |
| **استقرار خادم التطبيق** | `pm2 status` | حالة العملية `online` وتعداد الانهيار ثابت. | [ ] |
| **صحة الاستجابة الخارجية** | `curl -s https://jumanasoft.com/api/health` | استلام رمز `200 OK` وجسم استجابة يحتوي `{"status":"UP"}`. | [ ] |
| **استقرار خادم Redis** | `redis-cli ping` | استلام الاستجابة `PONG` وعمل كوكيز الجلسة. | [ ] |
| **سجلات الأخطاء للعملية** | `pm2 logs nama-medical-erp --lines 50 --nostream` | خلو السجلات من أي استثناءات غير معالجة أو أخطاء RLS. | [ ] |
| **ترويسات أمن HTTPS** | فحص استلام الكوكيز عبر المتصفح | الكوكيز تحتوي وسوم الحماية `HttpOnly; Secure`. | [ ] |
