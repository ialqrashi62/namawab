# تدقيق منطق العمل (Business Logic Audit)

> التاريخ: 2026-06-20 | مرجع: [MEDICAL_BUSINESS_LOGIC_AUDIT_AR.md](MEDICAL_BUSINESS_LOGIC_AUDIT_AR.md). هذا تحديث (المحاسبة أصبحت مُوصَّلة OFF).

## القواعد الحرجة وحالتها
| القاعدة | الحالة الراهنة |
| ------- | -------------- |
| الوصفة لا تنقص المخزون قبل الصرف | ✅ (الصرف ينقص) — FEFO بالدفعة تحسين مطلوب |
| الصرف ينقص المخزون | ✅ |
| نتيجة المختبر لا تصبح نهائية بلا اعتماد | ⚠️ جزئي (اعتماد مزدوج verify/approve ناقص) |
| تقرير الأشعة لا يصبح نهائياً بلا اعتماد الطبيب | ⚠️ جزئي |
| فاتورة المريض تُرحَّل محاسبياً عبر posting مضبوط | **جديد**: محرك ترحيل مُوصَّل (`accounting_posting_service.js`) خلف flag OFF؛ fail-closed (الحدث + القيد في معاملة واحدة، app.tenant_id داخلها، ROLLBACK كامل عند الفشل) — **لكنه OFF؛ CoA+mapping مطبَّقان فعلاً (30/23، NUMERIC) → لا ترحيل فعلي بعد (journal=0)** |
| فاتورة المورّد تؤثّر AP + مخزون/مصروف | ⚠️ منطق ناقص (المشتريات جزئية) |
| رفض التأمين لا يحذف الإيراد بصمت | ✅ (سجلات؛ لا EDI) |
| نوع المنشأة يمنع API لا الواجهة فقط | ✅ **جديد**: حارس backend fail-closed |
| السجلات المنشورة لا تُعدّل بصمت | ⚠️ منطق منع تعديل is_posted غير مفعّل (المحاسبة OFF) |
| السجلات الطبية لها audit trail | ✅ audit_trail (old_values ناقص أحياناً) |

## تقييم العمليات (موجز)
| العملية | الحالة | فجوة |
| ------- | ------ | ---- |
| تسجيل/منع تكرار المريض | Functional | merge/MRN موحّد ناقص |
| المواعيد/الطابور/الزيارة | Functional | — |
| الوصفة/الصرف/المخزون | Functional | FEFO، تنبيهات إعادة الطلب متقدمة |
| المختبر/الأشعة (طلب→نتيجة→اعتماد) | Partial | اعتماد مزدوج |
| الفوترة/الاسترداد/إشعار دائن | Functional | idempotency |
| **الترحيل المحاسبي** | **Wired-OFF** | تفعيل يحتاج CoA seed + DDL idempotency + موافقة |
| المشتريات (PO/GRN/3-way) | Partial | GRNI/3-way match |
| دورة حياة المستأجر SaaS | Partial | provisioning/خطط |

## القرار
`BUSINESS_LOGIC_STATUS: WARNING (محسّن)`. التحسّن الأبرز: محرك ترحيل fail-closed مُوصَّل (OFF) + إنفاذ نوع المنشأة. المتبقي: تفعيل المحاسبة المحكوم، اعتماد المختبر/الأشعة المزدوج، FEFO، 3-way match، immutability للسجلات المنشورة.

`BUSINESS_LOGIC_AUDIT_COMPLETE`
