# سيناريوهات النظام الكاملة (Full System Scenarios)

> التاريخ: 2026-06-20 | لكل سيناريو: الدور، الخطوات، المتوقع (UI/API/DB)، أثر العزل/الاستحقاق/المحاسبة، الحالات السلبية.

## 1. Onboarding / SaaS
| سيناريو | المتوقع | حالة سلبية |
| ------- | ------- | ---------- |
| إنشاء مستأجر + نوع منشأة | يُضبط facility_type؛ الحارس يفعّل الاستحقاقات | نوع غير معروف → 422؛ غير مضبوط على مسار حساس → 403 |
| منشأة pharmacy_only تصل EMR | **403 Facility type not entitled** | تجاوز الرابط المباشر → 403 (قرار على req.path) |

## 2. المريض والاستقبال
- تسجيل مريض → بحث → فتح ملف. متوقع: ختم tenant_id من الجلسة؛ IDOR يُمنع (مريض مستأجر آخر → 403/404). سلبي: بلا جلسة → 401.
- حجز موعد → check-in → فتح زيارة. تعارض/تكرار → فحص؛ no-show عبر التحديث.

## 3. سريري (EMR)
- استدعاء مريض من الطابور → تشخيص → طلب مختبر/أشعة → وصفة → إغلاق زيارة. متوقع: كل استعلام مفلتر tenant + RLS؛ الطبيب يرى مرضى مستأجره فقط.

## 4. الصيدلية/المخزون
- استقبال وصفة → صرف → خصم مخزون. قاعدة: الوصفة **لا** تنقص المخزون قبل الصرف؛ الصرف ينقص حسب الدفعة (FEFO — تحسين مطلوب).

## 5. المختبر/الأشعة
- طلب → عينة → نتيجة → اعتماد. قاعدة: النتيجة لا تصبح نهائية بلا اعتماد (تحسين: فصل verify/approve مزدوج).

## 6. الفوترة/التأمين/المحاسبة
- إنشاء فاتورة → دفع جزئي → استرداد → ZATCA QR.
- **المحاسبة (مُوصَّلة، OFF)**: عند `ACCOUNTING_POSTING_ENABLED=true` فقط: فاتورة → قيد Dr ذمم/Cr إيراد/Cr ضريبة داخل معاملة fail-closed تربط `app.tenant_id`؛ أي فشل → ROLLBACK كامل (لا فاتورة جزئية ولا قيد يتيم). **حالياً OFF؛ CoA+mapping مطبَّقان فعلاً (30/23، NUMERIC) لكن لا قيود مرحَّلة بعد (journal=0)** — [محدَّث 2026-06-21].
- سلبي: ترحيل مكرّر يُمنع عبر مرجع المستند (idempotency).

## 7. التنويم/الطوارئ/الجراحة/ICU
- إدخال → جولة → نقل سرير → إفراغ (معاملة تربط app.tenant_id). طوارئ: فرز triage. جراحة: preop/anesthesia.

## 8. الأمن وعزل المستأجرين
| سيناريو | المتوقع |
| ------- | ------- |
| مستخدم بلا جلسة على مسار محمي | 401 |
| مستأجر A يطلب بيانات مستأجر B | لا نتائج (RLS) + تحقق ملكية → 403/404 |
| الإنتاج بلا SESSION_SECRET صالح | التطبيق يرفض الإقلاع (crash آمن) |
| الإنتاج بلا Redis | يرفض الإقلاع (لا تراجع MemoryStore) |
