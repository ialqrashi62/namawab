# PHASE 8 — فهرس أدلة التدريب / الإدارة / المستخدم

> 2026-06-22 | فهرس وتسلسل إعداد (لا أدلة ضخمة كاملة الآن).

## الأدلة المقترحة (حسب الدور)
| الدليل | الجمهور | المحتوى الأساسي |
|---|---|---|
| admin guide | Admin/IT | إدارة المستخدمين (Admin فقط)، الأدوار، الإعدادات، النسخ الاحتياطي |
| doctor/clinical | Doctor/Nurse | المرضى، المواعيد، EMR، الطلبات (مختبر/أشعة)، الوصفات |
| nursing | Nurse | التقييمات، العلامات الحيوية، ICU، eMAR |
| billing | Finance/Reception | الفواتير، الإيصالات، الاسترداد، التأمين، daily_close |
| HR | HR/Admin | الموظفين (إضافة/حذف = HR/Admin)، الرواتب، الإجازات |
| reports | Finance/Admin | التقارير المالية/العمولات (tenant-scoped) |
| operations | IT/Ops | P4 runbook (health/PM2/Redis/watchdog) |
| security | Admin/Security | P5 handover (RLS/RBAC/audit/least-privilege) |

## تسلسل الإعداد (onboarding)
1. Admin ينشئ المنشأة/النوع → 2. ينشئ المستخدمين بالأدوار → 3. يضبط الأقسام/الفروع → 4. الكتالوجات (خدمات/أدوية مرجعية) → 5. تدريب كل دور على دليله.

## ملاحظة
