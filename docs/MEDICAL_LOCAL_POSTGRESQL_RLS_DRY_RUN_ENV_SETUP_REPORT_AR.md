# تقرير حالة تهيئة بيئة PostgreSQL المحلية للتشغيل التجريبي (Local PostgreSQL Env Setup Blocker Report)
## Phase: Install Local PostgreSQL & CLI Tools for RLS Dry-Run

---

## 1. الملخص التنفيذي وحالة الحظر (BLOCKER ALERT)
تم فحص خيارات تهيئة بيئة قاعدة البيانات المحلية على جهاز التطوير للتمكن من تشغيل اختبارات أمان مستوى الصف (RLS) ومحاكاة عزل المستأجرين محلياً. بعد التحقق من بيئة نظام التشغيل، تبين أن **محرك Docker غير متوفر**، كما أن **خادم PostgreSQL وأدوات خط الأوامر (`psql`, `pg_dump`) غير مثبتة** على الجهاز الحالي. 

وبناءً عليه، يتم تثبيت **حالة الحظر (Blocker)** وطلب تدخل المستخدم/المالك لتثبيت خادم PostgreSQL محلي أو تفعيل البيئة محلياً للتمكن من فك حظر المراحل التالية.

---

## 2. نتائج فحوصات البيئة والخيارات المتاحة

### أ. فحص حاويات Docker
* **الأمر:** `docker --version` و `docker ps`
* **النتيجة:** `docker: The term 'docker' is not recognized...`
* **الاستنتاج:** محرك Docker غير مثبت أو غير متاح في مسار النظام (PATH).

### ب. فحص خادم PostgreSQL المحلي
* **الأمر:** `Get-Service -Name *postgres*`
* **النتيجة:** لم يتم العثور على أي خدمة مسجلة تحتوي على الاسم "postgres".
* **فحص المنفذ 5432:** تم فحص الاتصالات المحلية على المنفذ `5432` وثبت عدم وجود أي عملية تستمع عليه.

### ج. فحص أدوات خط الأوامر (CLI Tools)
* **الأمر:** `where.exe psql` و `where.exe pg_dump`
* **النتيجة:** `Could not find files for the given pattern(s)`
* **الاستنتاج:** أدوات العميل المساعدة غير متوفرة محلياً، مما يمنع تشغيل عمليات أخذ النسخ الاحتياطية وإجراء الاختبارات التلقائية المكتوبة في `rls_local_dry_run_3_tables.js`.

---

## 3. متطلبات فك الحظر (Action Plan for Unblocking)
لفك حظر هذه المرحلة واستكمال الأوتو بايلوت، يرجى القيام بأحد الإجراءات التالية على جهاز المطور:

1. **تثبيت PostgreSQL Installer (الخيار الموصى به):**
   * تحميل وتثبيت خادم **PostgreSQL 15 أو 16** لنظام ويندوز من خلال الموقع الرسمي: [EDB PostgreSQL Downloads](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads).
   * التأكد من تفعيل تثبيت أدوات العميل (Command Line Tools) وإضافة مسار الـ `bin` (مثلاً: `C:\Program Files\PostgreSQL\16\bin`) إلى متغّيرات بيئة النظام (PATH).
   * إعداد كلمة مرور حساب `postgres` الافتراضي كـ `postgres` لتتوافق مع ملف التهيئة `.env`.

2. **تثبيت وتفعيل Docker Desktop:**
   * في حال رغبتكم بالتشغيل عبر الحاويات، يرجى تثبيت [Docker Desktop](https://www.docker.com/products/docker-desktop/) والتأكد من تشغيله. وسيقوم النظام تلقائياً بإنشاء وتشغيل الحاوية `nama_medical_pg_local`.
