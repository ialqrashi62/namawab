# قالب قرار مواصلة التشغيل أو التوقف لبيئة الاختبار (Staging Go/No-Go Decision Template)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** خطة علاج فجوات بيئة الاختبار للمالك وفريق العمليات (PHASE_STAPS_OWNER_REMEDIATION_PLAN)
* **الهدف:** توفير نموذج تقييم وإقرار رسمي لتحديد إمكانية النشر والتشغيل لبيئة الاختبار بناءً على المعطيات الفنية وعزل الحماية.

---

## 1. نموذج خيارات القرار الفني (Decision Options)

يجب على لجنة النشر والجودة اختيار قرار واحد فقط من القرارات الثلاثة التالية بناءً على مطابقة شروط التشغيل:

### الخيار الأول: الجاهزية لنشر المحاكاة المحلية فقط (GO - LOCAL_MOCK_API_DEPLOYMENT)
* **الوصف:** يُسمح فقط بنشر كود الواجهة الأمامية للمحاكاة (الذي يعمل بالكامل في المتصفح ودون أي تواصل مع قاعدة البيانات).
* **الشروط المطلوبة:**
  * [ ] خادم Staging مستقل وجدار الحماية مفعل.
  * [ ] النطاق الفرعي `staging.alfaisal-erp.com` مهيأ مع شهادة TLS.
  * [ ] عملية PM2 مخصصة وتعمل بنجاح.
  * [ ] *قاعدة بيانات الاختبار والـ env لم يتم إعدادهما بالكامل بعد*.
* **النتيجة:** يسمح بالنشر المقيد للمحاكاة المحلية في المتصفح فقط.

### الخيار الثاني: الجاهزية لنشر النموذج الأولي للقراءة فقط (GO - READONLY_API_PROTOTYPE)
* **الوصف:** يُسمح بنشر النموذج الأولي للواجهات المدعومة ببيانات وهمية من قاعدة بيانات الاختبار المعزولة.
* **الشروط المطلوبة:**
  * [ ] استيفاء كافة شروط الخيار الأول.
  * [ ] قاعدة البيانات `nama_medical_staging` منشأة وجاهزة بالكامل.
  * [ ] تفعيل مستخدم قاعدة البيانات المقيد `nama_staging_user`.
  * [ ] إعداد ملف `.env.staging` بالكامل بأسرار تشفير فريدة وغير مكررة.
  * [ ] اجتياز كافة اختبارات حواجز الأمان للقراءة فقط بنسبة 100% محلياً.
* **النتيجة:** يسمح بالنشر الكامل للنموذج الأولي للواجهات بالقراءة فقط.

### الخيار الثالث: الاستمرار في الحجب - المعالجة غير مكتملة (NO-GO - STAGING_BLOCKED)
* **الوصف:** يُمنع تماماً إجراء أي عملية نشر أو رفع كود على خادم الاختبار.
* **الشروط المؤدية لهذا القرار:**
  * [ ] عدم حل أي فجوة من الفجوات الحرجة (مثل عدم وجود استضافة مستقلة أو استخدام قاعدة بيانات الإنتاج).
  * [ ] فشل أي اختبار من اختبارات الجودة أو الأمان المخصصة للمرحلة.
* **النتيجة:** يستمر حظر النشر التام وتتم إعادة الملف للمالك لاستكمال المعالجة.
