# قائمة التحقق لتجهيز بيئة الاختبار للمالك (Staging Environment Owner Checklist)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** خطة علاج فجوات بيئة الاختبار للمالك وفريق العمليات (PHASE_STAGING_GAPS_OWNER_REMEDIATION_PLAN)
* **الهدف:** توفير قائمة تحقق نهائية للمالك وفريق العمليات لاعتماد جاهزية بيئة الاختبار وإزالة حظر النشر.

---

## 1. قائمة التحقق الفنية للبيئة (Remediation Checklist)

يجب على مهندس العمليات (DevOps) التحقق من البنود التالية وتوقيعها:

* [ ] **جاهزية خادم الاستضافة (Host Ready):**
  * تم تشغيل خادم افتراضي أو حاوية معزولة ومستقلة جغرافياً وشبكياً عن خادم الإنتاج.
* [ ] **جاهزية قاعدة البيانات (DB Ready):**
  * تم إنشاء قاعدة بيانات مستقلة باسم `nama_medical_staging`.
* [ ] **جاهزية مستخدم قاعدة البيانات (DB User Ready):**
  * تم إنشاء مستخدم مقيد باسم `nama_staging_user` يمتلك صلاحيات الوصول للـ Staging فقط.
* [ ] **إعداد ملف البيئة (Env Ready):**
  * تم إنشاء ملف التكوين `.env.staging` وتأمينه على خادم الاختبار.
* [ ] **عزل الأسرار والتشفير (Secrets Separated):**
  * تم توليد وتعيين قيم فريدة ومستقلة لـ `SESSION_SECRET` و `JWT_SECRET` تختلف عن مفاتيح الإنتاج.
* [ ] **جاهزية عملية PM2 (PM2 Process Ready):**
  * تم تسجيل التطبيق في PM2 كعملية مستقلة باسم `nama-app-staging`.
* [ ] **عزل السجلات والأخطاء (Logs Separated):**
  * تم فصل وتوجيه ملفات السجلات لمسار معزول خاص ببيئة الاختبار.
* [ ] **جاهزية النطاق الفرعي (Domain Ready):**
  * تم إعداد سجلات الـ DNS للنطاق الفرعي وتوجيهها للآي بي المخصص `staging.jumanasoft.com`.
* [ ] **جاهزية تشفير الشبكة (TLS Ready):**
  * تم تثبيت وإعداد شهادة SSL/TLS (Let's Encrypt) بنجاح على خادم الاختبار.
* [ ] **خطة النسخ الاحتياطي (Backup Ready):**
  * تم إعداد وتجربة سكربت النسخ الاحتياطي التلقائي لقاعدة بيانات الاختبار.
* [ ] **خطة التراجع (Rollback Ready):**
  * تم توثيق وتجربة آلية التراجع الفوري للإصدارات السابقة واستعادة النسخ الاحتياطية عند حدوث أعطال.
* [ ] **جاهزية البيانات التجريبية (Synthetic Data Ready):**
  * تم شحن قاعدة بيانات الاختبار ببيانات مصطنعة ووهمية بالكامل (Synthetic Data) ولا تحتوي على أي بيانات مرضى حقيقية (No PHI).
* [ ] **تعطيل منصة نفيس (NPHIES Disabled):**
  * تم ضبط وحدة الربط الإلكتروني مع نفيس على وضع المحاكاة الجافة (Mock/Dry-run) بنسبة 100%.
* [ ] **تعطيل الترحيل المالي والضريبي (Financial Posting Disabled):**
  * تم إيقاف وإغلاق واجهات الصرف والصناعة والقيود المحاسبية الحقيقية.
* [ ] **تعطيل واجهات الكتابة (Write Operations Disabled):**
  * تم تأكيد إغلاق أعلام الكتابة والتكامل الحي في ملفات العقود البرمجية وتفعيل وضع القراءة فقط.
