* **2. فحص أمان Sandbox الساكن:**
  * *الأمر المنفذ:* `node billing_sandbox_prep_static_test.js`
  * *الحالة:* PASS ✅ (نجاح 4/4 فحوصات).
* **3. فحص أمان جداول e47 الساكنة:**
  * *الأمر المنفذ:* `node billing_tables_candidate_static_test.js`

* **4. فحص أمان محول الفوترة ووظائف الوحدات المستقلة:**
