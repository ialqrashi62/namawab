# تقرير تصنيف خصوصية وحساسية بيانات جداول الفوترة (Jumanasoft Billing Tables Data Classification)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** تصميم جداول الفوترة المرشحة (PHASE_BILLING_TABLES_CANDIDATE_DESIGN)
* **البوابة:** البوابة 1.3 — تصنيف حساسية البيانات (Gate 1.3 — Sensitive Data Classification)
* **الحالة:** تم الفرض والتوثيق بنجاح (ENFORCED) ✅

---

## 1. تصنيف حساسية الحقول والبيانات المقترحة

تم حصر وتصنيف الحقول المخطط لها لتحديد ضوابط التشفير والحماية المفروضة:

| الحقل أو المكون (Column/Field) | تصنيف الحساسية | متطلبات الحماية والتعامل |
| :--- | :--- | :--- |
| **`id`, `created_at`, `updated_at`** | **non-sensitive** | بيانات عامة؛ لا تشفير. |
| **`plan_key`, `amount_minor`, `currency`**| **business-sensitive** | بيانات تجارية؛ تصفية إحصائية آمنة مع عزل المستأجر. |
| **`provider_customer_id_hash`** | **secret-like** | يتم تخزين معرفات الموفر مشفرة أو مموهة في الواجهات. |
| **`billing_email_masked`** | **PII** | يتم إخفاء البريد الإلكتروني (Masked) في شاشات الإدارة. |
| **`provider_transaction_id_hash`** | **payment-sensitive** | تشفير المعرف لمنع التتبع الخارجي. |
| **`actor_user_id`, `actor_role`** | **audit-only** | مقيدة للوصول الإداري الأعلى فقط وسيرفر النظام. |

---

## 2. البيانات المحظور تخزينها كلياً (Forbidden Data)

يُحظر منعاً باتاً تخزين أو معالجة أو تمرير أي من البيانات المالية الحساسة التالية داخل قاعدة البيانات:

* **أرقام بطاقات الدفع الكاملة (`Card Numbers / PAN`):** محظور كلياً.
* **رمز التحقق من البطاقة (`CVV / CVC`):** محظور كلياً.
* **الأسرار الصريحة والرموز السرية للمزودين:** محظور كلياً.
* **أغلفة الأحداث غير المطهرة (`Raw Provider Payload`):** يجب تعقيم الحزم الواردة (JSONB sanitization) وحذف أي حقول للبطاقات أو العمليات غير الآمنة قبل التخزين.

---
**القرار:** تم اعتماد مصفوفة تصنيف الحساسية وحظر تخزين بطاقات الدفع، ومصرح بالانتقال لـ PHASE 2 لتصميم الهياكل المرشحة.
