# قائمة تدقيق اختبارات القبول للمراجعة الداخلية (Jumanasoft Local Sanitized Internal UAT Checklist)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** مراجعة وتدقيق نطاق تعقيم بيئة الاختبار المحلية (PHASE_LOCAL_SANITIZED_STAGING_SCOPE_VERIFICATION_AND_INTERNAL_REVIEW_PREP)
* **البوابة:** البوابة 4.2 — قائمة تدقيق المراجعة الداخلية (Gate 4.2 — Internal UAT Checklist)
* **الحالة:** معتمد وجاهز للاختبار الداخلي (READY) ✅

---

## 1. عناصر وقائمة اختبارات القبول الداخلية المحدودة (UAT Checklist)

يقتصر نطاق الاختبار والقبول الداخلي المسموح به محلياً على العناصر التالية مع الحفاظ على صمامات الأمان معطلة:

| البند المراد اختباره (Scope Item) | الإجراء والتحقق المطلوب | حالة التشغيل والأمان |
| :--- | :--- | :---: |
| **مراجعة واجهة المسؤول العام (`Super Admin UI`)** | مراجعة أدوات وميزات إدارة التراخيص ومراقبة المستأجرين. | **محلي فقط (لا اتصال بالإنتاج)** |
| **مركز التحكم بالمستأجرين (`Tenant Control Center`)**| مراجعة شاشات وخصائص إعداد المستأجرين الجدد وتوزيع الصلاحيات. | **محلي فقط** |
| **شاشات أسعار وخطط الـ SaaS (`Plans & Pricing UI`)**| التحقق من عرض وتخصيص الباقات الثلاث (Starter, Growth, Enterprise) محلياً. | **بيانات وهمية معقمة** |
| **شاشة عرض الاستحقاقات المحسوبة (`Entitlements Display`)**| مراجعة كفاءة عمل الـ resolver وعرض حدود استهلاك الباقات بشكل صحيح. | **وضع المراقبة / محاكاة فقط** |
| **فحص ربط الحد الأقصى للمستخدمين (`max_users`)** | التحقق من صحة توجيه وقراءة حدود الاستهلاك بدون تفعيل المنع. | **Enforce = disabled** |
| **مراجعة التحكم بالوصول وحوكمة الصلاحيات (`RBAC`)** | مراجعة صلاحيات الأدوار المحدثة للأطباء ومسؤولي النظام والمستأجرين. | **محلي فقط** |
| **التأكد من خلو واجهات العرض من بيانات حقيقية** | التحقق البصري من استبدال كافة بيانات المرضى بالقيم المطهرة والوهمية. | **Sanitized Data Only** |
| **مراجعة التقارير المحاسبية والسريرية المحدثة** | التحقق من عرض مخرجات التقارير باللغة العربية UTF-8 بشكل سليم دون مشاكل. | **محلي فقط** |

## 2. ميزات محظورة ومحجوبة تماماً أثناء الاختبار (Forbidden Features)

* **عمليات الدفع والتسوية المباشرة (`Payments/Checkout`):** محظورة ومعطلة تماماً.
* **الربط بالخوادم المباشرة وبوابات المطالبات والـ Webhooks الحية:** معطلة كلياً.
* **الاتصال بأي قواعد بيانات للإنتاج الفعلي:** محظور قطعياً.

**القرار:** تم إقرار قائمة التدقيق وجاهزيتها، ومصرح بالانتقال للبوابة 4.3 لصياغة قرار الجاهزية UAT.
