# حزمة فحص الإنتاج بوضعية القراءة فقط لترقية المنشآت (PHASE_FACILITY_PRODUCTION_READONLY_PREFLIGHT_OWNER_PACKET_AR)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المستند:** استبيان مطابقة الإنتاج read-only الفعلي
* **الجهة المعنية:** مالك المشروع / فريق DevOps
* **الوضعية:** معلق بانتظار استلام الأدلة والإجابات المعتمدة ⏳

---

## استبيان DevOps لمطابقة الإنتاج (Production Read-only Verification Packet)

يرجى إكمال وتحديد إجابات الاستبيان التالي (YES/NO/PARTIAL/UNKNOWN) وتوثيقه لتجاوز حظر الـ Preflight:

### 1. التحقق من سلامة فحص القراءة فقط (Verification Context)
* **السؤال:** هل تم فحص بيئة الإنتاج الفعلي بوضعية القراءة فقط (read-only) بشكل كامل وآمن؟
  * [ ] YES
  * [ ] NO

* **السؤال:** هل تم التأكيد على عدم تشغيل أي أمر كتابة (DML) أو تعديل مخطط (DDL) أو هجرة بيانات (migration) على الإنتاج أثناء هذا التحقق؟
  * [ ] NO (أي لم يتم تنفيذ أي كتابة)

### 2. مطابقة المخطط والجداول (Schema Compatibility)
* **السؤال:** هل الجداول الـ 17 المنشأة حديثاً على Staging موجودة مسبقاً في قاعدة بيانات الإنتاج الفعلي؟
  * [ ] YES
  * [ ] NO
  * [ ] PARTIAL

* **السؤال:** هل جدول المنشآت الأساسي `facilities` موجود مسبقاً في قاعدة بيانات الإنتاج الفعلي؟
  * [ ] YES
  * [ ] NO

* **السؤال:** هل توجد أي تعارضات في أسماء الجداول، أو أسماء الأعمدة، أو القيود (Constraints) بين المخططين؟
  * [ ] YES
  * [ ] NO

* **السؤال:** هل إعدادات RLS/FORCE RLS الحالية متوافقة وخالية من التعارضات؟
  * [ ] YES
  * [ ] NO
  * [ ] UNKNOWN

### 3. أمن الصلاحيات والحسابات (Database Role Privileges)
* **السؤال:** هل صلاحيات الحساب (DB Role) المستخدم للاتصال بقاعدة بيانات التطبيق ليست SUPERUSER؟
  * [ ] YES
  * [ ] NO

* **السؤال:** هل صلاحيات الحساب ليست BYPASSRLS؟
  * [ ] YES
  * [ ] NO

* **السؤال:** هل تم تأكيد عدم طباعة أو كشف أي أسرار أو كلمات مرور أو رموز تحقق أو محتويات لملفات `.env`؟
  * [ ] NO (أي لم يتم كشفها)

> **إرشادات أمنية هامة:**
> يمنع تماماً كتابة أو إرسال كلمات المرور، أو رموز التحقق MFA، أو سلاسل الاتصال بالإنتاج، أو محتويات ملفات التكوين `.env` داخل هذا الاستبيان لضمان حماية الخصوصية.
