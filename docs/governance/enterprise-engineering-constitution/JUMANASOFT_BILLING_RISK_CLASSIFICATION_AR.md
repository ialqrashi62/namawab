## 1. تصنيف مخاطر أسطح الفوترة وتأثيراتها

تم تقسيم وتصنيف ميزات الفوترة المقترحة لتأمين عزل التشغيل ومنع أي تواصل خارجي غير مصرح به:

| ميزة الفوترة (Feature) | تصنيف المخاطر (Classification) | الحالة والقرار التشغيلي الحالي |
| :--- | :--- | :---: |
| **هيكل ومحول الفوترة للمطورين** | **Safe design-only** | مسموح به كلياً (تصميم وملفات برمجية مرشحة فقط). |
| **محاكي الفوترة المحلي (Mock Provider)**| **Mock-only** | مسموح به ومفعل للتطوير والتحقق الداخلي محلياً. |
| **جداول وقاعدة بيانات الفوترة** | **Requires real staging** | معلق ومحجوب لحين توفر Staging حقيقي معزول سحابياً. |
| **مفاتيح الحسابات التجريبية (Sandbox Key)**| **Requires provider sandbox** | معلق كلياً (يمنع استخدام أي مفاتيح تجريبية حقيقية حالياً). |
| **تفعيل بوابات الدفع الحية لـ SaaS** | **Requires production approval**| معلق كلياً ويتطلب موافقة أمنية وإدارية منفصلة لاحقاً. |
| **الاتصالات الخارجية للـ API والـ Webhooks**| **FORBIDDEN_NOW** | **محظور تماماً** ❌ (يمنع إجراء أي اتصال خارجي أو فتح ثغرة استقبال إشعارات). |

---
**القرار:** تم فرض حالة **`FORBIDDEN_NOW`** لجميع الاتصالات الخارجية والـ Webhooks الحية والربط الفعلي لمنع أي تسريب أمني.
