## 2. تقييم المخاطر المترتبة على الفجوات (Risk Assessment)

- **غياب سجلات الحذف والتعطيل:** يتيح للمشرفين المخربين إيقاف حسابات زملائهم أو حذف موظفين دون ترك أي أثر إلكتروني يدينهم، مما يعرقل عملية المتابعة القانونية للحادثة.
- **استعلام سجل التدقيق دون إثبات:** يمكّن من حدوث تسريبات داخلية سرية؛ حيث يستطيع أي مسؤول مالي أو تقني لديه صلاحية `settings` قراءة السجلات بالكامل لتتبع حركة أداء زملائه أو فحص نقاط الضعف دون علم الإدارة.

---

## 3. التوصيات الفنية للتحسين الحاكم (Technical Recommendations)

1. **تحسين دوال التحكم بالوصول (RBAC Middleware):** تحديث `requireRole` و `requirePermission` لتضمين استدعاء `logAudit` تلقائي عند إرجاع `403 Access denied`.
2. **تحصين نهايات الحذف والإنشاء:** إجبار كتابة أحداث التدقيق التلقائية لعمليات التعديل الهيكلي لقاعدة بيانات المستخدمين.
