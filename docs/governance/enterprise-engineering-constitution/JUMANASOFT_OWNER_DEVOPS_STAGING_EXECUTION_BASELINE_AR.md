## 1. محددات نطاق التفعيل للمرحلة الحالية

يقر مالك المشروع ومسؤول الديف أوبس (DevOps) بالالتزام الكامل بحدود الحظر والمنع المفروضة طوال هذه المرحلة كالتالي:

* **هذه المرحلة مخصصة للإجراءات الإدارية وتوفير خوادم Staging فقط (DevOps/Owner only).**
* **لا يتم تشغيل أو تنفيذ مخططات الفوترة `e47` (No e47 execution).**
* **لا يتم تشغيل أي استعلامات أو هجرات SQL (No SQL migration).**
* **يُحظر لمس أو الاتصال بقاعدة بيانات الإنتاج الفعلي (No production DB touched).**
* **تظل ميزات الفوترة والاشتراكات معطلة كلياً وقت التشغيل (No billing activation).**
* **لا يتم تفعيل أو استخدام بوابات الدفع التجريبية الحية (No provider sandbox).**
* **لا يوجد أي مسارات دفع (checkout) أو إشعارات (webhook) حية.**
