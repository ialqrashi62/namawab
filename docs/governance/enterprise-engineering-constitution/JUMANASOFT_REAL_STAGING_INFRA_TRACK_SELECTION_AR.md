# قرار ومسار تهيئة البنية التحتية لـ Staging (Jumanasoft Real Staging Infra Track Selection)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** تهيئة وفحص جاهزية بيئة Staging الحقيقية (PHASE_REAL_STAGING_INFRA_PROVISIONING_AND_EVIDENCE_CAPTURE)
* **البوابة:** البوابة 2.1 — قرار تحديد المسار (Gate 2.1 — Detect Real Staging Evidence)
* **المسار المختار للتنفيذ (TRACK_SELECTED):** مسار تسليم المالك / الديف أوبس (**`TRACK_SELECTED = B_OWNER_DEVOPS_HANDOFF`**) ✅
* **القرار النهائي المعتمد للمرحلة:** حظر التفعيل بانتظار البنية المخصصة من المالك (`REAL_STAGING_INFRA_BLOCKED_OWNER_ACTION_REQUIRED`) ⚠️

---

## 1. شواهد ودليل فحص البنية التحتية الحالية لـ Staging

تم إجراء مسح شامل لبنية الاستضافة السحابية للمنصة وخلصت النتائج إلى التالي:

* **شواهد وجود خادم Staging مستقل:** لا توجد خوادم استضافة تجريبية معزولة حقيقية مفعلة حالياً؛ ولم يتم تمرير أي عناوين خوادم أو مفاتيح وصول للتحقق الميداني.
* **شواهد وجود قاعدة بيانات معزولة:** لا توجد قاعدة بيانات تجريبية حقيقية مستقلة؛ وقاعدة البيانات المحلية الحالية غير آمنة للربط المباشر مع بوابات الدفع حية.
* **حالة الـ Submodule والكود:** كود المحول معطل افتراضياً ومقيد بـ Mock-only.

## 2. نتيجة القرار والمسار المعتمد

نظراً لعدم توفر خادم Staging حقيقي معزول سحابياً:
1. تم تحديد المسار **`B_OWNER_DEVOPS_HANDOFF`** لإعداد حزمة تسليم فنية كاملة للمالك ومسؤول الشبكة (DevOps) لتنفيذ المطلوب.
2. تم إصدار القرار المعتمد **`REAL_STAGING_INFRA_BLOCKED_OWNER_ACTION_REQUIRED`** لتعليق ومنع تشغيل الهجرة `e47` أو الاتصال بالبوابات التجريبية لحين قيام المالك بإرجاع شواهد التهيئة وتوثيقها.

---
**القرار:** تم اعتماد مسار العمل B وتحديد خطة تسليم المالك، ومصرح بالانتقال لـ TRACK B لبناء مستندات التسليم والتعليمات.
