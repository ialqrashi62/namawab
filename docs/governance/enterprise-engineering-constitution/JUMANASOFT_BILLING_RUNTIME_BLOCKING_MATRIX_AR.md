## 1. مصفوفة الأنشطة المسموحة والمحظورة للفوترة حالياً

تم تقسيم وتوثيق الصلاحيات التشغيلية والأنشطة الخاصة بالفوترة لضمان سلامة البيئة ومنع أي تداخل أمني:

### الأنشطة المسموحة حالياً (Allowed Now) ✅
* **اختبارات الموفر الوهمي (Mock Provider Tests):** مسموح بها ومفعلة لاختبار جودة الدوال وصمامات التحقق.
* **المستندات التصميمية وتقارير الحوكمة (Design Docs):** مسموح بصياغتها وحفظها في مستودع الأكواد.
* **المراجعة البرمجية الداخلية لكود المحول (Internal Code Review):** مسموح وموصى بها للمطورين محلياً فقط.

### الأنشطة المحظورة والمحجوبة تماماً حالياً (Blocked Now) ❌
* **موفر الدفع الحقيقي والاتصال الحي (Live Provider / HTTP API):** محجوب بالكامل.
* **مفاتيح البوابات التجريبية (Sandbox Provider Keys):** محجوب بالكامل ويمنع إضافتها.
* **روابط الخروج والدفع المالي للعملاء (Checkout):** محجوب بالكامل.
* **نقاط استقبال إشعارات الدفع (Webhook Listeners):** محجوب بالكامل.
* **التعديل الهيكلي وقواعد بيانات الفوترة (Subscription Mutation / DDL):** محجوب بالكامل.
* **مهام الفوترة التلقائية ومحاولات التحصيل الفاشلة (Billing Cron / Dunning):** محجوب بالكامل.
* **النشر للإنتاج أو فتح الاستضافة العامة (Production Deploy / Public Staging):** محجوب بالكامل.
* **تفعيل المراقبة والمنع للاستحقاقات (Observe / Enforce):** محجوب بالكامل.
