## 1. مقارنة شاملة بين مزودي خدمات الفوترة والاشتراكات المقترحين

تم صياغة مقارنة تصميمية لخصائص بوابات الدفع المقترحة لتحديد قابليتها للتطبيق مستقبلاً:

| وجه المقارنة | `MockProvider` الحالي | `Moyasar` | `Stripe` | `HyperPay` |
| :--- | :--- | :--- | :--- | :--- |
| **التوفر الجغرافي (KSA/GCC)** | محلي للمراجعة | ممتاز ومحلي في السعودية | متوفر دولياً وإقليمياً | ممتاز ومحلي بالكامل |
| **العملات المدعومة (SAR)** | SAR, USD | SAR (أساسي)، عملات الخليج | SAR وعملات دولية متعددة | SAR وعملات دولية |
| **نموذج الدفع (Checkout)** | محاكاة بالذاكرة | Hosted Checkout / API | Stripe Checkout / API | Hosted Form / API |
| **نموذج الـ Webhook** | محاكاة محلية | HTTP POST (مع توقيع) | HTTP POST (توقيع متقدم) | HTTP POST (توقيع رقمي) |
| **نموذج الاسترداد (Refund)** | إرجاع حالة نجاح وهمية | عبر Moyasar API | عبر Stripe API | عبر HyperPay API |
| **دعم الاشتراكات الدورية** | محاكاة كاملة | محدود (يحتاج لإدارة وتنسيق مخصص) | متقدم جداً (Billing/Subscriptions) | يحتاج لربط متكرر مخصص |
| **الأسرار المطلوبة لاحقاً** | لا يوجد | مفاتيح Moyasar السرية والعامة | مفاتيح Stripe وسر الـ Webhook | مفاتيح HyperPay ومعرف الكيان |
| **متطلبات البيئة التجريبية** | لا يوجد | حساب Moyasar Sandbox | حساب Stripe Developer Sandbox | حساب HyperPay Test Account |
| **دعم مفتاح التفرد** | مدعوم محلياً | مدعوم في طلب الدفع | مدعوم عبر `Idempotency-Key` | مدعوم عبر طلب المعاملة |
| **مخاطر التشغيل والخصوصية** | منخفضة جداً | معالجة مخرجات مدى محلياً | معالجة البيانات دولياً | مخاطر تعقيد الربط والتكامل |
| **سبب حجب التفعيل حالياً** | **غير محجوب** (مسموح) | غياب بيئة Staging معزولة والموافقة | غياب بيئة Staging معزولة والموافقة | غياب بيئة Staging معزولة والموافقة |
