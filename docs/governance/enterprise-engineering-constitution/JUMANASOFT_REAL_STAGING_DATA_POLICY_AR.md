# سياسة سلامة وتعقيم البيانات لبيئة Staging (Jumanasoft Real Staging Data Safety Policy)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** تهيئة وفحص جاهزية بيئة Staging الحقيقية (PHASE_REAL_STAGING_INFRA_PROVISIONING_AND_EVIDENCE_CAPTURE)
* **البوابة:** البوابة 1.3 — سياسة سلامة البيانات (Gate 1.3 — Data Policy)
* **الحالة:** تم التوثيق والفرض بنجاح (ENFORCED) ✅

---

## 1. قواعد ومصدر بيانات بيئة الاستضافة التجريبية (Data Source Rules)

لضمان السرية التامة للمعلومات السريرية والمالية للمرضى، يتم فرض القواعد الحاكمة التالية على البيانات في بيئة Staging:

* **المصدر المعتمد للبيانات (Staging Data Source):**
  * **الخيار المفضل:** استخدام البيانات الاصطناعية بالكامل (Synthetic Data).
  * **الخيار المسموح بعد التأكيد:** استخدام البيانات الحقيقية فقط بعد إجراء تعقيم وتطهير شامل ومثبت بالأدلة الموثقة في تقارير التعقيم السابقة (`SANITIZED_SCOPE_VERIFIED`).
* **المحرمات والمحظورات القاطعة (Prohibited Data):**
  * **يُحظر تماماً** استيراد أو استخدام نسخة خام (Raw Dump) من قاعدة بيانات الإنتاج الفعلي.
  * **يُحظر تماماً** وجود أي سجلات تحتوي على بيانات المرضى الحيوية أو الشخصية (PHI/PII) مثل الهويات الوطنية، أو أرقام الهواتف الحقيقية، أو البريد الإلكتروني الحقيقي.
  * **يُحظر تماماً** تخزين أي رموز تشفير، أو مفاتيح دفع Moyasar/Stripe حقيقية، أو أسرار حيوية.
* **فحص المجهولات والشكوك (Verification Mandate):**
  * يجب أن يعاد فحص قاعدة Staging بصفة دورية للتأكد من أن عدد الحالات المشبوهة أو السجلات غير المعقمة مساوٍ تماماً للصفر (`suspicious_count = 0`).

---
**القرار:** تم صياغة واعتماد سياسة سلامة وتعقيم البيانات، ومصرح بالانتقال لـ PHASE 2 لتحديد مسار تشغيل الأوتوبيلوت.
