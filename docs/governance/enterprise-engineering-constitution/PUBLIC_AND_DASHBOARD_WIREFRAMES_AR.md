# تخطيط واجهات الصفحة الرئيسية ولوحة التحكم (Public & Dashboard Wireframes)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** منصة المنشآت الصحية المتعددة (PHASE_ENTERPRISE_FACILITY_PLATFORM_WITH_MEDICAL_CITY_SELECTOR)
* **المستند:** تخطيط واجهات الصفحة الرئيسية ولوحة التحكم (PUBLIC_AND_DASHBOARD_WIREFRAMES_AR)
* **الحالة:** معتمد ✅

---

## 1. التخطيط الهيكلي للواجهة العامة للمريض (Public Homepage Wireframe)

يتمثل تخطيط الصفحة الرئيسية العامة في الهيكل السلكي التالي المخصص لخدمة الجمهور:

```
+-----------------------------------------------------------------------------------+

+-----------------------------------------------------------------------------------+
|                                                                                   |
|                   أهلاً بك في منصة جمانة الطبية لإدارة الرعاية الصحية             |
|                                                                                   |
|        +-----------------------------------------------------------------+        |
|        |  اختر المدينة الطبية: [ مدينة الملك فهد الطبية               v ] |        |
|        +-----------------------------------------------------------------+        |
|        |  بحث بالاسم، التخصص، أو الخدمة الطبية...                        | [بحث]  |
|        +-----------------------------------------------------------------+        |
|                                                                                   |
+-----------------------------------------------------------------------------------+
|   [طوارئ وإسعاف 🚨]      [حجز موعد 📅]       [المراكز المتخصص 🏆]     [شركاء التأمين 🛡️]   |

|                                                                                   |
|  * خدماتنا الطبية المتكاملة:                                                      |
```

## 2. التخطيط الهيكلي للوحة التحكم الداخلية (Dashboard Wireframe & Switched Workspace)

يعتمد هيكل لوحة التحكم للمستخدمين بعد تسجيل الدخول على تفعيل الشريط الجانبي ومحدد المنشأة العلوي:

```
+-----------------------------------------------------------------------------------+
| [☰]  لوحة التحكم  |  محدد النطاق: [ مدينة الملك فهد - مستشفى الأطفال v ]  [Admin ⚙️] |
+-----------------------------------------------------------------------------------+
| (شريط جانبي)   |                                                                  |
| - الرئيسية     |  * لوحة تشغيل مستشفى الأطفال (Hospital Workspace)                |
| - المراجعين    |  +-----------------------+ +-----------------------+            |
| - العيادات     |  | إشغال الأسرة:  %85    | | الحالات بالطوارئ: 12  |            |
| - التنويم      |  +-----------------------+ +-----------------------+            |
| - العمليات     |  | العمليات اليوم: 4     | | الأطباء المناوبون: 8|            |
| - المختبر      |  +-----------------------+ +-----------------------+            |
| - الأشعة       |                                                                  |
| - الصيدلية     |  * الأقسام النشطة بالمنشأة (Department Activation Matrix):       |
| - التأمين      |  [x] الطوارئ  [x] العيادات الخارجية  [x] الصيدلية  [ ] العمليات الكبرى|
| - الموظفين     |                                                                  |
| - الإعدادات    |  * مراقبة مؤشرات الجودة والأمان (CBAHI & OVR):                    |
|                |  - السجلات الطبية غير المقفلة (>24 ساعة): 0 سجلات معلقة.           |
|                |  - بلاغات الحوادث التشغيلية (OVR): لا توجد بلاغات حرجة نشطة.     |
+-----------------------------------------------------------------------------------+
```
---
* **سلوك التنقل (Navigation Behavior):** عند اختيار مستخدم إداري "مدينة الملك فهد الطبية" بأكملها من المحدد العلوي، تتبدل واجهة العمل لتعرض ودجات Command Center شاملة لكافة الفروع والمستشفيات التابعة لها دفعة واحدة بدلاً من البيانات الحصرية للمستشفى المنفرد.
