# جرد وتصنيف البيانات الحساسة لبيئة الاختبار المحلية (Jumanasoft Local Staging Sanitization Inventory)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** حسم مسار مخاطر البنية التحتية والبيانات (PHASE_RESOLVE_INFRA_OR_DATA_RISK_FIRST)
* **البوابة:** البوابة B1 — جرد بيانات التعقيم (Gate B1 — Local Staging Sanitization Inventory)
* **الحالة:** تم الجرد والتصنيف بنجاح (SUCCESS) ✅

## 1. قائمة الجداول والأعمدة الحساسة المراد تعقيمها (PII/PHI)

تم مسح هياكل ومخططات جداول قاعدة البيانات لتحديد الحقول التي قد تحتوي على معلومات شخصية للمرضى والموظفين أو سجلات طبية ومالية حساسة:

| اسم الجدول (Table Name) | الأعمدة الحساسة (Sensitive Columns) | نوع البيانات (Data Type) | تصنيف الحساسية |
| :--- | :--- | :--- | :--- |
| **`patients`** | `name_ar`, `name_en` | أسماء المرضى | PII (معلومات شخصية) |
| | `national_id` | أرقام الهوية والإقامة | PII (معلومات شخصية) |
| | `phone` | أرقام الهواتف | PII (معلومات شخصية) |
| | `notes` | ملاحظات المريض العامة | PII / PHI |
| **`appointments`** | `patient_name` | أسماء المرضى | PII (معلومات شخصية) |
| | `notes` | ملاحظات الموعد | PHI (بيانات صحية) |
| **`waiting_queue`** | `patient_name` | أسماء المرضى | PII (معلومات شخصية) |
| **`employees`** | `name`, `name_ar`, `name_en` | أسماء الموظفين | PII (معلومات شخصية) |
| **`invoices`** | `patient_name` | أسماء المرضى | PII (معلومات شخصية) |
| | `description` | وصف الفاتورة والخدمة | PII / Financial |
| **`medical_records`** | `diagnosis` | التشخيصات الطبية | PHI (بيانات صحية حساسة) |
| | `symptoms` | الأعراض الطبية | PHI (بيانات صحية حساسة) |
| | `notes` | الملاحظات السريرية للأطباء | PHI (بيانات صحية حساسة) |
| **`system_users`** | `display_name` | الأسماء المعروضة للمستخدمين | PII (معلومات شخصية) |

## 2. قواعد التطهير والأمان المفروضة

* **منع الاستثناءات:** يجب إخضاع كافة الحقول المذكورة أعلاه لعملية استبدال كامل وقيم وهمية اصطناعية.
* **منع طباعة القيم الأصلية:** يُمنع طباعة أي قيم حقيقية مستهدفة بالتعقيم في سجلات التشغيل أو مخرجات الطرفية أثناء الفحص أو التطبيق.
