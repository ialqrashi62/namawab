# حزمة تسليم متطلبات البنية التحتية لـ Staging (Jumanasoft Real Staging DevOps Handoff Packet)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** تهيئة وفحص جاهزية بيئة Staging الحقيقية (PHASE_REAL_STAGING_INFRA_PROVISIONING_AND_EVIDENCE_CAPTURE)
* **البوابة:** البوابة B1 — حزمة تسليم المتطلبات (Gate B1 — DevOps Handoff Packet)
* **الحالة:** تم التوثيق والفرض بنجاح (ENFORCED) ✅

---

## 1. قائمة الموارد المطلوب إنشاؤها سحابياً (Required Resources)

يجب على مسؤول الديف أوبس (DevOps) أو مالك النظام تهيئة الموارد التالية بالكامل لتوفير بيئة اختبار آمنة لجمانة سوفت:

1. **خادم الاستضافة الافتراضي (Staging Server/VM):**
   * *الاسم التعريفي:* `jumanasoft-staging`
   * *الوصف:* خادم مستقل كلياً ومعزول في شبكة فرعية خاصة (Private Subnet).
2. **قاعدة البيانات (Database):**
   * *الاسم التعريفي:* `jumanasoft_staging`
   * *المستودع الرئيسي:* مستقل ومفصول عن عنقود الإنتاج.
3. **حساب مستخدم قاعدة البيانات (DB User):**
   * *الاسم التعريفي:* `jumanasoft_staging_user`
   * *أعلام الصلاحيات الأمنية (Role Flags):*
     * **`NOSUPERUSER`** (حظر صلاحيات المدير الأعلى لمنع التلاعب بالمخطط).
     * **`NOBYPASSRLS`** (فرض سياسات حماية الصفوف RLS على جداول الفوترة).
4. **عملية تشغيل التطبيق (App Process):**
   * *الاسم التعريفي في PM2:* `jumanasoft-app-staging`
   * *المنفذ المفتوح (Port):* `3010` (أو منفذ بديل موثق).
5. **ملف التهيئة البيئية (Environment File):**
   * *الاسم:* `.env.staging` (مع عدم كتابة أي مفاتيح Moyasar حقيقية عليه حالياً).
6. **مسارات خادم الويب (Nginx Site & Domain):**
   * *اسم النطاق:* `staging.jumanasoft.com`
   * *حماية الدخول:* تفعيل Basic HTTP Authentication أو تحديد العناوين المسموحة (IP Allowlist).
   * *منع محركات البحث:* تفعيل خيار `noindex` في ترويسة الصفحة لمنع جوجل ومحركات البحث من زحف البيئة التجريبية.

---
**القرار:** تم صياغة متطلبات حزمة التسليم، ومصرح بالانتقال لـ GATE B2 لبناء نموذج أدلة المالك.
