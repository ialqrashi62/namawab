# تصميم وحصر مفاتيح وأسرار الفوترة المستقبلية (Jumanasoft Billing Sandbox Secrets Inventory Design)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** إعداد بوابات الدفع التجريبية مستندياً (PHASE_BILLING_SANDBOX_PREP_DOCS_ONLY)
* **البوابة:** البوابة 2.1 — تصميم وحصر الأسرار (Gate 2.1 — Secrets Inventory Design)
* **الحالة:** تم التوثيق والفرض بنجاح (ENFORCED) ✅

---

## 1. مسودة الأسرار والمفاتيح المطلوبة مستقبلاً (قوالب بدون قيم حقيقية)

تم تخطيط وهيكلة الأسرار المطلوبة للتشغيل المستقبلي مع فرض سياسات صارمة لحمايتها:

### 1. المفتاح العام للربط (`BILLING_PROVIDER_PUBLIC_KEY`)
* **المالك:** مدير النظام (System Admin).
* **مكان التخزين المستقبلي:** متغيرات البيئة الآمنة على الخادم.
* **سياسة التدوير (Rotation Policy):** سنوياً أو عند طلب تحديث الحساب التجاري.
* **مخاطر الكشف (Exposure Risk):** منخفضة (مفتاح عام يستخدم للواجهات الأمامية).

### 2. المفتاح السري للعمليات والـ API (`BILLING_PROVIDER_SECRET_KEY`)
* **المالك:** مهندس العمليات الرئيسي (DevOps Lead).
* **مكان التخزين المستقبلي:** مدير الأسرار للبيئة السحابية (Secret Manager) / Vault.
* **سياسة التدوير:** نصف سنوية أو فورياً عند حدوث اشتباه تسريب.
* **مخاطر الكشف:** **حرجة جداً** (يسمح بإجراء عمليات دفع وسحب والتحكم بالاشتراكات).

### 3. سر التحقق من توقيع الـ Webhook (`BILLING_WEBHOOK_SIGNING_SECRET`)
* **المالك:** مهندس العمليات الرئيسي (DevOps Lead).
* **مكان التخزين المستقبلي:** مدير الأسرار السحابي الآمن.
* **مخاطر الكشف:** **حرجة** (يسمح للمهاجمين بإنشاء أحداث دفع وهمية وتخطي الدفع الفعلي).

### 4. معرف الكيان التجاري للموفر (`BILLING_PROVIDER_ACCOUNT_ID`)
* **المالك:** الإدارة المالية.
* **مكان التخزين المستقبلي:** متغيرات البيئة الآمنة على الخادم.
* **مخاطر الكشف:** منخفضة (معرف تعريفي للحساب).

---

## 2. قواعد السلامة الصارمة لحماية الأسرار (Security Mandates)

* **حظر مطلق في المستودع البرمجي (Never Commit to Git):** يُمنع منعاً باتاً كتابة أو حفظ أي من هذه القيم داخل ملفات الكود أو المستودع البرمجي.
* **حظر طباعة الأسرار في السجلات (Never Print in Logs):** يُحظر طباعة أي مفاتيح تشفير أو قيم سرية في مخرجات الكونسول أو ملفات سجلات التشغيل.
