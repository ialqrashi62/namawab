# تقرير القرار النهائي للأمان والبنية التحتية لبيئة الاختبار (Jumanasoft Staging Security & Infra Decision Closeout Report)

* **المشروع:** منصة نما الطبية (NamaMedical ERP)
* **المرحلة:** مراجعة أمان بيئة الاختبار وقرار البنية التحتية (PHASE_STAGING_SECURITY_REVIEW_AND_REAL_INFRA_DECISION)
* **البوابة:** البوابة 8 — تقرير القرار النهائي (Gate 8 — Final Decision Report)
* **القرار النهائي المعتمد للمرحلة:** متطلبات بيئة اختبار حقيقية معزولة أولاً (`PHASE_REAL_STAGING_INFRA_REQUIRED`) ⚠️

---

## 1. ملخص الحالة والمعالجات المنجزة

تم إنهاء فحص أمان بيئة الاختبار المحلية ومطابقتها بالأنظمة المعتمدة وتوثيق التالي:

* **ما تم معالجته وتصحيحه:**
  1. تدوير كلمة مرور قاعدة البيانات وتأكيد خلو المستودع من أي أسرار مكشوفة.
  2. تصحيح تصنيف الوصول لقاعدة بيانات الإنتاج إلى اتصال للقراءة فقط (`PRODUCTION_READONLY_TOUCHED: YES`) لتوضيح أخذ الـ dump.
  3. تصنيف البيانات المستعادة على أنها غير مطهرة (`PRODUCTION_DERIVED_UNSANITIZED`).
  4. إعادة تصنيف عزل البيئة الحالية على أنها قاعدة بيانات اختبار محلية على نفس العنقود القائم وليس خادماً مستقلاً معزولاً.
  5. تفعيل صمامات أمان التحميل والفشل الآمن لمنع أي انزلاق صامت للإنتاج في وضع التطوير.
* **ما زال محجوباً (Blocked):**
  * النشر للإنتاج، دمج الفروع مع الفرع الرئيسي، وفتح الوصول الخارجي أو الـ DNS لبيئة الاختبار.

---

## 2. جدول لوحة القرار والاعتماد (Decision Panel)

| البند الفني | الحالة / القرار المعتمد | تفاصيل وإيضاحات |
| :--- | :---: | :--- |
| **القرار المختار للمرحلة** | **PHASE_REAL_STAGING_INFRA_REQUIRED** | يتطلب المشروع توفير بنية staging حقيقية معزولة قبل أي تفعيل للإنفاذ. |
| **هل الإنتاج مسموح؟** | **NO** | يمنع النشر للإنتاج بالكامل. |
| **هل الاستضافة العامة مسموحة؟** | **NO** | يمنع تشغيل DNS عام لبيئة الاختبار الحالية. |
| **هل تفعيل المراقبة (Observe) مسموح؟** | **NO** | معطلة، ولن تفعل إلا بعد توفير staging الحقيقية أو إثبات تطهير البيانات. |
| **هل تفعيل المنع (Enforce) مسموح؟** | **NO** | معطل تماماً. |
| **هل تفعيل الفواتير (Billing) مسموح؟** | **NO** | معطل تماماً. |
| **هل دور العمليات (DevOps) مطلوب؟** | **YES** | مطلوب لتوفير الخادم المستقل وتثبيت الـ DNS والـ Nginx وعزل القاعدة. |
| **هل تعقيم البيانات (Sanitization) مطلوب؟** | **YES** | كمتطلب موازٍ أو بديل لتطهير البيانات الحالية وإثبات خلوها من PHI/PII. |

---

## 3. المخاطر المتبقية والخطوة التالية المسموحة

* **المخاطر المتبقية (Residual Risks):** بقاء بيانات إنتاج حقيقية غير مطهرة على الجهاز المحلي للتطوير يعرضها لمخاطر أمنية محلية في حال عدم تأمين الجهاز فيزيائياً.
* **الخطوة التالية المسموحة (Next Allowed Action):**
  * إحالة متطلبات التهيئة والتجهيز لمهندس العمليات (DevOps) لتوفير البنية التحتية المعزولة لبيئة الاختبار الحقيقية (`DEVOPS_PROVISION_REAL_ISOLATED_STAGING`).

---
**القرار المعتمد للجنة المراجعة:** اعتماد قرار **`PHASE_REAL_STAGING_INFRA_REQUIRED`** وإحالة حزمة العمل لمهندس العمليات لتوفير خادم مستقل بالكامل مع DNS معزول قبل المتابعة.
