## 1. نموذج الاتصال والربط الشبكي الآمن (Network Access Model)

تم تحديد مصفوفة الوصول وقنوات الاتصال لبيئة الاستضافة التجريبية لضمان عزل النطاق:

1. **منافذ الاتصال المسموحة (Inbound Ports):**
   * منفذ `22` (SSH): متاح للمشرف الأعلى والمالك فقط بتفويض آمن ومفاتيح معتمدة.
   * منافذ `80` و `443` (HTTP/HTTPS): متاحة بعد تطبيق تصفية العناوين (Basic Auth / IP allowlist) للتحقق والـ Smoke Tests.
2. **منع الوصول المتقاطع لقاعدة الإنتاج (Blocked DB Access):**
   * يتم فرض جدار حماية (Firewall) يمنع خادم Staging من إجراء أي اتصالات بقاعدة بيانات الإنتاج الفعلي أو شبكته الخاصة.
3. **عدم مشاركة بيانات الاعتماد (No Shared Credentials):**
   * يُمنع استخدام أي كلمات مرور، أو مفاتيح تشفير، أو ملفات بيئة مشتركة بين خادم الإنتاج وخادم Staging.
4. **ملف تهيئة الموارد (.env.staging):**
   * يتم تخصيص ملف البيئة `.env.staging` على الخادم ليضم متغيرات Staging فقط.
   * يُحظر طباعة قيم هذا الملف أو إدراجه في المستودع البرمجي.
5. **جدران الحماية للـ DB (pg_hba.conf):**
   * تقييد اتصال قاعدة البيانات `jumanasoft_staging` بالاتصال المحلي فقط أو حاوية التطبيق الحصرية عبر ملف `pg_hba.conf`.
