# دليل الاستجابة لحوادث الأمن السيبراني والتشغيل (Security Incident Response Runbook)

**تاريخ الإصدار**: 2026-07-03  
**الحالة**: معتمد ونشط  
**النطاق**: نظام إدارة المستشفيات NamaMedical  
**التوافق**: متطلبات الهيئة الوطنية للأمن السيبراني (NCA) ونظام حماية البيانات الشخصية (PDPL)  

---

## 1. أهداف الدليل وسياق الأمان
يحدد هذا الدليل الخطوات المنظمة التي يجب على فريق التشغيل والأمان اتباعها فور رصد أي حادثة سيبرانية أو تشغيلية تؤثر على سلامة البيانات أو استمرارية الأعمال في نظام NamaMedical.  
يتم اتباع سياسة **عزل المخاطر أولاً (Containment First)** لضمان حماية بيانات المرضى (PHI) وسجلات الفواتير المالية.

---

## 2. مصفوفة تصنيف الحوادث والتعامل معها

### الحادثة الأولى: تعطل خادم مخزن الجلسات (Redis Outage)
* **الأعراض**:
  - فشل عمليات الدخول للنظام وإرجاع رمز الحالة HTTP 500.
  - تعذر إعادة تجديد أو توثيق الجلسات (Session regeneration).
* **إجراءات التحقق**:
  - فحص حالة الحاوية عبر سطر الأوامر:
    ```powershell
    docker ps -a --filter "name=nama-redis"
    ```
  - التحقق من استجابة خادم Redis:
    ```powershell
    docker exec nama-redis redis-cli ping
    ```
* **خطوات التعافي والاحتواء**:
  1. إذا كانت الحاوية متوقفة، قم بتشغيلها فوراً:
     ```powershell
     docker start nama-redis
     ```
  2. إذا كان خادم Docker daemon متوقفاً بالكامل، اتبع خطوات الحادثة الثانية أدناه.
  3. فور استعادة الخدمة، تأكد من استقرار جلسات المستخدمين عبر مراقبة سجلات PM2:
     ```powershell
     pm2 logs nama-medical-erp
     ```

---

### الحادثة الثانية: توقف محرك الحاويات (Docker Daemon Failure)
* **الأعراض**:
  - إرجاع خطأ "Docker daemon is not running" عند تنفيذ أي أمر.
  - تعطل الخدمات المعتمدة على الحاويات (مثل Redis أو قنوات الربط الرقمية).
* **إجراءات التحقق**:
  - تشغيل فحص صحة محرك Docker:
     ```powershell
     docker info
     ```
* **خطوات التعافي والاحتواء**:
  1. تشغيل واجهة Docker Desktop أو الخدمة الخلفية عبر سطر الأوامر بصلاحية مسؤول:
     ```powershell
     Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'
     ```
  2. الانتظار لمدة 30 ثانية ثم التحقق من استجابة المحرك.
  3. إعادة تشغيل الحاوية المخصصة للجلسات:
     ```powershell
     docker start nama-redis
     ```
  4. إعادة تفعيل حارس التشغيل التلقائي (Watchdog) للتأكد من استقرار الخدمة:
     ```powershell
     powershell -NoProfile -File ops/watchdogs/nama_health_watchdog.ps1
     ```

---

### الحادثة الثالثة: تسريب أو اشتباه بكشف مفاتيح التشفير (KEK Compromise)
* **الأعراض**:
  - ظهور مفتاح التشفير أو جزء من ملف الـ escrow في سجلات عامة أو مستودع الكود (Git commit).
  - رصد دخول غير مصرح لصندوق الخادم الأساسي.
* **إجراءات التحقق**:
  - مراجعة سلامة ملف `nama_kek.dpapi` والتحقق من عدم المساس بصلاحيات الوصول للملف (ACL).
* **خطوات الاحتواء وإعادة التغليف (Re-wrapping)**:
  1. **تفعيل وضع الصيانة الفوري**: حظر الوصول للمنافذ الخارجية مؤقتاً عبر جدار الحماية (Firewall) لمنع أي تعديل أو فك تشفير غير مصرح.
  2. **إصدار مفتاح جديد**: تشغيل أداة إعادة التغليف الآمنة لتوليد مفتاح KEK جديد وتعديل ملف التكوين.
  3. **إعادة تشفير الحقول الحساسة**: تشغيل سكربت إعادة التشفير داخل بيئة معزولة (Dry-run أولاً لمطابقة الهاشات).
  4. **تحديث الـ Escrow**: تشغيل أداة الكيما الخام لإنشاء حزمة الـ escrow الجديدة وإزالتها فوراً إلى cold storage مع حذف النسخة المؤقتة.

---

### الحادثة الرابعة: محاولة الوصول عبر المستأجرين (Cross-Tenant Access Attempt)
* **الأعراض**:
  - ظهور سجلات تحذيرية في الـ Audit Trail تحمل الكود `BLOCKED_AUTHORIZATION` أو محاولة قراءة معرف `patient_id` لا يخص الـ `tenant_id` النشط للمستخدم.
* **إجراءات التحقق**:
  - استعلام سجلات التدقيق للأمن السيبراني:
     ```sql
     SELECT * FROM audit_trail WHERE action = 'UNAUTHORIZED_CROSS_TENANT_ACCESS' ORDER BY created_at DESC LIMIT 50;
     ```
* **خطوات الاحتواء والردع**:
  1. **تعليق الحساب مؤقتاً**: تعليق حساب المستخدم الذي صدرت منه المحاولة فوراً عبر لوحة السوبر أدمن أو تحديث حالة المستخدم في قاعدة البيانات إلى `is_active = 0`.
  2. **حظر عنوان IP**: في حال تكرار المحاولات من نفس العنوان الخارجي، يتم إدراج عنوان IP في قائمة الحظر التلقائي بجدار الحماية أو Cloudflare.
  3. **الإبلاغ التنظيمي**: رفع تقرير بالحادثة إلى مسؤول حماية البيانات لمطابقة متطلبات لوائح PDPL (خلال 72 ساعة كحد أقصى).
