# 02 — مصفوفة البوابات الحاجبة (Blocking Gates)

> 2026-06-22 | ما الذي يحجب كل مسار، ومن يملك فكّه.

| الحاجز | يحجب | المالك | الفكّ |
|---|---|---|---|
| **Browser E2E (لا حساب اختبار)** | A1 UI، A2 MFA، A3A file guard، BCMA، WHO checklist، accessibility | المالك | `PROVIDE_TEST_ACCOUNT_FOR_BROWSER_E2E` (ملف اعتماد out-of-band) |
| **KMS / مفاتيح** | A3 تشفير، النسخ المشفّرة offsite، NPHIES/ZATCA شهادات | المالك/البنية | توفير KMS/مفتاح خارج المستودع |
| **أطراف خارجية** | FHIR/HL7/PACS/LIS-RIS/NPHIES/ZATCA | المالك + مزوّدون | عقود/بيئات تكامل |
| **موافقة DDL/نشر صريحة** | A2 MFA، A3/A3A، WHO جدول، أي جدول جديد | المالك | بوابة باسمها (APPROVE_*) |
| **موافقة محاسبة منفصلة** | تفعيل الترحيل | المالك | `APPROVE_ACCOUNTING_POSTING_ENABLEMENT` (يبقى OFF) |
| **شجرة R17 (محلولة)** | — (مرفوعة؛ main نظيفة) | — | لا حاجز الآن؛ عدم merge بلا قرار |
| **PHI upload freeze (A3B)** | رفع ملفات PHI حقيقية | المالك | `APPROVE_PHI_FILE_GUARD_DEPLOY` (يحتاج E2E) |

## الخلاصة
الحاجز الأكبر = **حساب اختبار E2E** (يفكّ 6 بنود). يليه **KMS** (يفكّ التشفير/النسخ). التكاملات تحتاج أطرافاً خارجية. لا حاجز تشغيلي داخلي متبقٍّ (R17 محلولة، النواة مستقرة).
