# جرد وتوصيف جداول واجهات المستخدم الكاملة لإعادة التصميم عبر Stitch

يوثق هذا التقرير كافة الجداول وقوائم البيانات المعروضة في نظام **نما الطبي (Nama Medical ERP)**، بما يشمل الأعمدة، الفلاتر، حقول البحث، إجراءات الصفوف، والمشاكل البصرية التي تتطلب إعادة هيكلة وتصميم كامل في منصة Stitch.

---

## 1. جدول دليل المرضى (Patients Directory Table)

### الصفحة / Page
الاستقبال والتسجيل

### المسار / Route
`#reception`

### الملف / File
`namaweb/public/js/app.js` (الدوال `renderReception` و `renderPatientTable`)

### الوحدة / Module
Patient Administration

### المستخدمون / Roles
Receptionist, Cashier, Admin

### نوع المنشأة / Facility Types
جميع المستشفيات، المدن الطبية، المستوصفات، ومراكز الرعاية الأولية (من 1 إلى 7)

### الأعمدة / Columns
| Column | Meaning | Data type if known | Source | Notes |
|---|---|---|---|---|
| رقم الملف / File# | الرقم الطبي المتسلسل للمريض | INTEGER | `file_number` | مفتاح البحث الأساسي |
| الاسم / Name | اسم المريض الكامل (ثنائي اللغة) | TEXT | `name_ar` / `name_en` | يظهر بحسب لغة الواجهة النشطة |
| الهوية الوطنية / National ID | رقم الهوية الوطنية أو الإقامة | TEXT | `national_id` | مكون من 10 أرقام |
| الجوال / Phone | رقم هاتف المريض للاتصال | TEXT | `phone` | يبدأ بـ 05 |
| القسم / Department | العيادة أو القسم الطبي الحالي | TEXT | `department` | القسم المحال إليه المريض |
| الحالة / Status | حالة المريض بالعيادة حالياً | TEXT | `status` | Waiting, With Doctor, Done |
| الإجراءات / Actions | أزرار التفاعل السريع مع المريض | HTML | - | تعديل، فرز وتصنيف |

### الفلاتر / Filters
| Filter | Field | Type | Current issue | Redesign note |
|---|---|---|---|---|
| تصفية الحالة | `status` | Dropdown | لا توجد أيقونات توضح الحالات | تفعيل مؤشرات لونية مستديرة |
| تصفية القسم | `department` | Dropdown | يعرض جميع الأقسام دفعة واحدة | تقسيم بحسب الأقسام السريرية الكبرى |

### البحث / Search Fields
- البحث الشامل (بالاسم، الهوية الوطنية، رقم الجوال، أو رقم الملف الطبي).

### إجراءات الصف / Row Actions
| Action | Purpose | Current behavior | Redesign note |
|---|---|---|---|
| تعديل / Edit | تعديل بيانات المريض الشخصية | يفتح نافذة منبثقة (Modal) لنموذج كامل | تحويله إلى لوح جانبي منزلق (Drawer) أكثر حداثة |
| فرز / Triage | تصنيف حالة المريض (للقسم الطبي والتمريض) | يفتح نافذة فرز تحدد مستوى الألم والخطورة | تفعيل واجهة منزلقة تعتمد على درجات الفرز الملونة |

### الإجراءات الجماعية / Bulk Actions
- لا يوجد حالياً.

### خصائص الجدول
- **Pagination**: غير مفعل تلقائياً (يعرض أول 200 سجل تنازلياً).
- **Sorting**: غير مدعوم في الواجهة الحالية (مرتب بحسب تاريخ الإدخال التنازلي).
- **Export**: مدعوم تصدير الدليل كملف CSV بالكامل.
- **Print**: غير مدعوم بشكل مخصص للجدول ككل.
- **Column visibility**: غير مدعومة.
- **Row selection**: غير مدعومة.
- **Status badges**: مفعلة بشكل بسيط (أخضر لـ Done، برتقالي لـ Waiting).
