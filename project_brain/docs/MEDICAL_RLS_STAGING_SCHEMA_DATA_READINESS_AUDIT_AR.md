### 2. تدقيق التبعية وتكامل العلاقات (Integrity & Constraints Check)

* **خلو البيانات من اليتم التنظيمي (No Orphans)**: لا توجد أي صفوف معزولة أو يتيمة لا ترتبط بمعرف مستأجر حقيقي في قاعدة بيانات خادم الاستضافة (Staging).
* **توافق الجداول مع سياسة عزل المعاملات**: جميع مسارات الـ API في `server.js` الخاصة بهذه الجداول مهيأة بالكامل لفلترة البيانات واستخلاص الهويات تلقائياً مما يحافظ على عدم انكسار العلاقات السريرية تحت مظلة RLS.
* **سياسة حماية البيانات الحقيقية**: تم التأكد من عدم استخدام أو تخزين أي بيانات حقيقية لمرضى أو فواتير حقيقية في السجلات المفحوصة (جميع البيانات وهمية للاختبارات فقط).
