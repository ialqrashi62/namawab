# 21 — مخطط الذكاء الاصطناعي / RAG / الوكلاء (AI Blueprint)

> 2026-06-22 | Blueprint فقط — لا تكامل AI فعلي. ضوابط PHI صارمة. يُبنى فوق نمط العزل (RLS/tenant) القائم.

## 1-4 الهدف/النطاق/المنهجية
مساعد سريري/إداري يعزّز الإنتاجية دون المساس بخصوصية PHI أو عزل المستأجرين. كل استدعاء AI محصور بسياق المستأجر والدور.

## العناصر
| العنصر | التصميم |
|---|---|
| Prompt Engineering | قوالب مهام (تلخيص سجل، صياغة تقرير، ترميز ICD مقترح، أسئلة دوائية) بصيغة موجّهة |
| System Prompt | يحدّد الدور، حدود PHI، منع التشخيص القطعي، الالتزام بالعربية، إخلاء المسؤولية السريري |
| Context Strategy | حقن سياق محدود من سجل المريض الحالي فقط (tenant+patient scoped)، بلا تسريب عبر مرضى/مستأجرين |
| Workflow/Orchestration | طبقة وكيل تستدعي أدوات داخلية (قراءة سجل، بحث كتالوج) عبر API المصرّح بالدور |
| Chaining (LangChain-style) | retrieve→ground→generate→verify؛ خطوة تحقّق قبل العرض |
| Vector Search | فهرسة وثائق/سياسات/كتالوجات (غير PHI) في متجر متجهات؛ PHI لا يُفهرس خارج الحدود |
| Backend Logic | بوابة AI خلف requireAuth+requireRole+tenant؛ تسجيل كل استعلام في audit_trail |
| API integration | مزوّد LLM (مثل Claude) عبر خدمة وسيطة؛ مفاتيح في vault، لا تُطبع |
| Data & Storage | فصل متجر المتجهات عن PHI؛ تشفير؛ احتفاظ محدود |
| Vector Databases | pgvector (داخل Postgres) أو متجر خارجي معزول بالمستأجر |
| RAG architecture | استرجاع وثائق المنشأة/السياسات + سياق المريض المصرّح → توليد مؤطّر بمصادر |
| Frontend AI UX | مساعد جانبي/نافذة؛ يعرض المصدر؛ يميّز "مقترح AI" بوضوح؛ موافقة بشرية |
| Guardrails | منع PHI خارج السياق، منع قرارات سريرية ملزمة، فلترة مخرجات، حدود معدّل |
| Security/PHI controls | tenant+role scope لكل استدعاء، تسجيل تدقيق، عدم تخزين PHI في prompts خارجية، إخفاء هوية حيث أمكن |
| Testing AI outputs | تقييم دقّة/سلامة، اختبارات حقن، رفض الهلوسة، مراجعة بشرية للعيّنات |
| Monitoring/Eval | قياس جودة/كلفة/كمون، سجلّ استخدام، تنبيه على مخرجات شاذّة |

## حالات استخدام مقترحة (آمنة)
تلخيص سجل المريض للطبيب، اقتراح ترميز ICD/CPT (بمراجعة)، مساعد بحث في السياسات/الأدلة، صياغة تقارير/خطابات، مساعد إداري للتقارير. **بلا تشخيص قطعي أو قرار دوائي آلي**.
