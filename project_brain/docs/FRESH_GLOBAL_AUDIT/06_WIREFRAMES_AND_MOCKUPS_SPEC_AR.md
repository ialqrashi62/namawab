> 2026-06-22 | ≥25 شاشة. لكل شاشة: Purpose, Header, Sidebar, Cards, Tables, Filters, Forms, Buttons, Primary CTA, Secondary, Validation, Responsive, RTL, Empty/Error/Loading, Accessibility. بلا رسم صور (مواصفات نصية + ملاحظات Stitch design system القائم).

## معايير عامة (تنطبق على كل الشاشات)
- **RTL**: dir=rtl، lang=ar افتراضي، tr(en,ar) ثنائي اللغة. **Header**: شعار + اسم المنشأة + مستخدم + لغة + تنبيهات. **Sidebar**: قوائم حسب الدور + FACILITY_ALLOWED. **Responsive**: breakpoints موبايل/تابلت/سطح؛ sidebar collapsible. **States**: empty (رسالة + CTA)، error (toast + إعادة)، loading (skeleton). **A11y**: تباين WCAG AA، ARIA labels، تنقّل لوحة مفاتيح، حجم خط قابل للتكبير.
