## خطة الطرح (rollout، عند الموافقة)
1. **نسخة كاملة غير مشفّرة محفوظة بأمان** (شبكة أمان قبل أي تشفير).
2. full-disk encryption (مضيف DB/الخزنة) — أساس.
3. نقل ملفات PHI خارج public/ + مسار تنزيل محكوم + phi_files registry (rehearsed).
4. تشفير عمودي انتقائي + KMS (rehearsed: pgcrypto round-trip PASS).
5. تشفير النسخ + offsite + drill استعادة.
6. تدوير المفاتيح + retention + break-glass.
كل خطوة: backup → rehearse → نافذة منخفضة الحمل → validate → smoke → rollback جاهز.

## التحقّق/المراقبة
- validate: لا ملف PHI في public/؛ phi_files RLS؛ round-trip تشفير؛ drill استعادة نسخة مشفّرة.
- monitoring: تنبيه على فشل فك التشفير، وصول break-glass، فشل drill.

## موافقة المالك المطلوبة
DDL (phi_files/metadata) + تمكين pgcrypto + KMS + نقل الملفات + نشر مسار التنزيل = **بوابة موافقة صريحة** (`APPROVE_PHI_ENCRYPTION_VAULT_ROLLOUT`)، مع توفّر KMS/مفتاح خارج المستودع.
