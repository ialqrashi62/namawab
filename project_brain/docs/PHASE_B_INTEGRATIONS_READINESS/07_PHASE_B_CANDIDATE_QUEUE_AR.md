# Phase B — طابور المرشّحات (مرتّب بالأولوية والمخاطرة)

> Discovery فقط. لا تنفيذ. كل المرشّحات تبدأ بـ candidate ورقي ثم sandbox ثم بوابة موافقة مخصّصة.

|---|---|---|---|---|---|
| B0 | **نموذج الأسرار/المفتاح** (مشترك مع A3) | ممكّن لكل ما يحمل شهادة | منخفضة (إعداد) | قرار مالك (ملف/DPAPI/KMS) | **الممكّن الأول** |

## ترتيب منطقي موصى (بلا تنفيذ الآن)
1. **B0** نموذج الأسرار/المفتاح (يفكّ حجب الجميع، ويخدم A3 أيضاً).
2. **B1** تقييم محرّك تكامل (قرار معماري: داخل المونوليث أم خدمة منفصلة).
3. **B2** FHIR sandbox محلي (إثبات مفهوم بلا PHI، بلا اتصال خارجي).
4. ثم الأعلى قيمة تنظيمية: **B3 ZATCA Ph2** و**B4 NPHIES** (كلٌّ بوابة مخصّصة، بعد sandbox + شهادات).
5. **B5/B6** PACS/LIS/RIS حسب احتياج التشغيل.

## مبدأ
لا يُجمَع مرشّحان في بوابة واحدة. كل مرشّح: candidate ورقي → sandbox معزول (بلا PHI/بلا إنتاج) → backup/rehearsal → بوابة موافقة → تنفيذ محكوم → إغلاق. المحاسبة تبقى OFF، R17 لا تُمَسّ.
