## تفصيل فئات القرارات وأثرها الأمني

### 1. فئة التفعيل المباشر (ENABLE_NOW)
* **المفهوم**: جداول تشغيلية تتبع مستأجراً واحداً ومستعدة إنشائياً وبياناتياً.
* **الأثر**: تفعيل RLS يرفع عزل البيانات بنسبة 100% ويمنع أي تسرب للأسرة أو الأدوية الصيدلانية الخاصة بالعيادة.
* **الحالة في هذه المرحلة**: تم تأجيل التفعيل الفعلي إلى مرحلة التنفيذ (Batch 7) كإجراء أمني وقائي لضمان عدم كسر التطبيق.

### 2. فئة القراءة العامة المشتركة (SHARED_READ_ONLY)
* **المفهوم**: جداول مراجع طبية دولية موحدة.
* **الأثر**: قراءة عامة وآمنة، تمنع تكرار البيانات بين المنشآت الطبية، وتمنع تعديل الأكواد من غير المصرح لهم.

### 3. فئة جداول التخصيص المطلوبة (TENANT_OVERRIDE_REQUIRED)
* **المفهوم**: كتالوجات عامة تتطلب مرونة تسعير وخدمات مخصصة لكل منشأة.
* **الأثر**: منع تكرار 760 سطر فحوصات وأشعة لكل مستأجر، مع توفير عزل تام للأسعار المحددة.

### 4. فئة تعديل المخطط الهيكلي (SCHEMA_CHANGE_REQUIRED)
* **المفهوم**: جداول ذات حساسية عالية تفقد تماماً عمود هوية المستأجر.
* **الأثر**: تفعيل RLS عليها حالياً مستحيل تقنياً ويشكل خطراً أمنياً داهماً بفقدان البيانات. يتطلب هجرات وتعديل ملفات السورس.
