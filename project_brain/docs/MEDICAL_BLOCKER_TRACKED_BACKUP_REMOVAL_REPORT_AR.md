### 1. إجراءات فك الارتباط من فهرس Git (Git Index Removal)

تم تشغيل الأمر التالي لإلغاء تتبع الملف دون حذفه من القرص:
```bash
git rm --cached docs/sql/icu_nursing_backup.sql
```
* **النتيجة**: تم إدراج حذف الملف ضمن التغييرات المهيأة للالتزام (Staged changes for commit) بوضع `deleted`.

1. **معرفة الملفات المتتبعة (`git ls-files`)**:

2. **التحقق من التجاهل بالقوة (`git check-ignore`)**:

   * **النتيجة**: **PASS** (الملف يظهر كـ deleted staged، ولا يظهر كـ untracked or staged addition).
