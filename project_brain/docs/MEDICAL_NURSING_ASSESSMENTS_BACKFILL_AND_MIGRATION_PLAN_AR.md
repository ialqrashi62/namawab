# خطة تعبئة وتحديث البيانات التراكمية - موديول التقييمات التمريضية (Backfill and Migration Plan)
## نظام نما الطبي (NamaMedical) - بيئة Staging

يوثق هذا التقرير التفاصيل الفنية وخطة الهجرة وتعبئة حقول المستأجرين للبيانات الحالية لجدول التقييمات التمريضية `nursing_assessments` وتحديد المخاطر والتحققات المطلوبة لبيئة الإنتاج.

---

### 1. مصدر البيانات وقواعد التعبئة (Backfill Logic & Source of Truth)

عند بدء مرحلة التنفيذ الفعلي، سيتم استنباط وتوطين الحقول الجديدة بناءً على القواعد التالية:
* **مصدر معرّف المستأجر (`tenant_id`)**: جدول المرضى `patients`.
* **سكربت التحديث وتعبئة البيانات (Backfill SQL)**:
  ```sql
  -- تحديث السجلات الحالية استناداً لمعرّف المريض المرتبط بها
  UPDATE nursing_assessments a
  SET tenant_id = p.tenant_id,
      facility_id = p.facility_id
  FROM patients p
  WHERE a.patient_id = p.id;
  ```

---

### 2. معالجة الحالات الشاذة والمتعارضة (Exception & Mismatch Handling)

لضمان سلامة الهجرة وعدم حدوث أي تشوهات بالبيانات:
1. **التحقق من وجود حقول NULL بعد التعبئة**:
   في حال وجود سجلات تقييم ممررة بدون مريض صالح أو يتيم، سيتم كشفها بالاستعلام التالي:
   ```sql
   SELECT COUNT(*) FROM nursing_assessments WHERE tenant_id IS NULL;
   ```
   * **الإجراء**: إذا كان العدد أكبر من صفر، يمنع إضافة قيد `NOT NULL` ويتم معالجة السجلات اليتيمة يدوياً أو ربطها بالمنشأة الافتراضية.
2. **التحقق من تطابق مستأجر المريض**:
   يتم التحقق من عدم وجود أي تباين في السياقات الأمنية للبيانات.

---

### 3. خطة التراجع وجاهزية الإنتاج (Rollback & Production Readiness Gap)

* **خطة التراجع (Rollback Plan)**:
  - استعادة نسخة ما قبل الهجرة المأخوذة للجداول المتأثرة باستخدام SQL Dump.
  - التراجع البرمجي عن أي تعديلات في نهايات API الويب.
* **فجوة جاهزية بيئة الإنتاج**:
  تبقى الجاهزية للإنتاج مصنفة كـ **PRODUCTION_READY: NO** للأسباب التالية:
  - لم يتم تطبيق التعديل الهيكلي (DDL) أو تعبئة البيانات فعلياً على Staging بعد، ويجب تفعيلها وفحصها تحت ضغط التشغيل أولاً.
  - يتطلب الإنتاج مراجعة وحوكمة مع منسقي قواعد البيانات الطبيين للتأكد من عدم وجود سجلات مريضة يتيمة قد تنعزل أو تختفي عن الأطباء والممرضين فجأة بعد تفعيل RLS.
