# Admin Onboarding (Facility IT/Quality/HR Admin)
v1.0

## Prerequisites
- Account provisioned with `facility_admin` role.
- Familiar with facility's existing HR/Finance/PACS/LIS systems.

## Day 1 — Settings & users
- [ ] Login + 2FA setup
- [ ] Tour Settings → Branches, Roles, Privileges
- [ ] Add a test user; assign role
- [ ] Configure SCIM connector (HR feed → IdP)

## Day 2 — Departments & order sets
- [ ] Enable departments per facility scope
- [ ] Review/approve Order Sets with clinical leads
- [ ] Tune CDS rule thresholds (alert fatigue review)
- [ ] Configure shift schedules + on-call rosters

## Day 3 — Integrations
- [ ] Verify NPHIES + Wasfaty + Mawid + Sehhaty + Yaqeen + ZATCA + Shahm dashboards
- [ ] Test claim, prescription, appointment, identity check
- [ ] Confirm PACS + LIS interfaces

## Day 4 — Quality & Audit
- [ ] Tour Quality module (CBAHI evidence + KPI dashboards)
- [ ] Configure incident categories (OVR)
- [ ] Set credentialing renewal alerts
- [ ] Review audit log access

## Day 5 — Patient experience & support
- [ ] Configure patient portal branding
- [ ] Set complaint SLA + routing
- [ ] Test in-app help bot
- [ ] Set support escalation list

## Ongoing duties
- Weekly: review user requests, training compliance
- Monthly: KPI review with leadership; CAPA tracker
- Quarterly: CBAHI mock survey; risk register update
- Annually: pen-test review; policy refresh
