#### ب. الجداول المؤجلة لتعقيد العلاقات أو حاجة التطبيق (DEFERRED_NEEDS_BACKFILL_OR_WRAPPER):
1. **pharmacy_drug_catalog** (90 صفاً): جدول يحتوي على كتالوج الأدوية لـ tenant_id=1. يؤجل لتفادي مشاكل عزل المبيعات وحركات المخزون المعقدة.

1. **medications**, **lab_samples**: لا تحتوي على عمود `tenant_id`.
2. **lab_tests_catalog**, **radiology_catalog**: كتالوجات عامة مشتركة لجميع المستأجرين ويجب أن تظل عامة للوصول.

### 2. تدقيق أثر طبقة الاتصال ونهايات API

* **طريقة الاتصال الحالية**: يتصل التطبيق بنسخة PostgreSQL في بيئة Staging كمالك لقاعدة البيانات `postgres` (Superuser)، وبالتالي لن تتأثر نهايات API التشغيلية وسير العمل في لوحة التحكم بأي خلل أثناء الاستخدام الاعتيادي، حيث تتجاوز حسابات المشرفين الكبار RLS تلقائياً.
* **سيناريو الفحص المقيد**: يتم إنشاء دور اختبار مقيد (`test_rls_user`) لإجراء التحقق من سياسات العزل الأمنية والتأكد من سلامة منع التداخل بين مستأجري النظام.
