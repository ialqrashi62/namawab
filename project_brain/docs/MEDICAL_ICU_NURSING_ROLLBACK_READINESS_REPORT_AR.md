# تقرير جاهزية الرجوع للعناية والتمريض - الدفعة الرابعة (ICU & Nursing Rollback Readiness Report)
## نظام نما الطبي (NamaMedical) - بيئة Staging

يوثق هذا التقرير الخطط والسكربتات والإجراءات الفورية اللازمة للتراجع عن التغييرات البرمجية أو الهيكلية في حال حدوث أي خلل أمني أو تشغيلي في مسارات الدفعة الرابعة.

---

### 1. إجراءات التراجع البرمجي (Code Rollback Procedures)

في حال استدعت الحاجة التراجع عن التعديلات المطبقة في الخادم `namaweb/server.js`:
* **أمر التراجع الفوري**:
  ```bash
  git checkout -- server.js
  ```
  أو من خلال سحب آخر نسخة مستقرة وملتزمة:
  ```bash
  git restore server.js
  ```
* **التحقق من التراجع البرمجي**: إعادة تشغيل خادم Express والتحقق من عودة الواجهات والاستجابات لوضعها السابق، وتشغيل اختبارات الانحدار للتأكد من السلامة التامة.

---

### 2. إجراءات التراجع عن هيكل قاعدة البيانات وسياسات الـ RLS (Database Rollback)

إذا تطلب الأمر التراجع عن سياسات الـ RLS أو الفهارس المضافة حديثاً على جداول العناية والتمريض الثمانية:
* **الأمر التنفيذي المباشر**:
  يتم تشغيل السكربت المخصص للتراجع عن الـ RLS باستخدام أداة `psql` (الموجودة محلياً في مسار PostgreSQL 16):
  ```powershell
  $env:PGPASSWORD="postgres"
  & "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -d nama_medical_web -f ./docs/sql/icu_nursing_rls_down.sql
  ```
* **ملف سكربت التراجع**: [icu_nursing_rls_down.sql](./sql/icu_nursing_rls_down.sql).
* **إجراءات الاستعادة الكاملة للبيانات**:
  في حالة حدوث تشوهات بالبيانات، يمكن استرجاع حالة الجداول الثمانية تماماً لما قبل البدء باستخدام ملف النسخة الاحتياطية المأخوذ في البوابة 2:
  * **ملف النسخة الاحتياطية**: [icu_nursing_backup.sql](./sql/icu_nursing_backup.sql).
  * **أمر الاستعادة**:
    ```powershell
    $env:PGPASSWORD="postgres"
    & "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -d nama_medical_web -f ./docs/sql/icu_nursing_backup.sql
    ```
