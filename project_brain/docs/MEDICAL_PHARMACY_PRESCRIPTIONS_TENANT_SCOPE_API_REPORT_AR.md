## 4. مسارات الصيدلية التي تم حمايتها

تم تأمين العمليات الحساسة عبر المسارات التالية:

1. `GET /api/prescriptions` — عرض الوصفات الطبية (تصفية بـ `tenant_id` + منع IDOR عند طلب مريض محدد).
2. `POST /api/prescriptions` (مسارين) — إنشاء وصفة طبية (التحقق من المريض وختم `tenant_id` / `facility_id`).
3. `GET /api/pharmacy/queue` (مسارين) — عرض طابور صرف الأدوية في الصيدلية (تصفية بـ `tenant_id`).
4. `PUT /api/pharmacy/queue/:id` (مسارين) — صرف الدواء وتحديث الحالة (التحقق من ملكية الطلب ومنع صرف أدوية مستأجر آخر، مع ختم المستأجر والمنشأة على الفاتورة المصاحبة).
5. `GET /api/pharmacy/drugs` (مسارين) — عرض كتالوج أدوية الصيدلية (تصفية بـ `tenant_id`).
6. `POST /api/pharmacy/drugs` (مسارين) — إضافة دواء للكتالوج (ختم `tenant_id` و `branch_id`).
7. `GET /api/pharmacy/low-stock` — تنبيهات نقص كميات الأدوية (تصفية بـ `tenant_id`).
8. `GET /api/pharmacy/expiring` — تنبيهات الأدوية قاربة الانتهاء (تصفية بـ `tenant_id`).
9. `POST /api/pharmacy/deduct-stock` — خصم المخزون عند الصرف (التحقق من تبعية المريض والدواء والوصفة لـ `tenant_id`).
10. `GET /api/pharmacy/stock-log` — سجل حركات مخزون الأدوية (تصفية وعزل البيانات عبر JOIN مع كتالوج الأدوية دون الحاجة لتعديل هيكل الجدول).
11. `GET /api/print/prescription/:id` — طباعة وصفة طبية محددة (التحقق من ملكية الوصفة لمنع IDOR).
12. `GET /api/pharmacy/prescriptions` — عرض وصفات الصيدلية الديناميكية (تصفية بـ `tenant_id` مع تفعيل الـ ALTER التلقائي لإضافة الحقول).
13. `POST /api/pharmacy/prescriptions` — إضافة وصفة ديناميكية (التحقق من المريض وختم الهوية).
14. `PUT /api/pharmacy/prescriptions/:id` — تحديث حالة وصفة ديناميكية (التحقق من الملكية لمنع IDOR).

```javascript
const { tenantId } = getRequestTenantContext(req);
if (tenantId && patient_id) {
    const patientCheck = (await pool.query('SELECT id FROM patients WHERE id=$1 AND tenant_id=$2', [patient_id, tenantId])).rows[0];
    if (!patientCheck) return res.status(404).json({ error: 'Patient not found' });
}
```

### ب. فلترة سجل حركات مخزن الأدوية دون تعديل الجدول (JOIN Filtering)
```javascript
const { tenantId } = getRequestTenantContext(req);
const query = tenantId ?
    `SELECT sl.* FROM pharmacy_stock_log sl 
     JOIN pharmacy_drug_catalog dc ON sl.drug_id = dc.id 
     WHERE dc.tenant_id = $1 
     ORDER BY sl.created_at DESC LIMIT 200` :
    `SELECT * FROM pharmacy_stock_log ORDER BY created_at DESC LIMIT 200`;
```
