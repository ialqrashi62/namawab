# التدقيق العالمي 09 — جاهزية الامتثال الصحي (Healthcare Compliance Readiness)

> التاريخ: 2026-06-20 | المرجع: HIPAA-like، توقعات الصحة السعودية، NPHIES، HL7/FHIR، ICD-10، SNOMED، LOINC، DICOM، CBAHI.

## جدول الجاهزية

| المعيار | الموجود | الناقص | إلزامي/اختياري | مطلوب قبل البيع لمستشفى كبير؟ |
| ------- | ------- | ------ | -------------- | ----------------------------- |
| **خصوصية HIPAA-like** | تجزئة bcrypt، RBAC، audit_trail، عزل مستأجرين، HTTPS، least-privilege DB | تشفير at-rest موثّق، سياسة احتفاظ، BAA، فصل بيانات كامل (فجوة Gate 5) | إلزامي | **نعم** |
| **سجل تدقيق (Audit Trail)** | جدول audit_trail + logAudit واسع | old_values ناقص، حذف غير مُدقّق، لا حماية tamper-proof | إلزامي | نعم |
| **إدارة الموافقات (Consent)** | موديول consent-forms + قوالب + توقيع | توقيع رقمي معتمد (PKI)، حجية قانونية | إلزامي | نعم |
| **سجلات الوصول (Access Logs)** | last_ip + audit login | تتبع وصول لكل سجل مريض (who accessed what) | إلزامي | نعم |
| **ICD-10** | جدول `icd10_codes` + medical-records/coding | محرك ترميز كامل، تحديث دوري | إلزامي | نعم |
| **SNOMED CT** | غير موجود | الترميز السريري الموحّد | اختياري (مفضّل) | لا (مفضّل) |
| **LOINC (مختبر)** | غير موجود | ترميز نتائج المختبر | اختياري/مطلوب للتبادل | جزئياً |
| **DICOM/PACS (أشعة)** | تخزين ملفات فقط | DICOM فعلي + عارض + PACS | إلزامي لقسم أشعة جاد | نعم |
| **HL7 v2 / FHIR** | غير موجود | تبادل بيانات صحية معياري | إلزامي للتكامل المؤسسي | نعم |
| **NPHIES (السعودية)** | غير موجود | التأمين/المطالبات الموحّد الوطني | إلزامي للتأمين السعودي | **نعم** |
| **ZATCA (الفوترة)** | QR محلي فقط | توقيع + تقديم Phase 2 معتمد | إلزامي نظامياً (السعودية) | **نعم** |
| **CBAHI (تشغيلي)** | موديولات الجودة/مكافحة العدوى/الحوادث موجودة | مطابقة معايير CBAHI الموثّقة | إلزامي للاعتماد السعودي | نعم |
| **سياسة الاحتفاظ بالبيانات** | لا soft-delete، حذف صلب | retention + أرشفة | إلزامي | نعم |
| **إدارة الهوية (IdP/SSO)** | جلسات داخلية فقط | SAML/OIDC، MFA | مطلوب مؤسسياً | نعم |

## التحليل

### ما هو قوي بالفعل
- البنية التحتية للخصوصية (RBAC، عزل، تجزئة، HTTPS، least-privilege، audit) **أساس امتثال صلب**.
- وجود موديولات الجودة ومكافحة العدوى والحوادث ورضا المرضى يدعم متطلبات CBAHI التشغيلية.
- ICD-10 + الموافقات + السجلات الطبية موجودة كأساس.

### أخطر الفجوات الامتثالية (إلزامية قبل مستشفى كبير سعودي)
1. **NPHIES** — لا تكامل تأمين/مطالبات وطني. حاجز تجاري في السوق السعودي.
2. **ZATCA Phase 2** — لا توقيع/تقديم معتمد؛ QR محلي فقط. إلزام نظامي.
3. **HL7/FHIR** — لا تبادل بيانات معياري؛ يمنع التكامل المؤسسي.
4. **DICOM/PACS فعلي** — قسم أشعة بلا معيار صور.
5. **فصل البيانات الكامل** — فجوة عزل الموديولات الحديثة (Gate 5) تنتهك خصوصية المريض في سياق متعدد المستأجرين.
6. **تتبع الوصول لكل سجل + tamper-proof audit + retention**.
