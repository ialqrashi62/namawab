# التدقيق العالمي 03 — تحليل فجوات تجربة المستخدم والواجهة (UX/UI Gap Analysis)

> التاريخ: 2026-06-20 | المرجع: Epic Hyperspace، Cerner PowerChart، Athenahealth، واجهات SaaS حديثة.

---

## 1. ملخص الواجهة

- **النمط**: تطبيق صفحة واحدة (SPA) بـ Vanilla JS — `app.js` بـ 10,884 سطراً، `index.html` قشرة 95 سطراً.
- **التوطين**: عربي/إنجليزي كامل مع `dir=rtl/ltr` وتبديل لغة محفوظ في `localStorage` (`namaLang`)، ودالة `tr(en, ar)` للترجمة الفورية.
- **التصميم**: نظام "Stitch Premium" بـ 8 ثيمات (4 داكنة + 4 فاتحة)، glassmorphism وتأثيرات Neon Glow، خط IBM Plex Sans Arabic، متغيرات CSS، `styles.css` بـ 1,686 سطراً.
- **التكيّف حسب نوع المنشأة**: `FACILITY_ALLOWED` يخفي الموديولات غير المناسبة (عيادة/مركز صحي/مستشفى).
- **RBAC في الواجهة**: القائمة تتكيّف مع صلاحيات المستخدم؛ لوحة إدارة مستقلة (`admin.html`) للمدير فقط.

## 3. مشاكل UX الحرجة (P1)

| المشكلة | الأثر | الدليل | الإصلاح |
| ------- | ----- | ------ | ------- |
| **غياب ARIA/إتاحة الوصول (Accessibility)** | غير متوافق مع WCAG 2.1 AA؛ يُفشل متطلبات الشراء الحكومي/المؤسسي | لا `aria-label`/`role`/`alt` في HTML | إضافة سمات ARIA، `<dialog>` للنوافذ، نص بديل، skip links |
| **البحث العام مخفي على الموبايل** (≤768px) | فقدان اكتشاف وظيفة جوهرية على الأجهزة الصغيرة | `styles.css` media query | إظهار بحث مصغّر/أيقونة بحث على الموبايل |
| **لا تجميع/تثبيت للتركيز (focus trap) في النوافذ** | التركيز يهرب خلف النافذة — مشكلة إتاحة + استخدام | نوافذ `<div>` لا `<dialog>` | focus trap + إغلاق بـ ESC |
| **لا ترقيم صفحات (pagination) ظاهر** | تحميل آلاف الصفوف يبطئ الأداء ويربك المستخدم | جداول `makeTable` | pagination + lazy loading + حد صفوف |

## 4. مشاكل التصميم/التجربة المتوسطة (P2)

| المشكلة | الأثر | الإصلاح |
| ------- | ----- | ------- |
| التحقق من النماذج كـ toast فقط | لا رسائل خطأ سطرية بجانب الحقل | inline validation messages |
| اختصارات لوحة المفاتيح (Alt+1-9) غير موثّقة | مستخدمون لا يعرفونها | بطاقة اختصارات + توثيق |
| لا تحديث لحظي (real-time) | الإحصائيات/الطوابير تتطلب تحديثاً يدوياً | WebSocket/polling للوحات الحرجة (طوارئ/طابور) |
| لا عمليات جماعية (bulk actions) | لا تحديد متعدد/حذف جماعي | multi-select على الجداول |
| تصدير محدود (CSV) | لا Excel/PDF موقّع/HL7 | خيارات تصدير متعددة |
| لا undo/تأكيد للعمليات الحساسة | أخطاء دائمة | حوارات تأكيد + سجل تراجع |

## 5. تجربة الأدوار المختلفة

| الدور | التجربة الحالية | الفجوة مقابل العالمي |
| ----- | --------------- | -------------------- |
| الطبيب | محطة طبيب + طابور + next-patient | جيدة؛ تنقص دعم قرار سريري (CDS) ولوحة مهام موحدة |
| الاستقبال | استقبال + مواعيد + انتظار | جيدة جداً |
| التمريض | تمريض + علامات حيوية + ICU + رعاية | قوية؛ تنقص تكامل أجهزة المراقبة |
| الإدارة | لوحات تنفيذية + تقارير + صلاحيات | جيدة؛ تنقص تحليلات تفاعلية حديثة |
| مالك SaaS | **لا توجد تجربة مخصصة** | فجوة كبيرة — لا control center للمستأجرين (انظر Gate 11) |

## 6. توصيات واجهة عالمية

**Quick Wins (جهد منخفض، أثر عالٍ)**:
1. إعادة البحث على الموبايل.
2. إضافة سمات ARIA الأساسية + alt للصور + focus trap للنوافذ.
3. توثيق اختصارات لوحة المفاتيح في الواجهة.
4. رسائل تحقق سطرية للنماذج.
5. حوارات تأكيد للحذف/العمليات المالية الحساسة.

**Deep Redesign (جهد عالٍ)**:
1. ترقيم صفحات + تحميل كسول لكل الجداول الكبيرة.
2. تحديث لحظي (WebSocket) للوحات الطوارئ والطابور وICU.
3. لوحة مهام موحّدة للطبيب (Inbox/Worklist) بنمط Epic.
4. تحليلات تفاعلية (drill-down dashboards).
5. control center منفصل لمالك SaaS.
