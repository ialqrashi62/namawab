# خطة فحص وتمرين استعادة قاعدة بيانات الإنتاج (Database Backup & Recovery Validation Plan)
## نظام نما الطبي (NamaMedical) - خطة الحماية والتعافي السريع لقاعدة البيانات

يوثق هذا التقرير خطة أخذ وتدقيق والتحقق من النسخ الاحتياطية لقاعدة بيانات الإنتاج وسيناريوهات استعادة البيانات الفورية لضمان التعافي السريع وعدم فقدان البيانات الحساسة للمرضى.

---

## 1. استراتيجية النسخ الاحتياطي التلقائي (Database Backup Plan)

- **نوع النسخ الاحتياطي**: نسخ احتياطي كامل لقاعدة البيانات في صيغة مخصصة مضغوطة (`Custom Format -F c`) باستخدام أداة `pg_dump`.
- **مواقع الحفظ الآمن**:
  - حفظ نسخة احتياطية محلية مشفرة في مجلد معزول على الخادم لا يدخل ضمن تتبع الـ Git (مجلد `local_backups/` أو `/var/backups/db/`).
  - نقل تلقائي وفوري للنسخة الاحتياطية إلى وحدة تخزين خارجية معزولة (خادم تخزين سحابي مؤمن أو خادم ملفات معزول بالشبكة الداخلية للمنشأة).
- **جدولة النسخ**: جدولة دورية وتلقائية للنسخ الاحتياطي بمعدل مرة كل ساعة للجداول التشغيلية الحية، ونسخ كامل مرتين يومياً.

---

## 2. تمرين محاكاة الاستعادة والفحص (Recovery & Restore Drill Plan)

لضمان سلامة وصلاحية ملفات النسخ الاحتياطي (حيث لا يمكن الاعتماد على ملف نسخ احتياطي دون تجربة استعادته):
1. **قاعدة بيانات معزولة للاختبار**: توفير قاعدة بيانات تجريبية مؤقتة (مثال: `nama_medical_restore_drill`) على خادم الاختبار.
2. **أوامر الاستعادة التجريبية**:
   ```bash
   # إنشاء قاعدة اختبار فارغة
   createdb -U postgres nama_medical_restore_drill
   
   # استعادة ملف النسخة الاحتياطية الأخير
   pg_restore -U postgres -d nama_medical_restore_drill --clean --verbose /var/backups/db/nama_medical_prod_before_cutover.bak
   ```
3. **التحقق من سلامة البنية**: فحص قاعدة البيانات المستعادة للتأكد من اكتمال استعادة كافة الجداول الـ 148 وصحة العلاقات والمفاتيح الخارجية والسياسات الأمنية للـ RLS.

---

## 3. التحقق من مطابقة الأمان للنسخة الاحتياطية (Backup Security Verification)

- **تجاهل الأمني في Git**: التأكد من استبعاد كافة ملفات النسخ الاحتياطي (ذات الامتدادات `.bak` أو `.sql` أو `.tar`) تماماً من مستودع الكود عبر تحديث شروط الاستبعاد بملف `.gitignore`.
- **سلامة بيانات المرضى**: التأكد من أن جميع ملفات النسخ الاحتياطي مشفرة أثناء النقل والتخزين لحماية سرية البيانات والامتثال للمعايير والأنظمة الصحية.
- **تحديد الصلاحيات**: تقييد صلاحيات قراءة واستعادة ملفات النسخ الاحتياطي لتقتصر فقط على حسابات كبار المهندسين والمسؤولين المخولين أمنياً.
