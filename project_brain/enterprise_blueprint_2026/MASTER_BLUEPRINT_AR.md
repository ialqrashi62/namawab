# المخطط المؤسسي الشامل 2026 (Enterprise Blueprint 2026)
## نظام إدارة المستشفيات الذكي - NamaMedical ERP

هذا المستند هو "المصدر الوحيد للحقيقة" (Single Source of Truth) لعملية التوسع الشاملة للمنصة. يتم تطبيق منهجية **Loop Engineering** لضمان جودة كل وحدة.

### 1. مصفوفة الأقسام والوحدات (Departmental Matrix)
يتم تقسيم النظام إلى 10 مسارات عمل رئيسية (Workstreams):
- **المسار A:** الباطنية والتخصصات الدقيقة.
- **المسار B:** الجراحات التخصصية.
- **المسار C:** النساء والتوليد والأطفال.
- **المسار D:** التشخيص المتقدم والأشعة والمختبرات.
- **المسار E:** العناية المركزة والطوارئ وإدارة الألم.
- **المسار F:** التأهيل والخدمات العلاجية المساندة.
- **المسار G:** الخدمات اللوجستية والتمريضية.
- **المسار H:** الإدارة التنفيذية والجودة والاعتماد.
- **المسار I:** التعليم والبحث العلمي والموارد البشرية.
- **المسار J:** المراكز المتخصصة والأقسام النادرة.

### 2. معايير التنفيذ لكل قسم (The Execution Standard)
لكل قسم يتم إنشاؤه، يجب استيفاء "حلقة الهندسة" (Engineering Loop) التالية:

#### أ. طبقة الذكاء الاصطناعي (AI Layer)
- [ ] **Prompt Engineering:** تصميم System Prompt متخصص لكل تخصص.
- [ ] **Context Design:** تحديد سياق البيانات المطلوبة للـ LLM.
- [ ] **RAG Pipeline:** ربط القسم بقاعدة بيانات متجهة (VectorMine) تحتوي على البروتوكولات الطبية العالمية.
- [ ] **LangChain Orchestration:** بناء سلاسل (Chains) للتشخيص والعلاج.

#### ب. البنية التحتية والبيانات (Data & Backend)
- [ ] **ERD Extension:** إضافة الجداول المتخصصة للقسم.
- [ ] **API Specs:** تعريف OpenAPI لجميع العمليات.
- [ ] **Business Flow:** رسم تدفق البيانات من الدخول حتى الخروج.
- [ ] **Migration Scripts:** سكربتات التحديث (Up/Down).

#### ج. تجربة المستخدم والواجهات (UI/UX)
- [ ] **Wireframes:** نماذج أولية للشاشات التخصصية.
- [ ] **Stitch Design System:** تطبيق الهوية البصرية الموحدة.
- [ ] **i18n:** تعريب كامل للمصطلحات الطبية الدقيقة.

#### د. الجودة والأمان (QA & Security)
- [ ] **Unit/Integration Tests:** اختبارات شاملة للمنطق الطبي.
- [ ] **RBAC:** تحديد صلاحيات الوصول الدقيقة.
- [ ] **Compliance:** مطابقة معايير ZATCA, NPHIES, CBAHI.
