# مهارة سيناريوهات واستراتيجية الاختبار (Test Scenarios & Coverage)

## Purpose
توليد استراتيجية اختبار ومصفوفة تغطية: وحدوي، تكامل، API، E2E، دخان، عزل مستأجرين، استحقاقات منشآت، سير سريري، مخزون صيدلية، مختبر، أشعة، ترحيل محاسبي، فوترة تأمين، أمن، انحدار.

## When to Use
عند تدقيق الجودة أو تصميم تغطية الاختبارات أو سدّ فجوة P0 باختبارات عزل.

## Inputs Needed
ملفات `cross_tenant_*.js`، `e2e_local_smoke_test.js`، جرد الموديولات.

## Procedure
1. حصر الاختبارات الموجودة (نمطها: static audit + simulation، تعمل بلا DB).
2. لكل موديول حرج: حدّد السيناريو الحرج، الاختبار الموجود/الناقص، الأولوية.
3. أنشئ اختبارات عزل جديدة بنفس النمط (`cross_tenant_<wave>_test.js`) تثبت: A لا يرى B؛ create يختم tenant؛ update/delete عابر ممنوع؛ بلا سياق → 401/403؛ app user لا يتجاوز RLS.
4. شغّل الانحدار: كل `cross_tenant_*` يجب أن تنتهي exit 0 + `node --check`.

## Safety Rules
لا اختبارات تكتب على الإنتاج. الاختبارات محلية/staging. لا تعتبر فشلاً نجاحاً.

## Output Format
`docs/MEDICAL_TESTING_COVERAGE_AUDIT_AR.md` — مصفوفة: الموديول | السيناريو الحرج | اختبار موجود | اختبار ناقص | الأولوية.

## Done Criteria
مصفوفة التغطية مكتملة، الاختبارات الحرجة الناقصة مُحدّدة، الانحدار يمرّ.
