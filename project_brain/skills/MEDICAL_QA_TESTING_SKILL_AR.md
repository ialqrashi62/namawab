# MEDICAL_QA_TESTING_SKILL_AR

## الهدف
إنشاء سيناريوهات اختبار شاملة للنظام الطبي.

## أنواع الاختبارات
- Unit tests
- Integration tests
- API tests
- Permission tests
- Workflow tests
- Browser/E2E tests
- Security checks
- Regression tests
- Smoke tests

## سيناريوهات أساسية
لكل وحدة افحص:
- فتح الصفحة
- عرض البيانات
- البحث والتصفية
- إنشاء سجل
- تعديل سجل
- حذف/تعطيل إن وجد
- صلاحيات الوصول
- أخطاء الإدخال
- حالات عدم وجود بيانات
- API success
- API failure
- Audit log إن وجد

## وحدات ذات أولوية
- المرضى
- المواعيد
- الملف الطبي
- الفوترة
- التأمين
- المختبر
- الأشعة
- الصيدلية
- الصلاحيات
- التقارير
- Dashboard
- Tenant isolation

## قاعدة مهمة
لا تعتبر المرحلة مكتملة إلا إذا:
- تم إنشاء تقرير اختبار
- تم توثيق ما تم اختباره
- تم توثيق ما لم يتم اختباره
- تم توثيق المخاطر المتبقية
- تم تحديد المرحلة التالية
