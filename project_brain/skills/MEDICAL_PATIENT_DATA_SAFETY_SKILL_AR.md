# MEDICAL_PATIENT_DATA_SAFETY_SKILL_AR

## الهدف
حماية سرية وسلامة بيانات المرضى في نظام نما الطبي ومنع أي تسريب متقاطع للبيانات بين المستأجرين (Cross-Tenant Data Leak) والالتزام بأعلى معايير الخصوصية الصحية.

## القواعد الأساسية
- **حظر البيانات الحقيقية**: يُمنع منعاً باتاً استخدام أسماء أو هويات أو أرقام هواتف أو سجلات طبية لمرضى حقيقيين في بيئات التطوير والاختبار والاستباقية (Staging).
- **توليد بيانات وهمية**: يجب استخدام بيانات وهمية 100% تم إنشاؤها خصيصاً لأغراض الفحص والاختبار التقني.
- **تأكيد العزل التام**: التحقق المستمر من أن استعلامات جلب وتعديل بيانات المرضى تمر دائماً عبر محدد هوية المستأجر (`tenant_id` و `facility_id`).
- **حجب الـ IDOR**: منع ثغرات التلاعب بالمعرفات (Insecure Direct Object Reference) عن طريق التحقق من ملكية السجل والمريض للمستأجر الحالي قبل تقديم البيانات في أي واجهة أو API.

## سيناريوهات التطبيق
- عند تصميم واجهات استقبال المرضى.
- عند كتابة وحقن بيانات الاختبار الافتراضية (Seed Data).
- عند فحص استدعاءات API الخاصة بالملف الطبي للمريض.
