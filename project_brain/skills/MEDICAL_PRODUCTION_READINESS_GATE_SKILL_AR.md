# MEDICAL_PRODUCTION_READINESS_GATE_SKILL_AR

## الهدف
وضع المعايير والبوابات التقنية والأمنية (Quality Gates) الواجب اجتيازها بالكامل قبل إعلان جاهزية النظام للتشغيل الإنتاجي الفعلي (Production Promotion).

## القواعد الأساسية
- **تفعيل RLS الكامل**: يجب أن تكون كافة جداول المعاملات السريرية والمالية والتشغيلية محمية ومفعلة بـ RLS بنسبة 100% على بيئة Staging.
- **تشفير HTTPS وترويس الأمان**: التأكد من فاعلية شهادات SSL الأمنية وتفعيل كامل ترويسات حماية الويب (HSTS, CSP, X-Frame-Options) وتأمين الكوكيز.
- **نجاح اختبارات الدخان بنسبة 100%**: اجتياز كامل اختبارات الدخان المؤتمتة محلياً وخارجياً دون أي إخفاق.
- **مراجعة النظافة الأمنية للنسخة (Clean Commit)**: خلو مستودع Git والفرع النشط من أي ملفات تهيئة مؤقتة، أو كلمات مرور، أو مفاتيح، أو ملفات بيئية (.env).
- **التفويض والاعتماد الرسمي**: إعداد تقرير الجاهزية الأمنية النهائي وتقديمه للإدارة للحصول على الاعتماد الصريح قبل النشر الفعلي.

## سيناريوهات التطبيق
- عند إنهاء كافة دفعات RLS التدريجية والتحضير للنشر الإنتاجي.
- عند إعداد تقارير التقييم الأمني والامتثال النهائي.
