# مهارة تدقيق سير عمل السجل الطبي الإلكتروني (EMR/EHR Workflow Audit)

## Purpose
تدقيق المسارات السريرية: الـ encounter، ملاحظات الطبيب/التمريض، العلامات الحيوية، التشخيص، الحساسية، أوامر الأدوية/المختبر/الأشعة، خطط العلاج، التقارير، ملخص الخروج، سجل التدقيق السريري، وعدم قابلية التعديل/التصحيح.

## When to Use
عند تدقيق الوحدات السريرية (محطة الطبيب، التمريض، السجلات الطبية).

## Inputs Needed
مسارات `/api/medical/*`, `/api/nursing/*`, `/api/medical-records/*`؛ نماذج encounters/medical_records/prescriptions.

## Procedure
1. تتبّع فتح الـ encounter → التوثيق → الإغلاق.
2. افحص ربط التشخيص بـ ICD-10 والحساسية وفحص التداخل الدوائي.
3. تحقّق من سجل التدقيق وعدم قابلية تعديل السجلات النهائية (تصحيح بإصدار جديد لا استبدال صامت).
4. عزل tenant + منع IDOR في كل مسار سريري.

## Safety Rules
قراءة فقط. السجلات السريرية النهائية يجب ألا تُعدَّل صامتاً. لا بيانات مرضى حقيقية في التقارير.

## Output Format
نتائج سير العمل السريري + سيناريوهات + تدفّقات + مخاطر سريرية ضمن تقارير السيناريوهات/المنطق/المخاطر.

## Done Criteria
كل مسار سريري موثّق بحالته (مكتمل/ناقص)، مخاطر السلامة السريرية مُحدّدة، اختبارات مطلوبة.
