# مهارة تدقيق تجربة وواجهة المستخدم (UX/UI Audit)

## Purpose
تدقيق جودة UX/UI: المصطلحات العربية/الإنجليزية، RTL/LTR، تجارب الأدوار (استقبال/طبيب/تمريض/صيدلية/مختبر/أشعة/محاسبة/مخزون/إدارة/onboarding)، جودة لوحات التحكم، النماذج، الجداول، الفلاتر، البحث، الحالات الفارغة/التحميل، رسائل الخطأ، حوارات التأكيد، الاستجابة، الإتاحة (WCAG)، اللمسة المؤسسية.

## When to Use
عند تدقيق الواجهة أو تخطيط تحسينات تجربة المستخدم.

## Inputs Needed
public/js/app.js (NAV_ITEMS، الدوال)، public/css/styles.css، public/*.html.

## Procedure
1. لكل صفحة/دور: الحالة الحالية، نقاط الضعف، الإجراءات/الفلاتر/التقارير الناقصة، إعادة التصميم المقترحة، الأولوية.
2. ركّز على الفجوات الموثّقة سابقاً: غياب ARIA/WCAG، البحث على الموبايل، focus trap في النوافذ، الترقيم، التحقق السطري.
3. قيّم التوطين العربي/RTL كنقطة قوة.

## Safety Rules
قراءة فقط. لا إعادة بناء لما يعمل (التصميم/التوطين) دون مبرّر. توصيات لا تنفيذ في هذه المهارة.

## Output Format
`docs/MEDICAL_UX_UI_REVIEW_AR.md` — لكل صفحة: الحالة | الضعف | الناقص | إعادة التصميم | الأولوية.

## Done Criteria
الصفحات/الأدوار الرئيسية مُقيّمة، فجوات الإتاحة/الموبايل/التجربة مُحدّدة بأولويات وquick wins.
