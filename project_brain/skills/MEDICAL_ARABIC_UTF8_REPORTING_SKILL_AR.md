# مهارة التوثيق العربي UTF-8 السليم (Arabic UTF-8 Reporting)

## Purpose
ضمان أن كل التوثيق العربي بترميز UTF-8 نظيف بلا تشويه (mojibake)، وحظر الإغلاق إذا كان الترميز فاسداً.

## When to Use
قبل أي commit أو إغلاق مرحلة تتضمّن تقارير عربية.

## Inputs Needed
ملفات `docs/*.md` و`.ai-brain/*.md` الجديدة/المعدّلة.

## Procedure
1. اكتب كل التقارير عربية UTF-8.
2. قبل الإغلاق شغّل تدقيق mojibake:
   `git grep -nE "Ø|Ù|ï»¿|�" docs/ .ai-brain/`
3. تحقّق ألا تظهر العلامات المحظورة داخل النص العربي (ظهورها داخل أنماط grep تعليمية في مهارة النظافة مقبول).
4. إن ظهر تشويه فعلي → أوقف الإغلاق وأصلح الترميز.

## Safety Rules
العلامات المحظورة: `Ø` `Ù` `ï»¿` `�`. لا إغلاق مع ترميز فاسد. لا تحويل ترميز يفسد المحتوى.

## Output Format
قسم "تدقيق ترميز UTF-8 العربي" ضمن الإغلاق النهائي: `UTF8_ARABIC_AUDIT: PASS/FAIL`.

## Done Criteria
لا mojibake فعلي في التقارير، ونتيجة التدقيق PASS.
