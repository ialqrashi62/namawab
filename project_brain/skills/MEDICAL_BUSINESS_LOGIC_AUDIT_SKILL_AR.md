# مهارة تدقيق منطق العمل الطبي (Business Logic Audit)

## Purpose
التحقّق من وجود منطق عمل طبي ومؤسسي حقيقي وليس مجرد شاشات CRUD: تسجيل المرضى، منع التكرار، المواعيد، الطابور، الزيارة/الـ encounter، الوصفة، صرف الصيدلية، منطق الدُفعة/الانتهاء، اعتماد المختبر/الأشعة، الفوترة، التأمين، الترحيل المحاسبي، استهلاك المخزون، المشتريات، HR، تفعيل نوع المنشأة، عزل المستأجر، الإلغاء/العكس، انتقالات الحالة.

## When to Use
عند الحكم على نضج النظام الفعلي (هل هو منطق حقيقي أم واجهات فقط).

## Inputs Needed
server.js (منطق الـ handlers)، db_postgres.js، تقارير التدفّقات/السيناريوهات.

## Procedure
تحقّق من القواعد الحرجة بالكود:
1. الوصفة لا تُنقِص المخزون قبل الصرف.
2. الصرف يُنقِص حسب الدُفعة/الانتهاء.
3. نتيجة المختبر لا تكون نهائية بلا اعتماد؛ تقرير الأشعة كذلك.
4. فاتورة المريض تُرحَّل محاسبياً عبر ترحيل متحكَّم فقط.
5. فاتورة المورّد تؤثّر على AP والمخزون/المصروف.
6. رفض التأمين لا يحذف الإيراد صامتاً.
7. نوع المنشأة يحجب المسارات غير المدعومة من API لا الواجهة فقط.
8. السجلات المالية المرحَّلة لا تُعدَّل صامتاً؛ السجلات السريرية لها سجل تدقيق.
9. انتقالات الحالة مُنفَّذة (لا قفزات غير شرعية).

## Safety Rules
قراءة فقط. كل حكم بدليل (مسار/سطر). غياب المنطق = خطر يُسجَّل، لا يُفترض وجوده من وجود الجدول/الشاشة.

## Output Format
`docs/MEDICAL_BUSINESS_LOGIC_AUDIT_AR.md` — لكل قاعدة: الحالة (موجودة/ناقصة/خطأ) | الدليل | الأثر (سريري/مالي/مخزون/بيانات) | الإصلاح | الاختبار.

## Done Criteria
كل القواعد الحرجة مُقيّمة بأدلة، الفجوات المنطقية مُحدّدة بأثرها واختباراتها.
