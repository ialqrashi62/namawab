# مهارة تدقيق الصيدلية والمخزون (Pharmacy & Inventory Safety)

## Purpose
تدقيق سلامة الصيدلية والمخزون: كتالوج الأدوية، الوصفة، الصرف، الصرف الجزئي، الإرجاع، تتبّع الدُفعات/الانتهاء، توقيت خصم المخزون، الأدوية المراقَبة، POS الصيدلية، تعدد الصيدليات، تنبيهات إعادة الطلب، تقييم المخزون، حركات المخزون، GRN، ربط فاتورة المورّد.

## When to Use
عند تدقيق الصيدلية/المخزون أو فحص سلامة خصم المخزون والدُفعات.

## Inputs Needed
مسارات `/api/pharmacy/*`, `/api/inventory/*`؛ نماذج pharmacy_*/inventory_*.

## Procedure
1. تحقّق من القاعدة الحرجة: **الوصفة لا تُنقِص المخزون حتى الصرف الفعلي**.
2. تحقّق أن الصرف يُنقِص حسب الدُفعة/الانتهاء (FEFO).
3. افحص الإرجاع، منع صرف الدُفعات المنتهية، الأدوية المراقَبة.
4. تتبّع GRN → فاتورة المورّد → أثر المخزون/المحاسبة.
5. عزل tenant في كل حركة.

## Safety Rules
قراءة فقط. لا تعديل مخزون/إنتاج. القاعدة الحرجة (لا خصم قبل الصرف) يجب إثباتها بالكود.

## Output Format
تدقيق الصيدلية/المخزون + سيناريوهات + أثر المخزون + اختبارات مطلوبة (ضمن تقارير المنطق/السيناريوهات).

## Done Criteria
قاعدة "لا خصم قبل الصرف" مُتحقَّق منها، تتبّع الدُفعات/الانتهاء مُقيّم، المخاطر والاختبارات موثّقة.
