# MEDICAL_INCIDENT_RESPONSE_SKILL_AR

## الهدف
الاستجابة الفورية والمنهجية لأي حوادث أمنية أو تسريب للبيانات أو توقف للخدمة ناتج عن تفعيل سياسات الأمان أو التعديلات الهيكلية، لتقليل الأثر التشغيلي واسترجاع الوضع الآمن.

## القواعد الأساسية
- **الاحتواء الفوري (Containment)**: عند رصد أي تسريب متقاطع للبيانات بين المستأجرين، يجب فوراً عزل نهايات الـ API المصابة أو تجميد الجلسات النشطة.
- **التراجع السريع (Rollback)**: تشغيل سكربت التراجع المخصص للدفعة المعنية فوراً لإلغاء RLS أو التعديل الهيكلي وإرجاع النظام للحالة المستقرة السابقة.
- **منع المساس بالدفعات المستقرة**: عدم لمس أو إلغاء سياسات RLS الخاصة بالدفعات السابقة المستقرة لمنع توسيع الفجوة الأمنية أثناء معالجة الخلل.
- **التحقيق والتحليل (Post-Mortem)**: فحص سجلات الأخطاء لقاعدة البيانات والتطبيق لتحديد الثغرة أو الخلل البرمجي الذي أدى للحادثة.
- **التوثيق والإبلاغ**: توثيق الحادثة بالتفصيل (الوقت، الأثر، السبب، آلية الإصلاح، التوصيات لمنع التكرار) باللغة العربية بترميز UTF-8.

## سيناريوهات التطبيق
- عند فشل أحد اختبارات العزل الأمنية بعد التفعيل.
- عند رصد محاولات دخول غير مصرح بها أو استغلال لثغرات IDOR في سجلات الخادم.
