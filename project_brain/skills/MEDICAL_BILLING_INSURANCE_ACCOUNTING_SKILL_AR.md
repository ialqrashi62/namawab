# مهارة تدقيق الفوترة والتأمين والمحاسبة (Billing / Insurance / Accounting)

## Purpose
تدقيق الدورة الإيرادية والمحاسبة: الفوترة النقدية/التأمينية، الفاتورة/الإيصال/الاسترداد/إشعار الدائن، الموافقة المسبقة، جاهزية تقديم المطالبات، الرفض/إعادة التقديم، AR/AP، القيد المحاسبي، ميزان المراجعة، ZATCA/VAT، إقفال الفترة، القيود العكسية، سجل التدقيق.

## When to Use
عند تدقيق الفوترة/التأمين/المحاسبة أو فحص محرّك الترحيل المحاسبي.

## Inputs Needed
مسارات `/api/invoices/*`, `/api/insurance/*`, `/api/finance/*`, `/api/zatca/*`؛ نماذج invoices/insurance_*/finance_*.

## Procedure
1. تتبّع الفاتورة → الدفع/الجزئي → الاسترداد/الدائن.
2. افحص محرّك الترحيل: هل فاتورة المريض/الإيصال/فاتورة المورّد/استهلاك المخزون تُرحَّل آلياً وبشكل متحكَّم؟
3. القواعد الحرجة: رفض التأمين لا يحذف الإيراد صامتاً؛ السجلات المالية المرحَّلة لا تُعدَّل صامتاً؛ ZATCA توقيع/تقديم فعلي أم QR محلي.
4. عزل tenant + ترقيم فواتير فريد لكل tenant.

## Safety Rules
قراءة فقط. لا تعديل بيانات مالية. القواعد الحرجة تُثبَت بالكود.

## Output Format
جاهزية المحاسبة + مخاطر الفوترة/التأمين + فجوات محرّك الترحيل + اختبارات مطلوبة (ضمن تقارير المنطق/المخاطر).

## Done Criteria
الدورة الإيرادية ومحرّك الترحيل مُقيّمان بأدلة، القواعد الحرجة مُتحقَّق منها، المخاطر والاختبارات موثّقة.
