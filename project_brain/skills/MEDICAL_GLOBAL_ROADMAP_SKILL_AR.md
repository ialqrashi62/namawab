# مهارة خارطة الطريق العالمية (Global Roadmap)

## Purpose
إنشاء خارطة طريق مرحلية للوصول لمعايير الأنظمة الطبية العالمية، من الاكتشاف حتى الذكاء الاصطناعي.

## When to Use
بعد التدقيق والمقارنة العالمية، لترتيب التنفيذ.

## Inputs Needed
تقارير التدقيق، المقارنة العالمية، سجل المخاطر، مصفوفة الفجوات.

## Procedure
رتّب العمل في مراحل:
- Phase 0: الاكتشاف وخط الأساس الآمن.
- Phase 1: إصلاحات حرجة (عزل، خصوصية، RBAC، استحقاقات، APIs مكسورة، سلامة المحاسبة/المخزون).
- Phase 2: إكمال المسارات الطبية الأساسية.
- Phase 3: onboarding SaaS حسب نوع المنشأة.
- Phase 4: نضج المستشفى المؤسسي (تنويم/طوارئ/OR/تمريض/تأمين/مشتريات/HR/جودة).
- Phase 5: نضج المدينة الطبية (تعدد منشآت/مالية موحّدة/مشتريات مركزية/تحليلات مجموعة).
- Phase 6: التكاملات والامتثال (ZATCA/NPHIES/CHI/SMS/دفع/أجهزة/PACS/API).
- Phase 7: الذكاء الاصطناعي والأتمتة.

لكل بند: السبب، الأثر، الملفات المتوقعة، تغييرات DB، APIs، UI، الاختبارات، المخاطر، معايير الإنجاز.

## Safety Rules
لا إعلان جاهزية متعددة المستأجرين قبل إغلاق كل P0. ربط الأولويات بسجل المخاطر.

## Output Format
`docs/MEDICAL_GLOBAL_ROADMAP_AR.md` — مراحل مرتّبة ببنود وأدلة وأولويات.

## Done Criteria
خارطة طريق مرحلية كاملة قابلة للتنفيذ مربوطة بالفجوات والمخاطر.
