# Skill: Accounting

## 1. الغرض

هذه المهارة تُستدعى عندما تكون المهمة مرتبطة بالمحاور التالية:

- double-entry
- ledger
- tax
- close

هدفها تقليل استهلاك السياق عبر تحميل تعليمات هذا المجال فقط بدلاً من تحميل الدستور الكامل.

## 2. متى تُستدعى

استدع هذه المهارة عند:

- وجود تغيير مباشر في المجال المذكور.
- الحاجة إلى مراجعة أو تحليل متخصص.
- وجود خطر على البيانات أو الأمن أو الأداء في هذا المجال.
- الحاجة إلى تقرير أو قرار معماري متعلق بالمجال.

## 3. طريقة العمل الإلزامية

1. اقرأ الدستور الهندسي أولاً عند توفره.
2. حدد نطاق المهمة بدقة.
3. افصل بين الحقائق، الافتراضات، والتوصيات.
4. لا تنفذ قبل تحليل الأثر.
5. لا تعتمد حلولاً سطحية في الدومينات الحساسة.
6. وثق أي قرار جوهري.
7. اقترح اختباراً مناسباً.
8. قدم تقريراً نهائياً.

## 4. قواعد المجال

- يجب احترام عزل المستأجرين.
- يجب احترام الصلاحيات.
- يجب احترام قابلية التدقيق.
- يجب عدم إدخال تعقيد غير مبرر.
- يجب عدم الادعاء بنتائج لم يتم التحقق منها.
- يجب أن تكون الحلول قابلة للصيانة والاختبار.

## 5. مخرجات المهارة

عند استخدام هذه المهارة، يجب أن ينتج الوكيل:

- تحليل مختصر للمشكلة.
- قائمة الملفات أو الوحدات المتأثرة.
- خطة تنفيذ.
- قائمة مخاطر.
- اختبارات مطلوبة.
- تقرير نهائي أو تحديث للتقرير.

## 6. برومبت استدعاء مختصر

```text
استدع Skill: Accounting
طبّق الدستور الهندسي، حلل المهمة، لا تنفذ قبل تحليل الأثر، ولا تدّعِ أي تحقق لم يتم تشغيله فعلياً.
```

## 7. قائمة تحقق سريعة

- [ ] هل المهمة ضمن نطاق هذه المهارة؟
- [ ] هل تم تحديد الملفات المتأثرة؟
- [ ] هل تم تحليل الأمن والصلاحيات؟
- [ ] هل تم تحليل الأداء؟
- [ ] هل توجد اختبارات؟
- [ ] هل يلزم ADR؟
- [ ] هل يلزم تحديث وثائق؟
