# Documentation Checklist

## الغرض

هذه القائمة تُستخدم للتحقق من جاهزية العمل قبل اعتماده. لا تعني القائمة أن كل بند ينطبق دائماً، لكن أي بند غير مطبق يجب أن يكون مبرراً.

## قائمة التحقق الأساسية

- [ ] ADR
- [ ] Report
- [ ] API Docs
- [ ] User Guide

## قائمة تحقق عامة إلزامية

- [ ] تم تحديد نطاق المهمة.
- [ ] تم تحديد الدومينات المتأثرة.
- [ ] تم تحليل أثر الأمن والصلاحيات.
- [ ] تم تحليل أثر عزل المستأجرين.
- [ ] تم تحليل أثر قاعدة البيانات.
- [ ] تم تحليل أثر الأداء.
- [ ] تم تحديد الاختبارات المطلوبة.
- [ ] تم تشغيل الاختبارات الممكنة أو توضيح عدم تشغيلها.
- [ ] تم تحديث الوثائق عند الحاجة.
- [ ] تم إعداد تقرير نهائي.
- [ ] لا توجد ادعاءات تحقق بلا دليل.

## قرار القائمة

- [ ] مقبول.
- [ ] مقبول بشروط.
- [ ] مرفوض حتى معالجة الملاحظات.
