# P0-1_PATIENT_PORTAL_MOBILE — Patient Portal Mobile App

## Module ID
`P0-1_PATIENT_PORTAL_MOBILE` — Patient-facing mobile app + portal

## Specialty
Patient engagement + mobile-first care access

## Clinical Scope
- **Mobile appointments** — Schedule, reschedule, cancel
- **Telehealth visits** — Video consultations
- **Lab results** — View + download
- **Medications** — Refill requests, adherence tracking
- **Vital signs tracking** — Self-reported BP, glucose, weight
- **Health records** — Download CCD/FHIR
- **Messaging** — Secure provider chat
- **Bill pay** — Online payments
- **Insurance card** — Digital wallet
- **Consent management** — Bilingual consent forms
- **Family access** — Caregiver proxy
- **Health reminders** — Push notifications

## Compliance
- **PDPL** — Saudi Personal Data Protection Law
- **NHIA Sehhaty** — National Health Information Exchange
- **MoH Mawid** — Appointment booking
- **Anat Platform** — Patient identity
- **CBAHI** — Patient portal standards
- **ONC Cures Act** — US API standards (informational)
- **FHIR R4** — Standard API

## Approval Gate
- Patient consent (PDPL)
- Identity verification (Absher/Nafath)
- 2FA for sensitive operations
- Audit trail for all actions

## Saudi Integration
- **Sehhaty** — National unified health record
- **Mawid** — MoH appointment system
- **Nafath/Absher** — Identity verification
- **Wateen** — Insurance verification
- **NUPCO** — Pharmaceutical procurement
