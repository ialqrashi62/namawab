# P0-3 BCMA Wireframes

## Screen 1: Scan Patient (Mobile)
- Large camera viewport (top)
- Patient name + MRN (after scan, center)
- "مسح الدواء التالي" button (bottom)

## Screen 2: Scan Drug
- Camera viewport
- Drug name + dose + route (from barcode)
- 5 Rights checklist (animated checkmarks)
- High-alert warning if applicable

## Screen 3: Verify & Administer
- Drug + dose + time
- "تأكيد" (Confirm) button (green, large)
- "رفض" (Refuse) button (red, smaller)
- Witness button if high-alert

## Screen 4: Override (if blocked)
- Block reason (prominent)
- Reason code dropdown
- Witness picker
- Notes textarea
- Approver picker
