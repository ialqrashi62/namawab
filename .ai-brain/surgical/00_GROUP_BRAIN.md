## 🎯 Group-Level Clinical Authority (CMO)

### Universal surgical workflow (WHO Surgical Safety Checklist)

```
Pre-operative phase
  - Patient identification
  - Site marking
  - Anesthesia safety check
  - Allergies reviewed
  - Anticoagulation status
  - NPO status
  - Consent signed

"Time Out" (in OR, before incision)
  - Confirm patient, procedure, site
  - All team members introduced
  - Surgeon reviews critical steps
  - Anesthesia reviews concerns
  - Nursing reviews equipment, sterility
  - Antibiotics given within 60 min

"Sign Out" (before patient leaves OR)
  - Procedure recorded
  - Instrument, sponge, needle counts
  - Specimen labeled
  - Equipment issues addressed
  - Recovery plan discussed
```

### Universal post-op orders (template)

| Order | Default |
|---|---|
| NPO until | per anesthesia |
| IV fluids | NS or LR at maintenance |
| Pain control | multimodal: acetaminophen + NSAID + opioid PRN |
| Antiemetic | ondansetron 4 mg q8h PRN |
| DVT prophylaxis | enoxaparin 40 mg SC daily (if not contraindicated) |
| Antibiotics | per surgery type (cefazolin for clean, +/- anaerobic for clean-contaminated) |
| Wound care | dressing change q24h or per surgeon |
| Activity | out of bed POD0, ambulate POD1 |
| Diet | clear liquids → advance as tolerated |
| Discharge criteria | afebrile, tolerating PO, pain controlled, ambulating |

## 🤖 Group-Level AI (AI Engineer)

### Universal surgical risk calculators

```javascript
// surgical_risk_engine.js

// ASA Classification (1-6)
function calculateASA({ healthy, mildDisease, severeDisease, severeConstantThreat, moribund, brainDead }) {
    if (brainDead) return { class: 'VI', description: 'Brain dead, organ donation' };
    if (moribund) return { class: 'V', description: 'Moribund, not expected to survive 24h' };
    if (severeConstantThreat) return { class: 'IV', description: 'Severe systemic disease, constant threat to life' };
    if (severeDisease) return { class: 'III', description: 'Severe systemic disease' };
    if (mildDisease) return { class: 'II', description: 'Mild systemic disease' };
    return { class: 'I', description: 'Normal healthy patient' };
}

// Revised Cardiac Risk Index (RCRI) - Lee criteria
function calculateRCRI({ highRiskSurgery, ischemicHeartDisease, chf, stroke, diabetes, renal }) {
    let score = 0;
    if (highRiskSurgery) score += 1;
    if (ischemicHeartDisease) score += 1;
    if (chf) score += 1;
    if (stroke) score += 1;
    if (diabetes) score += 1;
    if (renal) score += 1;
    return { score, risk: score >= 3 ? 'high' : score >= 2 ? 'moderate' : 'low' };
}

// STOP-BANG (Obstructive Sleep Apnea screening)
function calculateStopBang({ snoring, tiredness, observedApnea, pressure, bmi, age, neck, gender }) {
    let score = 0;
    if (snoring) score += 1;
    if (tiredness) score += 1;
    if (observedApnea) score += 1;
    if (pressure) score += 1;
    if (bmi >= 35) score += 1;
    if (age >= 50) score += 1;
    if (neck >= 40) score += 1;  // cm
    if (gender === 'male') score += 1;
    return { score, osa_risk: score >= 5 ? 'high' : score >= 3 ? 'intermediate' : 'low' };
}

// Caprini Score (VTE risk)
function calculateCaprini({ age, mob, cancer, historyVTE, familyVTE, surgery, pregnancy, hormones, ... }) {
    let score = 0;
    if (age >= 75) score += 3;
    else if (age >= 60) score += 2;
    else if (age >= 40) score += 1;
    if (mob) score += 1;
    if (cancer) score += 2;
    if (historyVTE) score += 3;
    if (familyVTE) score += 3;
    if (surgery) score += 2;
    if (pregnancy) score += 1;
    // ... (full Caprini has 30+ factors)
    return { score, vte_risk: score >= 5 ? 'very_high' : score >= 3 ? 'high' : 'moderate' };
}

// Clavien-Dindo (complication severity)
function classifyClavienDindo({ complication }) {
    if (complication === 'deviation_from_normal_postop_no_treatment') return { grade: 'I' };
    if (complication === 'pharmological_treatment') return { grade: 'II' };
    if (complication === 'surgical_endoscopic_radiological_intervention') return { grade: 'IIIa' };  // no GA
    if (complication === 'intervention_under_ga') return { grade: 'IIIb' };
    if (complication === 'life_threatening_icu') return { grade: 'IVa' };  // single organ
    if (complication === 'life_threatening_multi_organ') return { grade: 'IVb' };
    if (complication === 'death') return { grade: 'V' };
    return { grade: 'unknown' };
}

module.exports = { calculateASA, calculateRCRI, calculateStopBang, calculateCaprini, classifyClavienDindo };
```
