# دليل المستخدم — مركز السكتة الدماغية (TIER3_CARD-301_STROKE)

> **الفئة المستهدفة**: أطباء الأعصاب، أطباء الطوارئ، تمريض السكتة الدماغية
> **الإصدار**: 1.0.0
> **آخر تحديث**: 2026-08-15

---

## 1. مقدمة

مركز السكتة الدماغية في NamaMedical يقدم رعاية شاملة من لحظة وصول المريض حتى 30 يومًا من المتابعة. يدعم النظام جميع المسارات المعتمدة من AHA/ASA 2019 ومعايير CBAHI ووزارة الصحة السعودية 2024.

## 2. الأدوار المسموح بها

| الدور | الصلاحيات |
|---|---|
| **طبيب أعصاب** | تقييم NIHSS، قرار الإذابة، التسجيل الكامل |
| **طبيب طوارئ** | تفعيل Code Stroke، NIHSS الأولي |
| **تمريض السكتة** | تسجيل العلامات الحيوية، تحضير الدواء |
| **طبيب أشعة تداخلية** | تسجيل Thrombectomy و TICI |
| **منسق الجودة** | عرض الإحصائيات، GWTG-S |
| **مدير** | جميع الصلاحيات |

## 3. سير العمل اليومي

### 3.1 تفعيل Code Stroke

1. اذهب إلى **القائمة الجانبية → مركز السكتة**
2. اضغط **🚨 تفعيل Code Stroke**
3. املأ تاريخ "آخر وقت معروف بصحة جيدة"
4. أدخل علامات NIHSS الـ 13
5. حدد موانع الاستعمال إن وجدت
6. أدخل الطول/الوزن ومعدل INR والصفائح
7. اضغط **🚨 تفعيل Code Stroke**

### 3.2 التحقق من الأهلية

النظام يحسب تلقائيًا:
- نتيجة NIHSS (0-42)
- الأهلية للإذابة
- جرعة Tenecteplase المقترحة (0.25 mg/kg، حد أقصى 25 mg)
- ⏱️ تنبيه SLA (Door-to-Needle ≤ 60 دقيقة)

### 3.3 تسجيل العلاج

1. بعد إعطاء الدواء، اذهب إلى **حالة المريض → العلاج**
2. أدخل:
   - وقت الإعطاء
   - الجرعة النهائية
   - ملاحظات (إن وجدت)
   - معلومات الموافقة (PDPL)
3. اضغط **حفظ**

### 3.4 المتابعة عند 30 يوم

1. في موعد المريض (30 يوم)، اذهب إلى **المتابعة**
2. أدخل نتيجة mRS (0-6)
3. تحقق من الالتزام بالأدوية
4. اضغط **حفظ**

## 4. معايير SLA

| المؤشر | الهدف |
|---|---|
| Door-to-CT | ≤ 25 دقيقة |
| Door-to-Needle | ≤ 60 دقيقة |
| Door-to-Groin | ≤ 90 دقيقة |
| وحدة السكتة | خلال 3 ساعات |
| 30-day Follow-up | ≥ 80% من المرضى |

## 5. الأسئلة الشائعة

### س: ما الفرق بين Tenecteplase و Alteplase؟
**ج**: Tenecteplase (0.25 mg/kg، جرعة واحدة IV bolus) هو الأحدث المعتمد من وزارة الصحة السعودية 2024، بنفس فعالية Alteplase مع سهولة الإعطاء.

### س: ماذا لو وصل المريض بعد 4.5 ساعة من TLKW؟
**ج**: قد يكون مؤهلًا ل Thrombectomy الميكانيكي إذا كان LVO (خلال 6 ساعات) أو مع تصوير perfusion favorable (6-24 ساعة).

### س: كيف أتعامل مع مريض يتناول مضاد تخثر؟
**ج**: استخدم النزيف المعاكس (Vitamin K, PCC, Idarucizumab, Andexanet). راجع AHA/ASA 2019.

## 6. الأخطاء الشائعة

- ❌ استخدام NIHSS الجزئي (نسيان subscore)
- ❌ عدم التحقق من INR / الصفائح قبل الإذابة
- ❌ عدم تسجيل وقت TLKW بدقة
- ❌ نسيان المريض في المراقبة بعد الإذابة
