# CARD-302_ADHF — User Stories

## US-1: GDMT 4-Pillar Optimization
**As** an HF cardiologist
**I want** to see all 4 GDMT pillars status at a glance
**So that** I can optimize therapy systematically

### AC
- [ ] Patient's GDMT score visible (0-4)
- [ ] Each pillar shows eligibility (✓/✗)
- [ ] Reasons for ineligibility displayed
- [ ] Recommended doses shown
- [ ] Titration schedule suggested

## US-2: Acute Decompensation Management
**As** an HF nurse
**I want** to track I/O and diuretic dose during admission
**So that** the patient achieves decongestion

### AC
- [ ] Daily weight recorded
- [ ] IV diuretic dose adjustable
- [ ] Urine output tracked
- [ ] BMP daily
- [ ] Discharge weight goal

## US-3: Cardiogenic Shock Activation
**As** an HF cardiologist/CCU fellow
**I want** to activate shock team and get SCAI staging
**So that** I can begin DRIPS protocol

### AC
- [ ] Shock team pager activated
- [ ] SCAI stage calculated (A-E)
- [ ] DRIPS recommendations shown
- [ ] Lactate, SBP, CI tracked
- [ ] Escalation alerts

## US-4: LVAD Monitoring
**As** an LVAD coordinator
**I want** to monitor LVAD parameters and detect pump thrombosis
**So that** I can intervene early

### AC
- [ ] Pump speed, power, flow tracked
- [ ] LDH and plasma Hgb monitored
- [ ] Thrombosis risk score
- [ ] Alarms for abnormal parameters
- [ ] Trend graphs

## US-5: LVAD Pre-Op Checklist
**As** an LVAD coordinator
**I want** to ensure all 10 checklist items are complete
**So that** the patient is ready for surgery

### AC
- [ ] All 10 items in checklist
- [ ] Status: ready/not-ready
- [ ] Missing items highlighted
- [ ] Heart Team review triggered when ready

## US-6: Heart Transplant Listing
**As** a transplant coordinator
**I want** to manage SCOT listing status
**So that** the patient is properly classified

### AC
- [ ] Status: 1A / 1B / 2 / inactive
- [ ] Waitlist days tracked
- [ ] PRA + HLA typing
- [ ] MELD score
- [ ] Match run eligibility

## US-7: Post-Transplant Surveillance
**As** a transplant cardiologist
**I want** to schedule biopsies and detect rejection
**So that** graft survival is maximized

### AC
- [ ] Biopsy schedule per protocol
- [ ] ISHLT grade (0/1R/2R/3R/AMR)
- [ ] Treatment per grade
- [ ] Immunosuppression compliance
- [ ] CAV screening

## US-8: Palliative Care Trigger
**As** an HF cardiologist
**I want** to identify when palliative care is needed
**So that** patients receive appropriate end-of-life care

### AC
- [ ] Multiple triggers detected
- [ ] Palliative care consult ordered
- [ ] Goals of care documented
- [ ] Advance directives on file
- [ ] Hospice referral when appropriate
