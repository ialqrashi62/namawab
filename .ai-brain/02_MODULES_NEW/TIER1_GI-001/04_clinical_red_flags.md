# GI-001 — Clinical Red Flags

## A. HARD red flags (BLOCK / STAT)

| ID | Red Flag | Action | Latency |
|----|----------|--------|---------|
| GI-RF-001 | Acute variceal bleed | STAT EGD + IV octreotide + abx | <1h |
| GI-RF-002 | Acute severe UGIB (Forrest I) | STAT EGD + scope | <1h |
| GI-RF-003 | Acute cholangitis | STAT ERCP + abx | <6h |
| GI-RF-004 | Fulminant hepatic failure | STAT ICU + N-acetylcysteine eval + transplant | <2h |
| GI-RF-005 | Boerhaave syndrome | STAT CT + surgical | <1h |
| GI-RF-006 | Mesenteric ischemia | STAT CTA + surgery | <1h |
| GI-RF-007 | Perforated viscus | STAT surgery | <1h |
| GI-RF-008 | Toxic megacolon | STAT bowel rest + IV steroids + surgery consult | <6h |
| GI-RF-009 | Acute severe colitis (Mayo>=3) | STAT IV steroids + biologic | <24h |
| GI-RF-010 | Foreign body (food impaction) | STAT EGD | <2h |

## B. SOFT red flags (escalate high priority)

| ID | Red Flag | Action |
|----|----------|--------|
| GI-RF-S01 | New-onset IBD in young adult | Same-day GI consult |
| GI-RF-S02 | Chronic GI bleed with anemia | GI consult + scope within 1 week |
| GI-RF-S03 | New HBV/HCV with elevated LFTs | GI + ID consult |
| GI-RF-S04 | Liver mass on imaging | MDT tumor board |
| GI-RF-S05 | Iron deficiency anemia (adult) | EGD+colonoscopy rule-out cancer |
| GI-RF-S06 | Persistent dysphagia + weight loss | EGD + biopsy |
| GI-RF-S07 | Severe refractory constipation + distension | CT + surgery eval |
| GI-RF-S08 | Decompensated cirrhosis (ascites, encephalopathy) | GI/hepatology + transplant eval |
| GI-RF-S09 | Post-ERCP pancreatitis (severe) | Admit + supportive care |
| GI-RF-S10 | Anti-TNF + TB reactivation risk | Screen + hold if active TB |

## C. Drug-related BLOCKs

| ID | Drug + Context | Action |
|----|----------------|--------|
| GI-DRUG-001 | Anti-TNF + active infection | BLOCK until resolved |
| GI-DRUG-002 | JAK inhibitor + pregnancy | BLOCK; switch to anti-TNF safe in 2nd/3rd tri |
| GI-DRUG-003 | Azathioprine + TPMT deficiency | BLOCK; alternative |
| GI-DRUG-004 | Mesalamine + sulfa allergy | BLOCK; use mesalamine (not sulfasalazine) or rectal |
| GI-DRUG-005 | PPI + concomitant clopidogrel | prefer pantoprazole or H2RA |
| GI-DRUG-006 | Statin + clarithromycin (CYP3A4) | hold statin during course |
| GI-DRUG-007 | Methotrexate + pregnancy | BLOCK (teratogen) |
| GI-DRUG-008 | Warfarin + antibiotic + diarrhea | monitor INR closely |
| GI-DRUG-009 | Biologic + live vaccine | defer vaccine; hold if active infection |
| GI-DRUG-010 | Octreotide + insulin | monitor glucose; reduce insulin |
