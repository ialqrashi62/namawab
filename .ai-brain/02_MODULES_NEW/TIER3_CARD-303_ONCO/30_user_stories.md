# CARD-303_ONCO — User Stories

## US-1: Pre-Treatment CV Risk Assessment
**As** a cardio-onc specialist
**I want** to assess cancer patient cardiac risk before therapy
**So that** I can plan cardioprotection

### AC
- [ ] HFA-ICOS risk score calculated
- [ ] Risk category displayed (Low/Moderate/High/Very High)
- [ ] Cardioprotection plan shown
- [ ] Monitoring schedule proposed

## US-2: Anthracycline Monitoring
**As** an oncologist
**I want** to monitor patient cardiac function during chemo
**So that** I can detect early cardiotoxicity

### AC
- [ ] Echo scheduled every 3 months
- [ ] GLS measured
- [ ] Troponin tracked
- [ ] Alert if EF drop >10% or GLS drop >15%

## US-3: ICI Myocarditis Detection
**As** an oncologist
**I want** to detect immune-related myocarditis early
**So that** I can start steroids immediately

### AC
- [ ] Troponin check every cycle
- [ ] ECG baseline + on symptoms
- [ ] Severity tier (mild/moderate/severe/fulminant)
- [ ] Treatment protocol triggered

## US-4: Cancer-Associated VTE
**As** a cardio-onc
**I want** to treat cancer-associated VTE
**So that** I can use the right anticoagulant

### AC
- [ ] Drug choice (DOAC vs LMWH)
- [ ] Dose adjustment for renal/platelets
- [ ] Duration tracking
- [ ] Recurrence monitoring

## US-5: Cardiac Amyloid Workup
**As** a cardiologist
**I want** to detect cardiac amyloidosis
**So that** I can refer to hematology

### AC
- [ ] Pyrophosphate scan
- [ ] TTR genetic test
- [ ] Light chains
- [ ] Cardiac MRI

## US-6: Cardioprotection Decision
**As** a cardio-onc
**I want** to start cardioprotection in high-risk patients
**So that** I can prevent cardiotoxicity

### AC
- [ ] ACEi/ARB recommended
- [ ] Beta-blocker recommended
- [ ] Statin recommended
- [ ] Dexrazoxane for high-dose anthracycline

## US-7: Survivorship
**As** a cardio-onc
**I want** to monitor long-term CV complications
**So that** survivors live longer

### AC
- [ ] Annual CV risk assessment
- [ ] 5-year cumulative risk
- [ ] 10-year cardiac amyloid
- [ ] 15-year RT-induced heart disease
