# CARD-304_ROBOTIC — Chaining Patterns

## Pattern 1: Heart Team MDT
```
[Cardiac Surgery Referral] → [Heart Team MDT]
       ↓
[Cardiology + Surgery + Anesthesia]
       ↓
[Decision: Robotic / Open / Catheter]
       ↓
[Patient Consent (PDPL)]
       ↓
[Pre-Op Workup]
```

## Pattern 2: Robotic Mitral Valve Repair
```
[MR Grade 3-4] → [Echo + TEE]
       ↓
[Heart Team Review]
       ↓
[STS + EuroSCORE II]
       ↓
[DaVinci Robotic Repair]
       ↓
[Repair techniques: Neo-chordae, Annuloplasty]
       ↓
[ICU Monitoring]
       ↓
[Discharge 5-7 days]
```

## Pattern 3: TAVI/TAVR
```
[Severe AS] → [Heart Team]
       ↓
[CT Annulus Sizing]
       ↓
[Femoral Access preferred]
       ↓
[Sapien 3 / Evolut / Myval]
       ↓
[Post-TAVI DAPT 1-6 months]
       ↓
[1-month + 1-year follow-up echo]
```

## Pattern 4: Robotic CABG
```
[LAD/LCx disease] → [Heart Team]
       ↓
[Single-vessel disease → TECAB]
       ↓
[Multi-vessel → MIDCAB or Hybrid]
       ↓
[DaVinci LIMA harvest]
       ↓
[Anastomosis on beating heart]
       ↓
[Hybrid PCI for non-LAD]
```

## Pattern 5: Robotic ASD Closure
```
[Secundum ASD] → [Echo sizing]
       ↓
[Defect <40mm] → [Robotic Closure]
       ↓
[Pericardial patch]
       ↓
[3-5 day hospital stay]
```

## Pattern 6: MitraClip
```
[MR Grade ≥3+] → [Heart Team]
       ↓
[High surgical risk → MitraClip]
       ↓
[Femoral venous access]
       ↓
[Transseptal puncture]
       ↓
[Clip deployment]
       ↓
[Discharge 2-3 days]
```

## Pattern 7: WATCHMAN
```
[AF + CHA2DS2-VASc ≥2] → [Cardiology]
       ↓
[Contraindication to anticoagulation]
       ↓
[CT/TEE for LAA anatomy]
       ↓
[LAA ostium 17-31 mm]
       ↓
[WATCHMAN FLX implant]
       ↓
[45-day post-implant TEE]
       ↓
[Discontinue anticoagulation]
```

## Pattern 8: Post-Op ICU
```
[Surgery Complete] → [ICU Admission]
       ↓
[24 hours: Hemodynamic monitoring]
       ↓
[48-72 hours: Ventilation weaning]
       ↓
[Step-Down]
       ↓
[Cardiac Rehab]
       ↓
[Discharge with follow-up]
```

## Pattern 9: Conversion to Open
```
[Intra-op complication] → [Surgeon decision]
       ↓
[Convert to Sternotomy]
       ↓
[Document + Audit]
       ↓
[Post-op MDT review]
```

## Pattern 10: Long-Term Surveillance
```
[Discharge] → [1-week visit]
       ↓
[1-month echo]
       ↓
[3-month echo]
       ↓
[1-year echo + ECG]
       ↓
[Annual valve function check]
       ↓
[5-year survival assessment]
```
