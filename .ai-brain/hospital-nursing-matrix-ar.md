## 1. المبدأ الحاكم والمنهجية

التمريض ليس دوراً عاماً واحداً. محطة التمريض v1 الحالية (10 تبويبات: NEWS2 / eMAR / تقييم / خطة رعاية / سوائل / SBAR / فرز / مخاطر / أوامر / ملاحظات) تمثل **نواة مشتركة (Core Nursing Shell)** ممتازة، لكنها لا تغطي سياقات الرعاية المتخصصة التي تشترطها CBAHI ومعايير الممارسة التمريضية السعودية. هذه الوثيقة تبني **مصفوفة 14 تخصصاً تمريضياً**، لكل تخصص:

1. **النطاق** — حدود المسؤولية السريرية.
2. **الشاشات** — ما يعاد استخدامه من v1 وما يجب بناؤه.
3. **التقييمات والمقاييس** — NEWS2 موجود؛ تُضاف MEWS/PEWS/Aldrete/Bromage/Ballard وغيرها حسب السياق.
4. **الصلاحيات** — أدوار RBAC مقترحة فوق RLS متعدد المستأجرين الموجود (150 سياسة FORCE).
5. **الأزرار (الإجراءات الأساسية)** — أفعال قابلة للتدقيق (Audit-able Actions).
6. **Handover** — تسليم الوردية/النقل (SBAR موجود كأساس).
7. **مؤشرات الجودة التمريضية** — على نمط NDNQI ومتطلبات CBAHI.

**قاعدة معمارية:** كل محطة تمريض تخصصية = القشرة المشتركة v1 + حزمة تبويبات تخصصية + حزمة مقاييس تخصصية + ملف صلاحيات تخصصي. لا استنساخ كود؛ توسعة بالتكوين (Configuration-driven Specialization) ضمن نمط Vanilla JS RTL الحالي.

## 2. خط الأساس — محطة التمريض العامة v1 (موجود-مكتمل)

| التبويب الحالي | الحالة | إعادة الاستخدام في التخصصات |
|---|---|---|
| NEWS2 (إنذار مبكر) | موجود — مرتبط بمحرك EWS/MEWS/PEWS بالكود | أساس لكل التخصصات؛ يُستبدل بـ PEWS للأطفال و MEOWS للولادة |
| eMAR (إعطاء الدواء) | موجود | مشترك؛ يمتد بتحقق ثنائي للأدوية عالية الخطورة |
| التقييم التمريضي | موجود | يُخصَّص بنماذج لكل سياق (Admission/Shift/Focused) |
| خطة الرعاية | موجود | مشترك مع مكتبات تشخيصات تمريضية لكل تخصص |
| السوائل (I&O) | موجود | يمتد لموازنة ساعية في ICU/NICU |
| SBAR | موجود | أساس كل Handover؛ يمتد إلى I-PASS للسياقات الحرجة |
| الفرز | موجود (يخدم ESI بالطوارئ) | ينتقل ليكون قلب محطة تمريض الفرز |
| المخاطر (سقوط/قرح) | موجود | يمتد بمقاييس Morse/Braden/Humpty Dumpty |
| الأوامر (عرض أوامر الطبيب) | موجود — متكامل مع CPOE v3 (تغذية/وريدية/تمريضية) | مشترك؛ Acknowledge إلزامي |
| الملاحظات | موجود | مشترك؛ يضاف قالب DAR/SOAPIE |

**فجوات القشرة المشتركة (تُبنى مرة واحدة للجميع):** تحقق ثنائي (Dual Sign-off) للأدوية عالية الخطورة، ربط باركود مريض-دواء (BCMA) كإطار مستقبلي، مؤقّتات مهام تمريضية (Task Timers)، لوحة عبء العمل (Acuity/Assignment)، توقيع إلكتروني مزدوج للشاهد.

## 4. التخصصات تفصيلاً

### 4.1 تمريض الفرز (Triage Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | أول تقييم عند وصول المريض للطوارئ: تحديد حدة الحالة (ESI 1–5)، علامات حيوية أولى، فرز أطفال/حوامل مسارات خاصة، إعادة فرز دوري للمنتظرين، فرز كوارث (START) وضع طوارئ جماعية. |
| **موجود في v1** | تبويب الفرز (يخدم ESI الحالي بقسم الطوارئ)، العلامات الحيوية، تقييم الألم (كشف قدرة موجود-ناقص). |
| **الشاشات الناقصة** | (أ) طابور فرز حي مرتبط بقائمة الانتظار الحالية مع مؤقّت انتظار لوني حسب ESI؛ (ب) شاشة إعادة الفرز التلقائي (تنبيه إذا تجاوز الانتظار حد ESI)؛ (ج) نمط فرز كوارث START/JumpSTART مبسّط؛ (د) مسار سريع Fast-Track. |
| **التقييمات** | ESI (موجود)، تقييم ألم (موجود-ناقص → إكمال)، PEWS سريع للأطفال (محرك موجود)، أعلام إنتان qSOFA/SIRS (محرك Gate 2 موجود — يُفعَّل عند الفرز)، سقسقة حمل/عزل تنفسي. |
| **الصلاحيات** | دور `NURSE_TRIAGE`: إنشاء/تعديل فرز، إعادة فرز، بدء بروتوكولات فرز معتمدة (تحليل/تخطيط قلب قبل الطبيب حسب سياسة)؛ لا يصرف دواء، لا يغلق زيارة. |
| **الأزرار** | [بدء فرز] [حفظ ESI] [إعادة فرز] [تصعيد فوري ESI-1] [تفعيل إنذار إنتان] [تحويل لمسار سريع] [بروتوكول فرز معتمد] |
| **Handover** | SBAR فرز→تمريض طوارئ محفوظ إلزامياً قبل نقل المريض من الطابور إلى سرير؛ يظهر تلقائياً بشاشة تمريض الطوارئ. |
| **مؤشرات الجودة** | زمن باب→فرز (هدف <10 د)، دقة الفرز (Over/Under-triage %)، % إعادة فرز في الوقت، غادر دون أن يُرى LWBS%، زمن باب→طبيب حسب ESI. |

### 4.2 تمريض الطوارئ (ED Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | رعاية المريض بعد الفرز حتى القرار (خروج/تنويم/تحويل): تنفيذ أوامر CPOE، مراقبة متكررة حسب ESI، إنعاش، سحب عينات، تجبير، أدوية طارئة. |
| **موجود في v1** | eMAR، الأوامر، NEWS2، سوائل، ملاحظات، SBAR — كلها تُعاد بتخطيط لوحة طوارئ. |
| **الشاشات الناقصة** | (أ) لوحة تتبّع ED Tracker (سرير/حالة/مؤقّت/مهام معلقة) فوق قائمة الانتظار الحالية؛ (ب) سجل إنعاش Code Blue بخط زمني (أدوية/صدمات/CPR) — يستفيد من GCS بمحرك الدرجات؛ (ج) شاشة مراقبة متكررة بفواصل حسب ESI مع تنبيه تأخّر؛ (د) توثيق إجراءات (قسطرة/خياطة/تجبير). |
| **التقييمات** | NEWS2/MEWS (محرك موجود)، GCS (محرك موجود)، ألم، سقوط Morse سريع، NIHSS لمسار السكتة (محرك موجود)، سلم تصعيد Gate 2. |
| **الصلاحيات** | دور `NURSE_ED`: تنفيذ أوامر، توثيق إعطاء دواء، توثيق إنعاش، طلب استشارة تمريضية؛ الأدوية عالية الخطورة تتطلب توقيعاً ثانياً. |
| **الأزرار** | [استلام من الفرز] [تنفيذ أمر] [إعطاء دواء] [بدء سجل إنعاش] [تسجيل علامات] [طلب نقل داخلي] [تجهيز تنويم] [خروج تمريضي] |
| **Handover** | SBAR بين الورديات + **I-PASS إلزامي** عند التنويم (طوارئ→جناح/ICU) مع إقرار استلام إلكتروني من التمريض المستقبِل (حلقة مغلقة). |
| **مؤشرات الجودة** | زمن باب→دواء حرج (مضاد حيوي إنتان <60 د)، % مراقبة في موعدها حسب ESI، مدة المكوث LOS بالطوارئ، % تسليم I-PASS مكتمل، أخطاء دواء لكل 1000 زيارة. |

### 4.3 تمريض العيادات الخارجية (OPD Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | تحضير المريض قبل الطبيب: علامات حيوية، وزن/طول/BMI، مطابقة أدوية منزلية، تطعيمات، فحوصات نقطة رعاية (سكر/ضغط)، تثقيف مقتضب. |
| **موجود في v1** | العلامات الحيوية ضمن التقييم، eMAR (للقاحات)، ملاحظات. قسم OPD نفسه **مفقود** بالكتالوج — هذه المحطة تُبنى معه. |
| **الشاشات الناقصة** | (أ) طابور تحضير مرتبط بالمواعيد (وصل→تحضير→جاهز للطبيب)؛ (ب) شاشة مطابقة أدوية منزلية (Medication Reconciliation) تغذي الصيدلية السريرية؛ (ج) شاشة تطعيمات مرتبطة بوحدة تحصين الأطفال الموجودة-الناقصة؛ (د) نتائج نقطة الرعاية POCT. |
| **التقييمات** | علامات حيوية + BMI، ألم، PHQ-2 فرز اكتئاب اختياري، PEWS مبسّط لعيادات الأطفال، إنذار تصعيد (قراءة حرجة → تحويل طوارئ). |
| **الصلاحيات** | دور `NURSE_OPD`: تحضير، توثيق لقاح، POCT، لا وصول لملفات التنويم إلا للقراءة عبر HIM. |
| **الأزرار** | [استدعاء للتحضير] [حفظ العلامات] [مطابقة أدوية] [تسجيل لقاح] [جاهز للطبيب] [تصعيد للطوارئ] |
| **Handover** | ملخص تحضير يظهر بمحطة الطبيب v3 قبل الدخول؛ لا وردية سريرية — التسليم = اكتمال التحضير. |
| **مؤشرات الجودة** | % مرضى مكتملي التحضير قبل الطبيب، زمن وصول→تحضير، % مطابقة أدوية موثقة، % لقاحات موثقة بالسجل، تصعيدات حرجة مكتشفة بالعيادة. |

### 4.4 تمريض التنويم (Inpatient/Ward Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | رعاية المريض المنوَّم: تقييم قبول خلال 24 ساعة، جولات ساعية، NEWS2 دوري، eMAR، وقاية سقوط وقرح، خطة رعاية، تحضير خروج. النواة الأقرب لمحطة v1 الحالية. |
| **موجود في v1** | الأغلبية: NEWS2/eMAR/تقييم/خطة رعاية/سوائل/SBAR/مخاطر/أوامر/ملاحظات. |
| **الشاشات الناقصة** | (أ) لوحة جناح (Ward Whiteboard) بكل الأسرّة — تعتمد على إدارة الأسرّة المركزية (فجوة عليا بالكتالوج)؛ (ب) توزيع المرضى على الممرضات (Assignment) بحسب الحدة Acuity؛ (ج) جولات ساعية موثقة (Hourly Rounding 4Ps)؛ (د) تكامل تصعيد EWS تلقائي (المحرك موجود — تنقصه شاشة الاستجابة وإقرار التصعيد). |
| **التقييمات** | NEWS2 (موجود)، Morse للسقوط، Braden للقرح، ألم، تغذية MUST، VTE تمريضي مساعد، Humpty Dumpty لأجنحة الأطفال (مع PEWS من المحرك). |
| **الصلاحيات** | دور `NURSE_WARD`: كامل القشرة + توزيع (لرئيسة الوردية `CHARGE_NURSE` فقط)، إقرار تصعيد EWS، لا إلغاء أوامر طبيب. |
| **الأزرار** | [قبول تمريضي] [جولة ساعية] [تسجيل NEWS2] [إعطاء دواء] [تحديث خطة الرعاية] [إقرار تصعيد] [طلب مرافقة نقل] [تجهيز خروج] |
| **Handover** | SBAR وردية إلزامي لكل مريض + تسليم بجانب السرير (Bedside Handover) بقائمة تحقق؛ تقرير رئيسة وردية إجمالي للجناح. |
| **مؤشرات الجودة** | سقوط لكل 1000 يوم-مريض، قرح ضغط مكتسبة HAPI%، % NEWS2 في موعدها، % استجابة تصعيد خلال الزمن المستهدف، % جولات ساعية موثقة، ساعات تمريض لكل يوم-مريض NHPPD. |

### 4.5 تمريض العناية المركزة ICU / CCU / PICU

| البند | التفصيل |
|---|---|
| **النطاق** | مريض حرج بأجهزة دعم: مراقبة ساعية، منافذ وريدية مركزية، تهوية آلية، أدوية مضبوطة بالتنقيط، تسكين/تهدئة، وقاية VAP/CLABSI/CAUTI. PICU للأطفال بنفس البنية مع مقاييس أطفال. |
| **موجود في v1** | القشرة كاملة أساس، سوائل I&O (تمتد لساعية)، أوامر CPOE (الوريدية موجودة بمحطة الطبيب v3). |
| **الشاشات الناقصة** | (أ) ورقة تدفق ساعية ICU Flowsheet (علامات/تهوية/تنقيط/موازنة) — أهم شاشة؛ (ب) إدارة الخطوط والأنابيب (Lines/Tubes/Drains) بأعمار الخطوط وتنبيه إزالة؛ (ج) لوحة تنقيط الأدوية المضبوطة (معدل/تركيز/توقيع مزدوج)؛ (د) حزم الوقاية Bundles (VAP/CLABSI/CAUTI) بقوائم تحقق يومية تغذي مكافحة العدوى؛ (هـ) تقييم تهدئة/هذيان دوري. |
| **التقييمات** | MEWS (محرك موجود)، SOFA/APACHE (محرك موجود — عرض تمريضي)، GCS (موجود)، **RASS** تهدئة (جديد)، **CAM-ICU** هذيان (جديد)، **CPOT** ألم غير الواعين (جديد)، Braden، PEWS لـ PICU (محرك موجود)، Comfort-B لأطفال منوّمين (جديد). |
| **الصلاحيات** | دور `NURSE_ICU`: توثيق ساعي، معايرة تنقيط ضمن أمر طبي محدد المدى (Titration Order)، توقيع ثانٍ إلزامي للأدوية عالية الخطورة، صلاحية عرض SOFA/APACHE دون تعديل مدخلات الطبيب. |
| **الأزرار** | [تسجيل ساعة] [معايرة تنقيط] [توقيع شاهد] [حزمة VAP اليوم] [حزمة CLABSI] [تقييم RASS/CAM] [موازنة سوائل] [تصعيد طبيب] |
| **Handover** | **I-PASS إلزامي** (Illness severity / Patient summary / Action list / Situation awareness / Synthesis) مع إقرار المستلم؛ تسليم منفصل لكل جهاز/خط. |
| **مؤشرات الجودة** | CLABSI و CAUTI و VAP لكل 1000 يوم-جهاز، % امتثال الحزم، % اكتمال الورقة الساعية، أحداث نقص تهدئة/فرطها، إعادة قبول ICU خلال 48 ساعة، قرح ضغط بالعناية. |

### 4.6 تمريض حديثي الولادة NICU

| البند | التفصيل |
|---|---|
| **النطاق** | الوليد الخديج/المريض: حاضنات، تغذية أنبوبية/رضاعة، علاج ضوئي، مراقبة تنفسية، أمان هوية الوليد (سوار مزدوج أم-وليد)، دعم الأم. القسم **مفقود** بالكتالوج رغم جاهزية APGAR — تُبنى المحطة مع القسم. |
| **موجود في v1** | القشرة أساس + APGAR بمحرك الدرجات جاهز للربط. |
| **الشاشات الناقصة** | (أ) ملف وليد مرتبط بملف الأم (رابط أم-وليد إلزامي، هوية مزدوجة)؛ (ب) ورقة تدفق وليدية (حرارة حاضنة/تشبع/أوكسجين/وزن يومي)؛ (ج) شاشة تغذية (رضاعة/حليب مسحوب/أنبوبية بمليلترات وسعرات)؛ (د) علاج ضوئي (بيليروبين ورسم منحنى)؛ (هـ) تحصينات وفحص وليدي (كعب القدم/سمع) بربط وحدة التحصين الموجودة-الناقصة. |
| **التقييمات** | **APGAR** (محرك موجود — يُوصَل)، **Ballard** لعمر الحمل (جديد)، **NIPS/N-PASS** ألم وليدي (جديد)، PEWS وليدي (تهيئة المحرك الموجود)، منحنيات نمو WHO، تقييم انسحاب NAS-Finnegan عند الحاجة (جديد). |
| **الصلاحيات** | دور `NURSE_NICU`: توثيق وليدي، تغذية، علاج ضوئي؛ حساب جرعات بالوزن يظهر للقراءة من الصيدلية السريرية؛ ممنوع فك رابط أم-وليد إلا بصلاحية مشرفة + سبب موثق (Audit). |
| **الأزرار** | [ربط أم-وليد] [تسجيل APGAR] [تقييم Ballard] [وجبة تغذية] [وزن يومي] [بدء/إنهاء علاج ضوئي] [فحص وليدي] [تنبيه اختطاف/أمان] |
| **Handover** | I-PASS وليدي + تحقق هوية سوارين عند كل تسليم؛ تسليم مزدوج عند نقل الوليد بين الحضانة والأم. |
| **مؤشرات الجودة** | % APGAR موثق خلال دقيقة/5 دقائق، انخفاض حرارة عند القبول%، أخطاء هوية وليد (هدف صفر)، % فحص وليدي مكتمل قبل الخروج، عدوى مجرى دم وليدية، % رضاعة طبيعية عند الخروج. |

### 4.7 تمريض العمليات (Perioperative Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | ثلاث مراحل: قبل الجراحة (تحضير وقائمة تحقق)، أثناءها (ممرضة متجولة Circulating + معقّمة Scrub)، وتوثيق العدّ والعينات والأجهزة. قسم العمليات موجود-مكتمل لكن **بلا توثيق تمريض جراحي** — أخطر فجوة سلامة مع التخدير/PACU. |
| **موجود في v1** | القشرة (تقييم/ملاحظات/أوامر) أساس فقط؛ لا شيء جراحي متخصص. |
| **الشاشات الناقصة** | (أ) قائمة تحقق جراحة آمنة WHO (Sign-in / **Time-out** / Sign-out) بتوقيعات الفريق؛ (ب) **سجل عدّ الأدوات والشاش والإبر** (قبل/أثناء/بعد + تسوية إلزامية)؛ (ج) سجل تمريض العمليات Intraoperative Record (وضعية المريض/كي كهربائي/رباط ضاغط/غسيل)؛ (د) تتبع العينات الجراحية → علم الأمراض؛ (هـ) تتبع أطقم التعقيم بربط CSSD الموجود-الناقص؛ (و) شاشة تحضير قبل الجراحة (صيام/حلاقة/مضاد حيوي وقائي/إزالة طقم). |
| **التقييمات** | قائمة تحقق قبل الجراحة، تقييم جلد قبل/بعد الوضعية، تقييم خطر انخفاض حرارة، تحقق موقع الجراحة وعلامته. |
| **الصلاحيات** | دور `NURSE_OR` (متجولة) ودور فرعي `NURSE_SCRUB`: توثيق العدّ يتطلب توقيعين (Scrub + Circulating)؛ إغلاق Sign-out محجوب حتى تسوية العدّ أو توثيق تصوير شعاعي للتحقق. |
| **الأزرار** | [Sign-in] [Time-out] [بدء عدّ] [عدّ ختامي] [تسوية/عدم تطابق عدّ] [تسجيل عينة] [Sign-out] [تسليم إلى PACU] |
| **Handover** | تسليم منظَّم OR→PACU (نوع الجراحة/التخدير/الضياع الدموي/الخطوط/أحداث) موقَّع من ممرضة العمليات وممرضة الإفاقة — لا يُفتح ملف PACU دون استلامه. |
| **مؤشرات الجودة** | % Time-out موثق قبل الشق (هدف 100%)، حوادث عدّ غير متطابق، أجسام متروكة (صفر أبداً — Never Event → OVR)، % مضاد حيوي وقائي خلال 60 دقيقة، % تسليم OR→PACU مكتمل، انخفاض حرارة بعد الجراحة%. |

### 4.8 تمريض الإفاقة PACU

| البند | التفصيل |
|---|---|
| **النطاق** | مراقبة ما بعد التخدير حتى استيفاء معايير الخروج: مجرى هواء، وعي، ألم، غثيان، مراقبة كل 5–15 دقيقة. **مفقود كلياً** — يُبنى مع قسمي التخدير وPACU (أخطر فجوة بالكتالوج). |
| **موجود في v1** | القشرة أساس (علامات/ألم/eMAR)؛ لا مقاييس إفاقة. |
| **الشاشات الناقصة** | (أ) ورقة تدفق PACU بفواصل 5/10/15 دقيقة وخط زمني؛ (ب) شاشة **Aldrete** بحساب تلقائي واتجاه؛ (ج) معايير خروج (Aldrete ≥9 أو معايير الطبيب) مع **قفل خروج** دون استيفاء أو توقيع طبيب تخدير؛ (د) توثيق PONV وعلاجه؛ (هـ) استلام تسليم OR→PACU. |
| **التقييمات** | **Aldrete** (جديد — يضاف لمحرك الدرجات)، **Bromage** للتخدير النصفي (جديد)، ألم، PONV، RASS عند التهدئة العميقة، PAED لهياج أطفال ما بعد التخدير (جديد). |
| **الصلاحيات** | دور `NURSE_PACU`: توثيق Aldrete/Bromage، أدوية ألم ضمن أوامر PRN، **لا خروج من PACU** إلا باستيفاء المعايير آلياً أو توقيع `PHYSICIAN_ANESTHESIA`. |
| **الأزرار** | [استلام من العمليات] [تسجيل Aldrete] [تسجيل Bromage] [إعطاء مسكن] [توثيق PONV] [طلب طبيب تخدير] [استيفاء معايير الخروج] [تسليم للجناح] |
| **Handover** | استلام OR→PACU إلزامي عند الدخول + تسليم PACU→جناح بنموذج معايير خروج موقَّع؛ حلقة إقرار من ممرضة الجناح. |
| **مؤشرات الجودة** | % Aldrete موثق بالفواصل المقررة، مدة مكوث PACU، أحداث تنفسية بالإفاقة لكل 100 حالة، % خروج مستوفي المعايير (هدف 100%)، عودة غير مخططة لغرفة العمليات، ألم شديد غير مسيطر عند الخروج%. |

### 4.9 تمريض النساء والولادة (Obstetric Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | مخاض وولادة ونفاس: مراقبة الجنين، الطلق، الولادة الطبيعية/القيصرية (مع تمريض العمليات)، النزف بعد الولادة، رعاية النفاس، بدء الرضاعة، ربط الوليد. قسم النساء والتوليد موجود-مكتمل لكن **بلا محطة تمريض ولادة**. |
| **موجود في v1** | القشرة + بيانات الحمل من قسم OB الموجود (بعد إصلاح Gate 6 لتظليل المسارات). |
| **الشاشات الناقصة** | (أ) **Partograph إلكتروني** (اتساع عنق الرحم/نزول الرأس/انقباضات/نبض الجنين) بخط إنذار وخط فعل؛ (ب) ورقة مراقبة جنين FHR بتوثيق دوري؛ (ج) سجل ولادة (زمن/نوع/بضع/مشيمة/نزف مقدَّر EBL)؛ (د) شاشة نفاس (قاع رحم/هبر/ثدي/جرح قيصرية) بجولات 15 دقيقة أول ساعتين؛ (هـ) بروتوكول نزف PPH بميزان كمي وتفعيل فريق. |
| **التقييمات** | **MEOWS** إنذار مبكر توليدي (جديد — تهيئة محرك EWS)، **Bishop** لتقييم عنق الرحم (جديد)، APGAR للوليد (محرك موجود)، ألم مخاض، خطر VTE نفاسي، **EPDS** اكتئاب ما بعد الولادة عند المتابعة (جديد)، Bromage بعد إبيدورال (مشترك مع PACU). |
| **الصلاحيات** | دور `NURSE_OB` + دور `MIDWIFE` (قابلة قانونية: توثيق ولادة طبيعية ضمن نطاقها)؛ تفعيل إنذار PPH متاح للجميع؛ توثيق APGAR خلال النافذة الزمنية فقط. |
| **الأزرار** | [بدء Partograph] [تسجيل FHR] [تسجيل انقباضات] [توثيق ولادة] [APGAR 1/5/10 د] [تفعيل إنذار نزف] [جولة نفاس] [بدء رضاعة] [ربط أم-وليد] |
| **Handover** | تسليم مزدوج (أم + وليد) لكل وردية؛ تسليم غرفة ولادة→نفاس وغرفة ولادة→NICU عند الحاجة بنموذج I-PASS وليدي. |
| **مؤشرات الجودة** | % Partograph مكتمل للولادات، زمن اكتشاف→استجابة PPH، % APGAR موثق بالنوافذ الزمنية، % ولادة قيصرية بمراقبة نفاس مكتملة، % بدء رضاعة خلال ساعة، % MEOWS في موعدها. |

### 4.10 تمريض نقل الدم (Transfusion Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | حلقة الإعطاء الآمن: طلب→استلام الوحدة من بنك الدم (موجود-مكتمل)→تحقق ثنائي بجانب السرير→مراقبة أثناء وبعد النقل→بلاغ تفاعل. تمتد عبر كل الأقسام السريرية (ليست موقعاً بل كفاءة Compliance). |
| **موجود في v1** | العلامات الحيوية وeMAR أساس؛ بنك الدم موجود كقسم لكن **حلقة التمريض عند السرير مفقودة**. |
| **الشاشات الناقصة** | (أ) شاشة **تحقق ثنائي إلزامي** (ممرضتان: هوية المريض/فصيلة/رقم الوحدة/توافق/تاريخ صلاحية) بتوقيعين قبل تفعيل بدء النقل؛ (ب) ورقة مراقبة نقل (قبل البدء/15 دقيقة/كل ساعة/عند الانتهاء)؛ (ج) شاشة بلاغ تفاعل نقل (إيقاف/عينات/إخطار بنك الدم والطبيب) تغذي OVR؛ (د) تتبع زمن خروج الوحدة من البنك (قاعدة 30 دقيقة). |
| **التقييمات** | علامات حيوية بالجدول الإلزامي، مقياس تفاعل نقل (حمى/طفح/ضيق نفس)، موازنة سوائل للوحدات المتعددة. |
| **الصلاحيات** | كفاءة `COMP_TRANSFUSION` تُمنح فوق أي دور تمريضي بعد اعتماد تدريبي؛ زر [بدء النقل] محجوب دون توقيعَي التحقق؛ بلاغ التفاعل يفتح تلقائياً سجل OVR سري. |
| **الأزرار** | [استلام وحدة] [تحقق ثنائي] [بدء النقل] [مراقبة 15 د] [إيقاف فوري] [بلاغ تفاعل] [إنهاء وإعادة الكيس] |
| **Handover** | نقل جارٍ بين ورديتين = تسليم موثّق إلزامي باسم الوحدة وزمن البدء والمراقبة التالية المستحقة. |
| **مؤشرات الجودة** | % تحقق ثنائي موثق (هدف 100%)، تفاعلات نقل لكل 1000 وحدة، % مراقبة 15 دقيقة في موعدها، وحدات مهدرة بسبب تجاوز الزمن، أخطاء ABO (Never Event → OVR). |

### 4.11 تمريض مكافحة العدوى (Infection Control Nursing)

| البند | التفصيل |
|---|---|
| **النطاق** | ممرضة مكافحة العدوى ICN: ترصد HAI (CLABSI/CAUTI/VAP/SSI)، جولات نظافة الأيدي، إدارة العزل، التحقيق بالفاشيات، صحة الموظفين (وخز إبر/تطعيمات). القسم موجود-ناقص (هيكلي) — هذه المحطة تملؤه. |
| **موجود في v1** | لا شيء متخصص؛ تتغذى من حزم ICU (4.5) وسجل العمليات (4.7). |
| **الشاشات الناقصة** | (أ) لوحة ترصد HAI بمعدلات لكل 1000 يوم-جهاز ورسوم اتجاه؛ (ب) سجل حالات عدوى مؤكدة بتعريفات CDC/NHSN مبسّطة؛ (ج) شاشة جولات نظافة الأيدي (لحظات WHO الخمس) بإدخال ملاحظة ميدانية؛ (د) إدارة أوامر العزل (تلامسي/رذاذي/هوائي) بشارة على ملف المريض تظهر لكل المحطات؛ (هـ) سجل وخز إبر وتعرض مهني (مرتبط بالموارد البشرية). |
| **التقييمات** | معايير تشخيص HAI، قوائم امتثال الحزم Bundles، تدقيق تعقيم بربط CSSD، تقييم جاهزية عزل. |
| **الصلاحيات** | دور `NURSE_IC`: قراءة عابرة للأقسام (ترصد) عبر صلاحية قراءة موسعة **بتسجيل تدقيق كامل**، إصدار/رفع أمر عزل، لا تعديل ملفات سريرية علاجية. |
| **الأزرار** | [تسجيل حالة HAI] [جولة نظافة أيدٍ] [فرض عزل] [رفع عزل] [بلاغ فاشية] [تدقيق حزمة] [بلاغ وخز إبرة] |
| **Handover** | تقرير ترصد أسبوعي/شهري للجنة مكافحة العدوى (إدارة اللجان مستقبلاً)؛ تنبيهات عزل تنتقل تلقائياً مع أي نقل مريض. |
| **مؤشرات الجودة** | معدلات CLABSI/CAUTI/VAP/SSI، % امتثال نظافة الأيدي، % امتثال الحزم، زمن فرض العزل من الاشتباه، فاشيات مكتشفة/مغلقة، % تغطية تطعيم الكادر. |

### 4.12 التثقيف الصحي التمريضي (Patient Education)

| البند | التفصيل |
|---|---|
| **النطاق** | تثقيف المريض والأسرة: أدوية، تغذية، عناية بالجروح، أمراض مزمنة (سكري/ضغط/ربو)، ما قبل وبعد الجراحة، بلغة المريض وبتقييم فهمه (Teach-back). |
| **موجود في v1** | الملاحظات فقط؛ القسم **مفقود** (Optional بالكتالوج). |
| **الشاشات الناقصة** | (أ) مكتبة مواد تثقيفية عربية/إنجليزية بتصنيف حالة؛ (ب) سجل جلسة تثقيف (موضوع/طريقة/حضور الأسرة/Teach-back ناجح؟)؛ (ج) خطة تثقيف مرتبطة بخطة الرعاية والتشخيصات؛ (د) دفع مواد لبوابة المرضى الموجودة-الناقصة. |
| **التقييمات** | تقييم جاهزية التعلم (لغة/حواجز/معرفة سابقة)، نتيجة Teach-back (فهم كامل/جزئي/إعادة). |
| **الصلاحيات** | كل الأدوار التمريضية توثّق تثقيفاً؛ إدارة المكتبة لدور `NURSE_EDUCATOR`. |
| **الأزرار** | [جلسة تثقيف جديدة] [Teach-back] [إرسال للبوابة] [طباعة مادة] [إحالة لمثقّف] |
| **Handover** | حالة التثقيف (مكتمل/ناقص) بند إلزامي في ملخص الخروج التمريضي (4.13). |
| **مؤشرات الجودة** | % مرضى خروج بتثقيف موثق، % Teach-back ناجح، % تثقيف أدوية عالية الخطورة (مضادات تخثر/أنسولين)، رضا المرضى عن الفهم. |

### 4.13 تمريض الخروج والرعاية المنزلية (Discharge & Home Care)

| البند | التفصيل |
|---|---|
| **النطاق** | تخطيط الخروج من يوم القبول: تقييم احتياج ما بعد الخروج، تعليمات، مطابقة أدوية خروج، مواعيد متابعة، إحالة رعاية منزلية/اجتماعية، متابعة هاتفية بعد الخروج. |
| **موجود في v1** | خطة الرعاية والملاحظات أساس؛ الخدمة الاجتماعية موجودة-ناقصة كقسم مستقل تُحال إليها. |
| **الشاشات الناقصة** | (أ) قائمة تحقق خروج تمريضية (أدوية/تعليمات/مواعيد/أجهزة منزلية/نقل)؛ (ب) مطابقة أدوية خروج (تغذي الصيدلية السريرية وبوابة المرضى)؛ (ج) شاشة تقييم خطر إعادة القبول؛ (د) سجل زيارة/مكالمة متابعة بعد الخروج (48–72 ساعة)؛ (هـ) خطة رعاية منزلية (جروح/قسطرة/أنبوب تغذية) للفرق المنزلية. |
| **التقييمات** | **LACE** أو مؤشر إعادة قبول مبسّط (جديد)، **Barthel/ADL** استقلالية (جديد)، تقييم أمان المنزل، جاهزية مقدم الرعاية. |
| **الصلاحيات** | دور `NURSE_DISCHARGE` (منسقة خروج) + `NURSE_HOMECARE` بوصول ميداني مقيَّد (ملفات مرضاها المحالين فقط — RLS). |
| **الأزرار** | [بدء خطة خروج] [قائمة تحقق الخروج] [مطابقة أدوية خروج] [حجز متابعة] [إحالة رعاية منزلية] [مكالمة متابعة] [إغلاق حلقة الخروج] |
| **Handover** | ملخص خروج تمريضي موحّد يُرسل لبوابة المريض ولفريق الرعاية المنزلية؛ حلقة مغلقة: لا يُغلق ملف الخروج قبل توثيق المكالمة/الزيارة الأولى. |
| **مؤشرات الجودة** | إعادة قبول 30 يوماً%، % قوائم خروج مكتملة، % مكالمات متابعة خلال 72 ساعة، % مطابقة أدوية خروج، متوسط زمن قرار الخروج→مغادرة فعلية. |

### 4.14 eMAR / MAR — إدارة الدواء التمريضية (كفاءة عرضية)

| البند | التفصيل |
|---|---|
| **النطاق** | حلقة الدواء المغلقة من منظور التمريض: استلام أمر CPOE→تحضير→تحقق (الحقوق الخمسة)→إعطاء→توثيق→مراقبة أثر؛ الأدوية عالية الخطورة والمخدرة والوريدية المضبوطة. |
| **موجود في v1** | تبويب eMAR موجود ويعمل، متكامل مع CPOE v3 (وصفات + Refill + QtyTotal) والأوامر الوريدية. |
| **الفجوات الوظيفية** | (أ) **تحقق ثنائي إلكتروني** للأدوية عالية الخطورة (أنسولين/هيبارين/كيماوي/إلكتروليتات مركزة) — توقيع شاهد إلزامي؛ (ب) **سجل مواد مخدرة** (عدّ الوردية بتوقيعين + تسوية هدر)؛ (ج) توثيق سبب عدم الإعطاء (رفض/صيام/غياب) بقائمة مقننة؛ (د) تنبيه جرعة فائتة/متأخرة على لوحة المحطة؛ (هـ) إطار BCMA مسح باركود مريض-دواء (مرحلة لاحقة)؛ (و) عرض تحذيرات التداخلات من الصيدلية السريرية وقت الإعطاء. |
| **التقييمات** | مراقبة ما بعد الإعطاء للأدوية الخطرة (علامات/سكر/تسكين)، تقييم ألم قبل/بعد المسكن. |
| **الصلاحيات** | الإعطاء لدور تمريضي مرخّص فقط؛ المخدرات تتطلب كفاءة `COMP_NARCOTICS` وتوقيعين؛ لا تعديل جرعة — أي تغيير يعود للطبيب عبر CPOE. |
| **الأزرار** | [استحقاق الآن] [تحضير] [توقيع شاهد] [إعطاء] [عدم إعطاء + سبب] [عدّ مخدرات] [توثيق هدر] [مراقبة بعد الإعطاء] |
| **Handover** | تسليم أدوية معلّقة/متأخرة وجرعات مخدرة وعدّ الخزنة بين الورديتين بتوقيع مزدوج. |
| **مؤشرات الجودة** | أخطاء دواء لكل 1000 جرعة، % جرعات في نافذة ±30/60 دقيقة، % تحقق ثنائي للأدوية الخطرة (هدف 100%)، فروق عدّ مخدرات (صفر)، % توثيق سبب عدم الإعطاء. |

## 6. مصفوفة الصلاحيات التمريضية (RBAC فوق RLS)

المبدأ: **الدور الوظيفي × الكفاءة المعتمدة × نطاق الوحدة**. الصلاحيات الحالية بفهرس القائمة (44 قسماً) تبقى الطبقة الأولى؛ تضاف طبقة أدوار تمريضية داخل المحطة. RLS يضمن عزل المستأجر؛ هذه المصفوفة تضبط الفعل داخل المستأجر.

| الدور | القراءة | التوثيق السريري | إعطاء دواء | توقيع شاهد | فرز/تصعيد | إدارة (توزيع/اعتماد) | حدود صريحة |
|---|---|---|---|---|---|---|---|
| `NURSE_TRIAGE` | مرضى الطوارئ | فرز فقط | لا | لا | نعم (ESI/إنذار إنتان) | لا | لا eMAR |
| `NURSE_ED` | مرضى الطوارئ | كامل الطوارئ | نعم | نعم | تصعيد | لا | لا إغلاق زيارة |
| `NURSE_OPD` | مرضى عياداته | تحضير/لقاح/POCT | لقاحات فقط | لا | تصعيد للطوارئ | لا | لا ملفات تنويم كتابةً |
| `NURSE_WARD` | مرضى جناحه | كامل التنويم | نعم | نعم | إقرار تصعيد EWS | لا | لا إلغاء أوامر طبيب |
| `NURSE_ICU` | مرضى وحدته | كامل + ساعي | نعم + معايرة ضمن أمر | نعم | تصعيد | لا | معايرة ضمن مدى الأمر فقط |
| `NURSE_NICU` | ولدان وحدته + رابط الأم | كامل وليدي | نعم (وزنية) | نعم | تصعيد | لا | فك رابط أم-وليد بمشرفة+سبب |
| `NURSE_OR` / `NURSE_SCRUB` | جدول عملياته | سجل جراحي/عدّ | لا (تخدير للطبيب) | نعم (عدّ) | إيقاف Time-out | لا | لا Sign-out دون تسوية عدّ |
| `NURSE_PACU` | مرضى الإفاقة | Aldrete/Bromage | PRN ضمن أمر | نعم | استدعاء تخدير | لا | لا خروج دون معايير/توقيع طبيب |
| `NURSE_OB` / `MIDWIFE` | أمهات وولدان | Partograph/ولادة/نفاس | نعم | نعم | إنذار PPH | لا | القابلة ضمن نطاق ترخيصها |
| `NURSE_IC` | **قراءة عابرة للأقسام (مدقَّقة)** | ترصد/عزل | لا | لا | فرض/رفع عزل | تدقيق حزم | لا كتابة علاجية |
| `NURSE_EDUCATOR` | مرضاه المحالون | جلسات تثقيف | لا | لا | لا | إدارة المكتبة | — |
| `NURSE_DISCHARGE` / `NURSE_HOMECARE` | مرضى الخروج/الإحالة | خطة خروج/زيارة منزلية | ضمن خطة منزلية | لا | تصعيد | لا | HOMECARE مقيّد بمرضاه (RLS) |
| `CHARGE_NURSE` (رئيسة وردية) | وحدتها كاملة | + توزيع | نعم | نعم | نعم | توزيع/اعتماد Handover | لا صلاحيات نظام |
| `NURSE_SUPERVISOR` (مشرفة) | المنشأة (تمريضياً) | اعتمادات استثنائية | لا | نعم | نعم | كفاءات/تجاوزات موثقة | كل تجاوز → سجل تدقيق |
| كفاءات عرضية | `COMP_TRANSFUSION`، `COMP_NARCOTICS`، `COMP_CHEMO`، `COMP_PICC` — تُمنح وتنتهي بتاريخ، وتحجب الأزرار الحرجة عند غيابها | | | | | | |

## 7. إطار Handover الموحد — حلقة مغلقة

| الانتقال | النموذج | الإلزام | الآلية |
|---|---|---|---|
| وردية→وردية (كل الوحدات) | SBAR (موجود v1) + تسليم بجانب السرير | إلزامي لكل مريض | قائمة مرضى بحالة "سُلِّم/لم يُسلَّم"؛ لا إغلاق وردية بقائمة ناقصة |
| فرز→طوارئ | SBAR مختصر | إلزامي قبل السرير | يُنشأ تلقائياً من بيانات الفرز |
| طوارئ→تنويم / أي نقل بين وحدات | **I-PASS** (جديد فوق SBAR) | إلزامي + **إقرار استلام إلكتروني** | لا يكتمل النقل بإدارة الأسرّة دون إقرار الطرف المستقبِل |
| OR→PACU | نموذج جراحي-تخديري مخصص | إلزامي بتوقيعين | يحجب فتح ملف PACU |
| PACU→جناح | معايير خروج + Aldrete أخير | إلزامي | قفل خروج آلي |
| ولادة→نفاس / ولادة→NICU | تسليم مزدوج (أم+وليد) | إلزامي | تحقق سوارين |
| نقل دم جارٍ بين ورديتين | ملحق تسليم نقل الدم | إلزامي | زمن المراقبة التالية ينتقل للوردية الجديدة |
| خروج→منزل/رعاية منزلية | ملخص خروج تمريضي | إلزامي | حلقة تُغلق بمكالمة المتابعة |

**قاعدة النظام:** كل Handover كيان مستقل قابل للتدقيق (مَن سلّم، مَن استلم، متى، ماذا تضمّن) — يغذي عارض سجل التدقيق والامتثال (فجوة J بالكتالوج).

## 8. لوحة مؤشرات الجودة التمريضية الموحدة (Nursing Quality Dashboard)

تتجمع مؤشرات الأقسام 4.1–4.14 في لوحة واحدة داخل قسم الجودة وسلامة المرضى (موجود-مكتمل)، بنمط NDNQI ومتطلبات CBAHI:

| المحور | المؤشرات المجمّعة | المصدر |
|---|---|---|

| عدوى المستشفيات | CLABSI/CAUTI/VAP/SSI، امتثال نظافة الأيدي والحزم | مكافحة العدوى، ICU، عمليات |

| تجربة المريض | تثقيف موثق%، Teach-back ناجح%، رضا عن التمريض | تثقيف، بوابة المرضى |

## 9. خارطة البناء والأولويات (تخطيط فقط — لا تنفيذ)

| موجة | النطاق | مبررات السلامة |
|---|---|---|
| **N1 (P1)** | PACU + Aldrete/Bromage، تمريض العمليات (WHO Checklist + العدّ)، تمريض ICU (ورقة ساعية + RASS/CAM/CPOT + حزم)، إكمال eMAR (تحقق ثنائي + مخدرات)، ترقية الفرز/الطوارئ (تصعيد إنتان + I-PASS)، تقنين Morse/Braden بالتنويم | يغلق أخطر فجوة (تخدير/إفاقة بلا توثيق) وأعلى مخاطر الدواء |
| **N2 (P2)** | تمريض الولادة (Partograph + MEOWS + PPH)، NICU (APGAR-ربط + Ballard + NIPS)، تمريض نقل الدم (تحقق ثنائي)، تفعيل محطة مكافحة العدوى (ترصد + عزل) | يكمل SafetyGates الولادية والدموية وشرطي CBAHI |
| **N3 (P3)** | تمريض العيادات (مع قسم OPD الجديد)، الخروج والرعاية المنزلية (LACE/Barthel + حلقة متابعة)، لوحة الجناح (مع إدارة الأسرّة المركزية) | يرفع الحجم التشغيلي واستمرارية الرعاية |
| **N4 (P4)** | التثقيف الصحي، BCMA باركود، لوحة الجودة التمريضية المجمّعة، تكامل بوابة المرضى | تحسين نضج وتميز |

**اعتماديات صريحة على فجوات الكتالوج:** إدارة الأسرّة المركزية (لوحات الأجنحة والنقل)، قسم التخدير (تسليم OR→PACU)، قسم NICU، قسم OPD، بلاغات OVR (تفاعلات النقل وNever Events)، عارض سجل التدقيق (تدقيق Handover والتجاوزات). كل الشاشات تُبنى ضمن نمط المنصة الحالي: Vanilla JS RTL ثنائي اللغة، صلاحيات بالفهرس + أدوار المحطة، RLS متعدد المستأجرين، وفلتر أنواع المنشآت الـ17 (منشأة بلا عمليات لا ترى محطات OR/PACU).
