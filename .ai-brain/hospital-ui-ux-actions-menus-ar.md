# 🎨 دليل واجهات المستخدم والإجراءات والأزرار (UI / UX / Actions / Menus Blueprint)

**التاريخ**: 2026-07-06 | **الحالة**: معتمد (GATE 9) | **المرجع التجميلي**: دليل تصميم الهوية البصرية لجمانة الطبي (Premium Dark/Teal Themes)

---

## 1. مكونات شاشات الأقسام الطبية (Core UI Frames)

لكل شاشة قسم طبي رئيسي في النظام، يجب تطبيق الهيكل البصري التالي لضمان توحيد التجربة وسهولة الاستخدام (Consistency):

```
┌────────────────────────────────────────────────────────────────────────┐
│ 👤 Patient Header Panel (الاسم، العمر، رقم الملف، الحساسيات، NEWS2)       │
├────────────────────────────────────────────────────────────────────────┤
│ 📂 Section Tab-Bar (العلامات الحيوية، eMAR، التقييمات، خطط الرعاية)     │
├────────────────────────────────────────────────────────────────────────┤
│ 🔍 Filters & Search (البحث بالاسم، التاريخ، الحالة السريرية)              │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                    🖥️ Active Workspace Area                            │
│           (نموذج إدخال البيانات، أو جدول البيانات السريرية)                │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ ⚡ Action Footer Bar (أزرار الحفظ، الإلغاء، الموافقة، الطباعة)              │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. شريط بيانات المريض (Patient Header Panel):
- يظهر في الجزء العلوي للملف الطبي.
- يعرض بصرياً: الاسم ثلاثياً، رقم الملف، العمر والنوع، والرمز اللوني لحالة NEWS2 خطورة (أخضر/أصفر/أحمر) وشريط الحساسية البارز باللون الأحمر في حال وجودها.

### 2. شريط التبويبات (Section Tab-Bar):
- تنقل أفقي سريع بدون تحميل كامل الصفحة (AJAX-based).
- أيقونات معبرة لكل تبويب وتسميات ثنائية اللغة (عربي/إنجليزي).

### 3. منطقة العمل النشطة (Active Workspace Area):
- تدعم اللغتين والعرض المناسب (RTL / LTR) باتجاه القراءة.
- النماذج تستخدم حقولاً واضحة ذات تلميحات مساعدة (Tooltips) لمنع الأخطاء في الإدخال.

## 2. كتالوج الأزرار المعتمد (Buttons Catalog)

يتم تنظيم أزرار الإجراءات بألوان تدل على طبيعة العملية لمنع الضغط بالخطأ:

| فئة الزر | اللون الافتراضي | لون النص | الاستخدام | مثال |
|---|---|---|---|---|
| **إجراء إيجابي/حفظ** | `#0d9488` (Teal) / `#16a34a` | أبيض | الحفظ، إرسال البيانات، الموافقة | "حفظ العلامات الحيوية"، "موافقة" |
| **إجراء سلبي/إلغاء** | `#9ca3af` (Gray) | أبيض | إلغاء، رجوع، إغلاق نافذة | "إلغاء الأمر"، "رجوع" |
| **إجراء حرج/خطير** | `#dc2626` (Red) | أبيض | حذف، إلغاء فاتورة، إيقاف أمر طبي | "حذف الوصفة"، "إيقاف صرف" |
| **تصعيد طوارئ STAT** | `#dc2626` + وميض | أبيض | تصعيد فوري للطبيب أو إنعاش | "ESCALATE TO DOCTOR" |
| **طباعة وتصدير** | `#ff9800` (Orange) | `#e65100` | طباعة التقارير، تصدير CSV | "طباعة SBAR"، "تصدير CSV" |
| **إجراء ثانوي** | خفي / شفاف | `#0ea5e9` | تفاصيل إضافية، فتح سجل تاريخي | "عرض التفاصيل" |

## 3. كتالوج القوائم والفلاتر (Menus & Filters Catalog)

لتسهيل الوصول للمعلومات في الشاشات الكبيرة وجداول البيانات:

### 1. قائمة الإجراءات السريعة (Quick Actions Menu):
- قائمة منسدلة (Dropdown) تظهر عند الضغط على أيقونة النقاط الثلاث `...` بجانب اسم المريض في جداول المتابعة تحتوي على:
  - "عرض الملف الطبي"
  - "إدخال علامات حيوية"
  - "إعطاء دواء (eMAR)"
  - "تسجيل فرز (Triage)"
  - "طلب تحويل"

### 2. فلاتر التصفية المعتمدة (Global Filters):
- **فلتر التاريخ**: تصفية حسب (اليوم، أمس، آخر 7 أيام، مخصص).
- **فلتر الحالة**: تصفية المرضى حسب (في الانتظار، مع الممرضة، مع الطبيب، تم التخريج).
- **فلتر الخطورة**: تصفية حسب مستوى فرز ESI (1-5) ومؤشر NEWS2 (حرج >= 7، متوسط 5-6، روتيني < 5).

## 📐 حالات شاشات واجهة المستخدم (UI State Matrix)

تلتزم جميع المكونات بعرض الحالات التالية لضمان تجربة مستخدم premium خالية من التباطؤ أو الارتباك:

1. **حالة التحميل (Loading State)**: استخدام Skeleton Loading رمادي متحرك يطابق هيكل البيانات الفعلي بدلاً من مؤشرات الدوران التقليدية (Spinners).
2. **حالة عدم وجود بيانات (Empty State)**: عرض أيقونة رمادية كبيرة معبرة، عنوان رئيسي، ووصف تفصيلي مع زر دعوة للإجراء (CTA) مثل "أضف أول علامة حيوية للمريض".
3. **حالة الخطأ (Error State)**: بطاقة بلون أحمر خفيف، أيقونة تحذير، شرح لسبب الخطأ، وزر "إعادة المحاولة" لإعادة تحميل البيانات.
4. **حالة منع الوصول (Permission Denied)**: قفل رمادي كبير، وتنبيه "لا تملك الصلاحيات الكافية للوصول لهذه الصفحة. يرجى التواصل مع مسؤول النظام".
5. **التعريب والاتجاه (RTL / LTR)**: دعم كامل للتبديل اللحظي بين العربية والانجليزية مع تغيير اتجاه الصفحة (Direction Mirroring) وقوائم الخطوط المتناسقة (Inter للانجليزية و Outfit/Tajawal للعربية).
