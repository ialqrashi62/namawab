# GATE 2 — الكتالوج الرئيسي للأقسام (Master Department Catalog)

**التاريخ**: 2026-07-06 | **المدخلات**: Gate 0 (جرد 44 قسماً) + Gate 1 (تحليل الفجوات) | **القرار**: ✅ PASS

## اصطلاحات

- **التصنيف**: Core (تشغيل أساسي) / Advanced (قيمة تنافسية) / Compliance (إلزام CBAHI/NPHIES/ZATCA/بيئي) / Optional (اختياري حسب المنشأة).
- **بوابة سلامة (Safety Gate)**: القسم يمس سلامة المريض مباشرة → تفعيل تدريجي + قوائم تحقق قبل الإطلاق.
- **بوابة موافقة (Approval Gate)**: يتضمن قرارات تتطلب اعتماد شخص مخوّل (طبيب استشاري/مدير مالي/مسؤول جودة) داخل سير العمل.
- **بوابة تدقيق (Audit Gate)**: كل حركة تُسجَّل بسجل تدقيق غير قابل للتعديل (مطلوب أصلاً في PHI/المال).
- **المرحلة**: 1 = فوري (سلامة/إيراد/إلزام) · 2 = توسعة (تخصصي/امتثال ثانوي) · 3 = لاحق (اختياري/مؤسسي).
- **الحالة**: موجود-مكتمل / موجود-ناقص (يشمل الهيكلي) / مفقود / دمج.
- فلتر نوع المنشأة (17 نوعاً) يبقى الحاكم: المنشأة الصغيرة لا ترى أقسام المستشفى المرجعي.

**الإجمالي النهائي**: 73 وحدة كتالوجية = 40 قائمة (بعد دمج 4) + 25 مفقودة + 6 كشف قدرات موجودة بالكود + 2 مستوعبة ضمن غيرها (تفصيل بالجداول).

## قواعد الإطلاق (Gates)

1. **Safety Gate**: أي قسم موسوم «سلامة = نعم» يُطلق خلف علم تفعيل (feature flag) لكل مستأجر + فترة observe-only + قائمة تحقق سريرية موقعة.
2. **Approval Gate**: تدفقات الاعتماد تُبنى بصلاحيات أدوار (RBAC) فوق RLS القائمة — لا اعتماد ذاتي (maker–checker).
3. **Audit Gate**: كل الأقسام PHI/مالية تكتب في سجل تدقيق غير قابل للتعديل؛ العارض الجديد (المجموعة J) قراءة فقط بصلاحية مدقق.
4. لا DDL ولا نشر ضمن هذه البوابة — تخطيط فقط؛ التنفيذ عبر مسار worktree → review → candidate المعتمد.

**GATE 2: PASS** — الكتالوج النهائي: 73 وحدة (40 قائمة بعد الدمج + 25 مفقودة + كشف 6 قدرات + 2 مستوعبة)، مصنفة A–J مع بوابات سلامة/موافقة/تدقيق ومراحل 1–3.
