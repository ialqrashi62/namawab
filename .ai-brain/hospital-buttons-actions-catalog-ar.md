## 1) المنهجية وسمات الزر الموحدة

كل زر في النظام يُعرَّف بتسع سمات إلزامية:

| السمة | التعريف | القيم الممكنة |
|---|---|---|
| **أين يظهر** | الشاشة/التبويب/البطاقة التي يعيش فيها الزر | اسم القسم + الموضع |
| **من يراه/يستخدمه** | الدور (Role) المخوَّل — تُطبَّق عبر صلاحيات الفهرس + RLS | طبيب/ممرض/صيدلي/كاشير/مدير... |
| **تأكيد؟** | هل يتطلب نافذة تأكيد قبل التنفيذ | نعم / لا / مزدوج (Two-step) |
| **سبب؟** | هل يتطلب إدخال سبب نصي/مقنن إلزامي | نعم / لا / عند التجاوز فقط |
| **Approval؟** | هل يتطلب موافقة دور أعلى قبل النفاذ | نعم(الدور) / لا |
| **Audit Log؟** | هل يُسجَّل في سجل التدقيق (من/متى/ماذا/قبل-بعد) | إلزامي / قياسي / لا |
| **أثر فاتورة؟** | هل يولّد/يعدّل بند فوترة (مع Idempotency على المال) | نعم / لا / غير مباشر |
| **أثر مخزون؟** | هل يخصم/يرجع/يحجز صنفاً | نعم / لا / حجز |
| **Safety Risk** | درجة خطر سلامة المريض عند سوء الاستخدام | حرج 🔴 / عالٍ 🟠 / متوسط 🟡 / منخفض 🟢 |

**تصنيف الكتالوج (حسب البرومبت الأصلي):** عامة → سريرية → إدارية/مالية → تشغيلية.

## 8) مصفوفة السياسات الموحدة (قواعد إلزامية عابرة للأقسام)

| القاعدة | التطبيق |
|---|---|
| **لا حذف سريري** | أي سجل سريري (ملاحظة/أمر/نتيجة/جرعة) لا يُحذف فيزيائياً أبداً — إبطال (Void) بسبب + Audit فقط |
| **التأكيد المزدوج** | إلزامي لكل: توقيع لقاء، إلغاء فاتورة، دمج MPI، صرف دم، مسير رواتب، تسوية مخزون، إيقاف جهاز، تعليق مستأجر |
| **السبب الإلزامي** | كل تجاوز CDS، كل Override، كل خصم/إلغاء مالي، كل تعديل بعد توقيع، كل حجب جرعة، كل تخفيض درجة فرز |
| **التوقيع/الشاهد الثاني** | أدوية عالية الخطورة، نقل دم، مخدرات، عدّ أدوات جراحية، Time-Out |
| **Audit إلزامي** | كل ما يمس PHI أو مالاً أو مخزوناً أو صلاحيات — بصيغة (من/متى/ماذا/قبل/بعد/tenant_id) خلف RLS |
| **Idempotency** | كل زر ذي أثر مالي (مطالبة/ZATCA/تحويل/دفعة) — مفعّل حالياً ✅ (Gate 7) |
| **RLS متعدد المستأجرين** | كل زر يقرأ/يكتب خلف 150 سياسة FORCE — الجلسة تتفوق على أي Header (Gate 4 ✅) |
| **حق التصعيد المكفول** | زر التصعيد التمريضي لا يُقيَّد بموافقة أبداً — سياسة سلامة |
| **فصل الواجبات** | مُدخِل النتيجة ≠ مُحرِّرها، الكاشير ≠ معتمد الاسترداد، أمين المستودع ≠ معتمد التسوية |
