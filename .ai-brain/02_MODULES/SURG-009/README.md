# SURG-009 — Transplant Surgery

## Mission
Solid organ transplantation: kidney, liver, pancreas, heart, lung, multi-organ.

## Top Organs
- Kidney (most common)
- Liver
- Heart
- Lung
- Pancreas
- Multi-organ (heart-kidney, liver-kidney)

## Workflow
- Recipient evaluation (medical, surgical, psych, social)
- Waitlist (UNOS, SCOT)
- Donor matching (ABO, HLA, crossmatch)
- Transplant surgery
- Induction immunosuppression
- Maintenance immunosuppression
- Long-term follow-up (rejection, infection, malignancy)

## Red Flags
- Hyperacute rejection
- Acute rejection
- Chronic rejection
- Post-op hemorrhage
- Vascular thrombosis
- Primary non-function
- Infection (immunosuppression)
- PTLD (post-transplant lymphoproliferative disorder)

## L4 Validation: 6/6 PASS
- Red flags: rejection, thrombosis
- Drug safety: immunosuppressants, calcineurin, mTOR
- PHI: encrypted (donor-recipient link)
- Auth: Transplant surgeon
- Compliance: JCI, OPTN, UNOS, CBAHI
- Tests: rejection monitoring, immunosuppression
