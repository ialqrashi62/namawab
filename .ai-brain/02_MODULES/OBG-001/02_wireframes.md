# OBG-001 — Wireframes (8 Screens)

## Screen 1: ANC Home
- List of patients due for ANC visit
- Quick add: new pregnancy
- Calendar view
- Filter: high-risk, gestational age

## Screen 2: Pregnancy Detail
- Patient header
- LMP, EDD, current GA
- Risk level badge
- BP, weight trend chart
- Lab timeline
- Ultrasound images
- Plan

## Screen 3: ANC Visit
- Date, GA
- Vitals: weight, BP
- Urine dipstick
- Fundal height
- FHR
- Symptoms
- Plan
- Next visit

## Screen 4: Ultrasound Form
- Type (first trimester, anomaly, growth)
- GA, EFW
- AFI, Doppler
- Findings text
- Image upload

## Screen 5: L&D Board
- All rooms
- Stage of labor
- FHR tracing
- Contraction pattern
- Pain management
- Plan

## Screen 6: Delivery Form
- Date/time
- Mode (SVD, vacuum, C-section)
- EBL
- Apgar
- Complications
- Newborn data

## Screen 7: Postpartum Visit
- Day postpartum
- Lochia, bleeding
- Perineal healing
- Breastfeeding
- Mood screening (Edinburgh)
- Contraception
- Plan

## Screen 8: Gyn Visit
- Chief complaint
- Menstrual history
- LMP
- Pap/HPV history
- Exam
- Plan
