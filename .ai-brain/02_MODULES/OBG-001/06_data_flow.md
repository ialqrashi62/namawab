# OBG-001 — Data Flow

## Pregnancy Registration
```
1. Patient confirms pregnancy (home test or clinic)
2. Booking visit at ANC (≤12 weeks)
3. Verify LMP, calculate EDD
4. Order first trimester labs (CBC, blood group, Rh, antibody, rubella, varicella, HepB, HIV, syphilis, urine)
5. First trimester screen (NT + serum markers)
6. Anomaly scan at 18-22 weeks
7. GDM screen at 24-28 weeks
8. Tdap at 27-36 weeks
9. GBS at 35-37 weeks
10. Antenatal visits (q4w until 28w, q2w until 36w, q1w until delivery)
11. Plan delivery (timing, mode, location)
12. Postpartum follow-up (1-2 weeks, 6 weeks)
```

## Labor & Delivery
```
1. Patient presents in labor
2. Triage assessment (vitals, cervical exam, FHR, ultrasound for presentation)
3. Admit to L&D
4. Fetal monitoring (continuous)
5. Stage of labor, progress
6. Pain management (epidural, IV opioid, N2O)
7. Delivery (vaginal or C-section)
8. Active management third stage (oxytocin, controlled cord traction)
9. Newborn assessment (Apgar, resuscitation if needed)
10. Skin-to-skin, breastfeeding initiation
11. Recovery (2h L&D → postpartum ward)
12. PPH surveillance
```

## PPH Workflow
```
1. EBL >500 mL (SVD) or >1000 mL (C-section)
2. Call for help
3. Bimanual uterine massage
4. Uterotonic (oxytocin 10U IV, then 20U/L)
5. Inspect for retained tissue, trauma
6. If atonic: misoprostol 800 mcg PR, methylergometrine 0.2 mg IM, carboprost 250 mcg IM
7. 2 large-bore IVs, type & cross
8. Crystalloid, blood products
9. Bakri balloon if medical mgmt fails
10. Surgical: B-Lynch suture, artery ligation, hysterectomy
11. ICU if hemodynamically unstable
12. Documentation, root cause
```

## Preeclampsia Workflow
```
1. BP ≥140/90 after 20 weeks
2. Urine dipstick (protein)
3. Labs: CBC, LFT, Cr, uric acid, LDH
4. Classification: gestational HTN, preeclampsia, severe, eclampsia, HELLP
5. MgSO4 (4g IV load, 1-2g/h maintenance) if severe
6. Antihypertensive: labetalol, hydralazine, nifedipine
7. Corticosteroids if <34 weeks
8. Delivery timing:
   - Mild: 37 weeks
   - Severe: 34 weeks (or sooner if deteriorating)
   - Eclampsia: stabilize then deliver
9. Postpartum monitoring (PE can worsen 24-48h post-delivery)
```

## GDM Workflow
```
1. Risk assessment at booking (obesity, age, family history, prior GDM)
2. 50g screen at 24-28 weeks
3. If positive: 75g or 100g OGTT
4. GDM diagnosis → medical nutrition therapy
5. Self-monitoring blood glucose (fasting + 2h post-meal)
6. Targets: fasting <95, 2h <120
7. Insulin if targets not met
8. Fetal growth scan q4 weeks
9. Delivery: 40w if well-controlled, 38w if insulin-requiring
10. Postpartum: GDM usually resolves; screen for DM at 6-12 weeks
```

## Infertility Workflow
```
1. <12 months trying (earlier if AMA, irregular cycles, prior pelvic surgery)
2. History + exam
3. Semen analysis (male factor 50%)
4. Ovulation assessment (mid-luteal progesterone)
5. HSG (tubal patency)
6. Hormones (FSH, LH, TSH, prolactin, AMH)
7. Treatment:
   - Ovulation induction (clomiphene, letrozole)
   - IUI
   - IVF
8. Counseling (success rates, risks, cost)
```

## Cervical Cancer Screening
```
1. Age 21-29: Pap q3y
2. Age 30-65: Pap+HPV co-test q5y (or Pap q3y)
3. ASCUS: HPV reflex
4. LSIL/HSIL: colposcopy
5. Biopsy if abnormal
6. CIN I: observation (often resolves)
7. CIN II/III: LEEP or cone biopsy
8. Cancer: staging + treatment (radical hysterectomy, radiation, chemo)
```
