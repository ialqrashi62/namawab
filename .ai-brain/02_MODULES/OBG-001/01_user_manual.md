# OBG-001 User Manual (Excerpt)

## EN

### Obstetric Triage

1. **Verify pregnancy status**
   - LMP + EDD + GA
   - Current symptoms
   - Vital signs (BP threshold: ≥140/90)

2. **Screen for red flags**
   - Severe headache, visual changes → pre-eclampsia
   - Seizures → eclampsia
   - Vaginal bleeding (painless = previa, painful = abruption)
   - Decreased fetal movement
   - Severe abdominal pain
   - Fluid leaking (rupture of membranes)

3. **Document**
   - Fetal heart rate (110-160 normal)
   - Contractions
   - Cervical exam (if no placenta previa)
   - Ultrasound if indicated

4. **Disposition**
   - Admit to L&D if active labor, bleeding, severe HTN
   - Discharge with follow-up if low-risk

### Magnesium Sulfate Protocol

- **Loading:** 4-6g IV over 15-20 min
- **Maintenance:** 1-2g/h IV
- **Monitor:** DTR (patellar), RR (>12), urine output (>30 mL/h), serum Mg (4-7 mg/dL)
- **Toxicity:** loss of DTR, RR<12, urine output <100 mL/4h
- **Antidote:** Calcium gluconate 1g IV over 3 min

### Postpartum Hemorrhage (PPH)

**HAEMOSTASIS algorithm:**
1. H — Help (call code)
2. A — Assess + resuscitate
3. E — Establish cause, Evacuate uterus
4. M — Massage
5. O — Oxytocin 10U IV + 40U in 1L NS
6. S — Second-line uterotonics
7. T — Tamponade (Bakri balloon)
8. A — Arterial ligation
9. C — Compression sutures (B-Lynch)
10. H — Hysterectomy (last resort)

## AR

### فرز التوليد

1. **التحقق من حالة الحمل**
   - تاريخ آخر دورة + تاريخ الولادة المتوقع + عمر الحمل
   - الأعراض الحالية
   - العلامات الحيوية (عتبة ضغط الدم: ≥140/90)

2. **فحص العلامات الحمراء**
   - صداع شديد، تغيرات بصرية → تسمم الحمل
   - نوبات → تسمم الحمل مع تشنجات
   - نزيف مهبلي (بلا ألم = مشيمة منزاحة، مع ألم = انفصال المشيمة)
   - انخفاض حركة الجنين
   - ألم بطن شديد
   - تسرب سائل (تمزق الأغشية)

3. **التوثيق**
   - معدل ضربات قلب الجنين (110-160 طبيعي)
   - التقلصات
   - فحص عنق الرحم (إذا لم تكن هناك مشيمة منزاحة)
   - الموجات فوق الصوتية إذا لزم

4. **القرار**
   - قبول في غرفة الولادة إذا كان هناك ولادة نشطة، نزيف، أو ارتفاع ضغط الدم الشديد
   - الخروج مع المتابعة إذا كان الخطر منخفضاً

### بروتوكول سلفات المغنيسيوم

- **التحميل:** 4-6غ وريدي على 15-20 دقيقة
- **الصيانة:** 1-2غ/ساعة وريدي
- **المراقبة:** منعكسات الوتر الرضفي، معدل التنفس (>12)، إدرار البول (>30 مل/ساعة)، مغنيسيوم المصل (4-7 ملغ/دل)
- **السمية:** فقدان المنعكسات، معدل التنفس <12، إدرار البول <100 مل/4 ساعات
- **الترياق:** غلوكونات الكالسيوم 1غ وريدي على 3 دقائق
