# PHARM-001 — Clinical Pharmacy

## Mission
Pharmaceutical care: dispensing, sterile compounding, clinical pharmacy, antimicrobial stewardship, TPN, oncology pharmacy, medication safety.

## Top Services
- Inpatient pharmacy (unit-dose)
- Outpatient pharmacy
- IV admixture (sterile)
- TPN (total parenteral nutrition)
- Chemotherapy admixture
- Clinical rounds (CC, ICU, peds)
- Antimicrobial stewardship
- Pharmacokinetic dosing (vancomycin, aminoglycoside)
- DUR (drug utilization review)

## Red Flags (Medication Safety)
- High-alert meds (insulin, anticoag, opioid, chemo, paralytic, K+ conc)
- Sound-alike / look-alike (SALAD)
- LASA (hydralazine/hydroxyzine, dopamine/doxazosin)
- Allergy check
- Drug-drug interaction
- Renal dose adjustment
- Duplicate therapy

- Red flags: high-alert, interaction
- Drug safety: double-check, bar code, override flag
- PHI: encrypted (meds)
- Auth: Pharmacist
- Compliance: JCI, ASHP, MOH
- Tests: DUR, interaction check
