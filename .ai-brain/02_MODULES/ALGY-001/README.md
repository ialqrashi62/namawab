# ALGY-001 — Allergy & Immunology

## Mission
Allergic and immunologic diseases: atopic, food, drug, stinging insect, anaphylaxis, primary immunodeficiency, autoimmune.

## Top Conditions
- Allergic rhinitis
- Asthma (allergic)
- Atopic dermatitis
- Food allergy
- Drug allergy
- Urticaria / angioedema
- Anaphylaxis
- Primary immunodeficiency (CVID, XLA, SCID)
- Hereditary angioedema (HAE)
- Eosinophilic disorders

## Workflow
- Allergy history
- Skin prick test
- Specific IgE (blood)
- Component testing
- Patch testing
- Drug challenge
- Immunotherapy (SCIT, SLIT)
- Omalizumab

## Red Flags
- Anaphylaxis (epinephrine STAT)
- Hereditary angioedema
- Severe food allergy
- SCID (peds emergency)
- Drug allergy desensitization failure

- Red flags: anaphylaxis, SCID
