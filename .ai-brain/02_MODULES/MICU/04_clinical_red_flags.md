# MICU — Clinical Red Flags (Critical Care Watch)

## Hemodynamic
- MAP <65 (despite fluids/vasopressors)
- HR >150 or <40
- New onset arrhythmia
- Sudden cardiac arrest
- Lactate rising despite resuscitation

## Respiratory
- SpO2 <88% on 100% FiO2
- RR >35 or <8
- Accessory muscle use, paradoxical breathing
- Pneumothorax (sudden hypoxia + hypotension)
- ET tube dislodgement
- Ventilator alarm (high pressure, low volume, disconnect)

## Neurological
- GCS drop ≥2 points
- New focal deficit
- Seizure activity
- Pupillary asymmetry
- Cushing's triad (HTN + bradycardia + irregular resp = ICP)

## Renal
- Urine output <0.5 mL/kg/h × 2h
- Sudden anuria
- Severe hyperkalemia (K+ >6.5)
- Severe acidosis (pH <7.1)

## Infectious
- New fever in ICU (often late)
- WBC <2 or >30
- Septic shock criteria
- New culture growth

## GI / Nutrition
- Coffee-ground emesis / hematochezia
- Abdominal distension (ileus, ischemia)
- Aspiration (witnessed)
- Refeeding syndrome (K, Phos, Mg crash)
- TPN-related hyperglycemia

## Procedure
- Central line complication (PTX, arterial puncture)
- Arterial line disconnection (blood loss)
- NG tube malposition

## Communication / Code
- Patient/family request for code change
- Conflict with family
- Staff concern
- Near-miss event
