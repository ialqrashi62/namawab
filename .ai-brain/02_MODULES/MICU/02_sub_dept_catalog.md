# MICU — Sub-Department Catalog

## Sub-Units
1. **MICU-MAIN** — Main medical ICU (level 1)
2. **MICU-RESP** — Respiratory failure unit
3. **MICU-SEPSIS** — Sepsis zone
4. **MICU-CARD** — Mixed cardiac-medical
5. **MICU-RENAL** — Renal failure + CRRT
6. **MICU-TOX** — Toxicology / overdose
7. **MICU-NEURO** — Mixed neuro-medical
8. **MICU-POSTOP** — Post-op (medical complications)

## Per-Subunit Top Issues
- **MICU-MAIN:** All conditions
- **MICU-RESP:** ARDS, severe pneumonia, COPD exacerbation, asthma
- **MICU-SEPSIS:** Septic shock, MDRO
- **MICU-CARD:** Cardiogenic shock, post-PCI, post-cardiac arrest
- **MICU-RENAL:** AKI on CKD, CRRT
- **MICU-TOX:** Drug overdose, snake/scorpion envenomation
- **MICU-NEURO:** Stroke, status epilepticus, GB syndrome
- **MICU-POSTOP:** Post-op respiratory failure, sepsis, bleeding

## Cross-Cutting
- Daily rounds (interdisciplinary: MD, RN, RT, Pharm, Nutrition, PT)
- Family meeting (weekly)
- Code status discussion (admit, day 3, change)
- Palliative care consult (when appropriate)
