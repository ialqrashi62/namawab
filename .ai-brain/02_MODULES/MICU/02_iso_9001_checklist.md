# MICU — ISO 9001:2015 Quality Management Checklist

## Context of the Organization (Clause 4)
- [ ] MICU scope defined
- [ ] Interested parties identified (patients, families, staff, MOH, JCI)
- [ ] QMS scope documented

## Leadership (Clause 5)
- [ ] MICU director (intensivist) appointed
- [ ] Quality committee meets monthly
- [ ] QMS policy communicated

## Planning (Clause 6)
- [ ] Quality objectives (mortality, bundle compliance, satisfaction)
- [ ] Risk register
- [ ] Quality plan for MICU

## Support (Clause 7)
- [ ] Competency matrix (MD, RN, RT, Pharm, etc.)
- [ ] Training plan
- [ ] Internal communication
- [ ] Documented information (SOPs, guidelines)

## Operation (Clause 8)
- [ ] Operational planning (admission criteria, staffing)
- [ ] Process map (admit → round → discharge)
- [ ] Critical care SOPs
  - Sepsis bundle
  - ARDS management
  - Ventilator weaning
  - Vasoactive titration
  - Code blue
- [ ] Change management (new protocols, equipment)
- [ ] Outsourced processes (lab, blood bank, radiology)

## Performance Evaluation (Clause 9)
- [ ] KPIs monitored:
  - APACHE-adjusted mortality
  - Bundle compliance (sepsis, VAP, CLABSI)
  - ICU readmission rate
  - Unplanned extubation
  - Pressure ulcer incidence
  - Patient/family satisfaction
  - Staff satisfaction
  - Code blue rate
- [ ] Internal audits (quarterly)
- [ ] Management review (annual)

## Improvement (Clause 10)
- [ ] Non-conformity handling
- [ ] Corrective action (CAPA)
- [ ] Continual improvement
- [ ] Lessons learned
