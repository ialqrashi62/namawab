# CARD-001 — Wireframes (8 Screens)

## Screen 1: Cardiology Board
- CCU patients
- Chest pain unit
- Color by acuity
- STEMI alert (if active)

## Screen 2: Patient Header
- Demographics
- Admission dx
- ECG, troponin trend
- Meds
- Procedures

## Screen 3: ECG Viewer
- 12-lead display
- Speed: 25 mm/s
- Gain: 10 mm/mV
- Interpretation
- Critical findings flag

## Screen 4: Risk Calculator
- TIMI
- GRACE
- HEART
- CHA2DS2-VASc
- HAS-BLED
- Killip
- NYHA

## Screen 5: Echo Report
- EF
- Valvular
- Wall motion
- Pulmonary pressure
- Pericardial effusion

## Screen 6: Cath Lab
- Pre-procedure checklist
- Indication
- Stents placed
- Contrast volume
- Complications
- Post-PCI

## Screen 7: Med Reconciliation
- Anticoag
- Antiplatelet
- Beta-blocker
- ACE-I/ARB
- Statin
- MRA
- SGLT2i
- Diuretic

## Screen 8: Device Check
- Pacemaker
- ICD
- CRT
- Loop recorder
- Battery, lead status
- Last check
- Next check
