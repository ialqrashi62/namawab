# CARD-001 — Data Flow

## STEMI Workflow
```
1. Patient arrives with chest pain
2. Triage → ECG within 10 min
3. ECG shows STEMI (ST elevation in 2+ contiguous leads)
4. Auto-page interventional cardiologist + cath lab team
5. Aspirin 325 mg chewed
6. P2Y12 (ticagrelor 180 mg or clopidogrel 600 mg)
7. Heparin bolus
8. Statin (high-dose atorvastatin 80 mg)
9. Cath lab (door-to-balloon <90 min)
10. PCI (angioplasty + stent)
11. Post-PCI: dual antiplatelet, statin, beta-blocker, ACE-I
12. CCU monitoring
13. Discharge planning (3-5 days)
14. Cardiac rehab referral
15. Follow-up at 1 week, 1 month, 3 months, 6 months, 1 year
```

## AF Workflow
```
1. New AF detected (ECG, holter, Apple watch)
2. Confirm (12-lead ECG)
3. Assess (rate, duration, symptoms)
4. CHA2DS2-VASc (stroke risk)
5. HAS-BLED (bleeding risk)
6. Decision: rate control vs rhythm control
7. Anticoagulation if indicated
8. Cardioversion if appropriate
9. Follow-up
```

## HF Workflow
```
1. Dyspnea, edema, weight gain
2. BNP or NT-proBNP
3. CXR
4. Echo (EF, structure)
5. NYHA class
6. GDMT: ARNI, beta-blocker, MRA, SGLT2i
7. Diuretic (loop, thiazide)
8. Education (weight, diet, meds)
9. Follow-up (2 weeks, 1 month, 3 months)
10. Cardiac rehab
```

## Chest Pain Unit
```
1. Chest pain triage
2. ECG within 10 min
3. HEART score
4. Troponin 0h, 3h (rule out MI)
5. Risk stratify
6. Observation (6-12h) or discharge
7. Stress test or CT angio if intermediate risk
8. Decision: discharge vs admit
```

## Pre-Hospital ECG
```
1. EMS arrives
2. 12-lead ECG on scene
3. Transmit to hospital (cellular)
4. Hospital receives + interprets
5. STEMI detection → activate cath lab
6. Bypass ER → straight to cath lab
7. Time saved: 20-30 min
```

## Pacemaker/ICD Follow-up
```
1. In-clinic check (every 3-6 months)
2. Remote monitoring (daily, weekly)
3. Battery status
4. Lead parameters
5. Captured arrhythmias
6. Alerts
7. Generator replacement planning
```
