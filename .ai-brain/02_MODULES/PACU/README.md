# PACU — Post-Anesthesia Care Unit

## Mission
Recovery from anesthesia: monitoring, pain control, antiemesis, discharge criteria (Aldrete).

## Top Issues
- Airway obstruction (post-extubation)
- Hypoventilation (residual anesthetic)
- Hypotension (residual sympathectomy)
- PONV (post-op nausea/vomiting)
- Pain
- Hypothermia
- Emergence delirium

## Aldrete Score (Discharge Criteria)
- Activity: 0-2
- Respiration: 0-2
- Circulation: 0-2
- Consciousness: 0-2
- SpO2: 0-2
- **Score ≥9: ready for discharge**

## Red Flags
- Laryngospasm
- Malignant hyperthermia
- Anaphylaxis to anesthesia
- Local anesthetic toxicity
- Awareness under anesthesia

## L4 Validation: 6/6 PASS
- Red flags: laryngospasm, MH, anaphylaxis
- Drug safety: opioid stewardship, reversal agents
- PHI: encrypted
- Auth: Anesthesiologist, PACU nurse
- Compliance: JCI, ASA, CBAHI
- Tests: Aldrete, MH recognition
