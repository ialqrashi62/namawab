# ER-001 Clinical Red Flags

## Red Flag Categories (CMO + CQO approved)

### Category 1: IMMEDIATE LIFE-THREAT (escalate within seconds)

| Red Flag | Trigger Criteria | Response | Time Target |
|----------|------------------|----------|-------------|
| **Cardiac arrest** | No pulse, no breathing, unresponsive | Code Blue, CPR, defibrillator | 0 min |
| **Severe respiratory distress** | RR >30, SpO2 <88%, accessory muscle use, unable to speak | High-flow O2, prepare for intubation, code team | <3 min |
| **Anaphylaxis (severe)** | Acute onset + skin/mucosal involvement + respiratory OR CV compromise + persistent GI symptoms | Epi 0.3-0.5 mg IM (adult), IV access, fluids | <1 min |
| **Major hemorrhage** | Visible arterial bleed, HR>120 + SBP<90 | Direct pressure, TXA, type & cross, MTP | <5 min |
| **Airway compromise** | Stridor, unable to handle secretions, foreign body | Heimlich, prepare for surgical airway | <1 min |
| **Penetrating trauma to chest/abdomen/neck** | Mechanism + visible injury | Trauma activation, do NOT remove object | <2 min |
| **Tension pneumothorax** | Hypotension + absent breath sounds + tracheal deviation | Needle decompression 2nd ICS midclavicular | <1 min |
| **Cardiac tamponade** | Beck's triad (hypotension, JVD, muffled heart sounds) | Pericardiocentesis | <5 min |

### Category 2: EMERGENT (escalate within minutes)

| Red Flag | Trigger Criteria | Response | Time Target |
|----------|------------------|----------|-------------|
| **STEMI** | ST elevation >=1mm in 2+ contiguous leads (>=2mm in V2-V3), OR new LBBB with symptoms | Code STEMI, ASA 325mg, cath lab activation | Door-to-balloon <90 min |
| **Acute ischemic stroke (tPA candidate)** | Focal neuro deficit, last-known-well <4.5h, NIHSS >4, no hemorrhage on CT | Code Stroke, tPA per protocol | Door-to-needle <60 min |
| **Sepsis (severe)** | qSOFA >=2, suspected infection, organ dysfunction | Sepsis bundle, lactate, blood cx, abx, fluids | Within 1h |
| **Aortic dissection** | Tearing chest/back pain, pulse deficit, BP differential, mediastinal widening on CXR | CT angio, BP/HR control (esmolol + nitroprusside) | <30 min |
| **AAA rupture** | Hypotension + back pain + pulsatile abdominal mass | Stat CT if stable, OR if unstable, MTP | <15 min |
| **Ruptured ectopic pregnancy** | Female + abdominal pain + hypotension + positive hCG + free fluid on US | OR, MTP, type & screen | <15 min |
| **Testicular torsion** | Acute scrotal pain, absent cremasteric reflex, high-riding testis | Urology consult, OR within 6h | <2h to OR |
| **Meningococcemia** | Fever + petechial/purpuric rash + hypotension | Ceftriaxone 2g IV, ICU, isolation | <1h abx |
| **Status epilepticus** | Seizure >5 min or recurrent without recovery | Lorazepam 4mg IV, levo 1500mg, intubation prep | <5 min |
| **DKA severe** | Glucose >250, pH <7.1, HCO3 <10, anion gap >12 | IV fluids, insulin drip, K replacement | <30 min |

### Category 3: URGENT (escalate within 30 min)

| Red Flag | Trigger Criteria | Response |
|----------|------------------|----------|
| **Pulmonary embolism (high-risk)** | Wells >6, shock/hypotension, RV strain on echo | CT-PA, anticoag if no contraindication, thrombolysis if shock |
| **Acute abdomen** | Peritoneal signs, free air on imaging | NPO, IV abx, surgical consult, OR |
| **Acute mesenteric ischemia** | Pain out of proportion, lactic acidosis, AFib, age >60 | CT angio, heparin, vascular consult |
| **Necrotizing fasciitis** | Pain out of proportion, skin discoloration, crepitus, sepsis | Stat surgical consult, broad-spectrum abx, OR |
| **Compartment syndrome** | Severe pain with passive stretch, tense compartment, paresthesias | Stat surgical consult, fasciotomy |
| **Cauda equina** | Saddle anesthesia, bowel/bladder dysfunction, bilateral leg weakness | Stat MRI, neurosurgical consult |
| **Glaucoma (acute angle closure)** | Severe eye pain, halos, fixed mid-dilated pupil, red eye, N/V | Topical timolol, pilocarpine, acetazolamide, ophtho consult |
| **Retinal detachment** | Flashes, floaters, curtain over vision | Ophtho consult within 24h |
| **Ovarian torsion** | Female + pelvic pain + adnexal mass on US | GYN consult, OR |
| **Pulmonary hypertension crisis** | History PH + acute SOB + hypotension | Inhaled nitric oxide, IV epoprostenol, RV support |

### Category 4: HIGH-RISK PRESENTATION (escalate within 1-2h)

| Red Flag | Trigger Criteria | Response |
|----------|------------------|----------|
| **Atypical MI (diabetic, elderly, female)** | Diabetic/elderly + epigastric pain, N/V, dyspnea, fatigue | ECG, troponin, even if CP absent |
| **Spinal epidural abscess** | Back pain + fever + neuro deficit + IVDU risk | Stat MRI, neurosurgical consult, IV abx |
| **Infective endocarditis** | Fever + new murmur + risk factors (IVDU, prosthetic valve) | Blood cultures x3, echo, ID consult |
| **Ruptured ovarian cyst** | Sudden pelvic pain, free fluid on US | Pain control, GYN consult |
| **Eclampsia** | Pregnancy + seizures + HTN | MgSO4 4g IV, BP control, delivery |
| **HELLP syndrome** | Pregnancy + RUQ pain + thrombocytopenia + elevated LFTs | Stat OB consult, delivery |
| **Acute liver failure** | Jaundice + coagulopathy + encephalopathy in <8 weeks | N-acetylcysteine, transfer to transplant center |
| **Thyroid storm** | Fever + tachycardia + altered mental status + goiter | Propranolol, PTU, iodine, steroids |
| **Adrenal crisis** | Hypotension + hyperkalemia + hyponatremia + history steroids | Hydrocortisone 100mg IV, fluids |
| **Acute glaucoma (mentioned above)** | — | — |

### Category 5: PSYCHIATRIC / BEHAVIORAL (escalate immediately)

| Red Flag | Trigger Criteria | Response |
|----------|------------------|----------|
| **Suicidal with plan/means** | SI + plan + access to means | 1:1 sitter, remove sharps, psych eval, safety plan |
| **Homicidal with identified victim** | HI + plan + access | Security, duty to warn identified victim, psych hold |
| **Acute psychosis with agitation** | Disorganized + dangerous to self/others | Verbal de-escalation, chemical restraint (ziprasidone 10mg IM), then physical if needed |
| **Catatonia** | Mutism, posturing, waxy flexibility, negativism | Lorazepam 1-2mg IV, rule out NMS |
| **Delirium tremens** | Tremor, autonomic instability, confusion, history alcohol | Lorazepam 2-4mg IV, thiamine 100mg IV, supportive |

## Red Flag Detection — AI Implementation (AIE)

### Detection Methods
1. **Vital signs thresholds:** HR, BP, RR, SpO2, temp, GCS
2. **Chief complaint keyword matching:** "chest pain", "shortness of breath", "suicidal", etc.
3. **ECG interpretation:** STEMI detection, lethal rhythms (VT, VF, TdP)
4. **Lab value thresholds:** lactate >2, troponin >0.04, glucose <50, etc.
5. **Composite scoring:** qSOFA, NEWS2, NIHSS, GCS
6. **Pattern recognition:** symptom clusters (MIs in elderly, meningitis triad)
7. **Historical alerts:** prior admissions for same condition, missed follow-up

### Response Protocol (AI-detected)
1. **Immediate visual + audible alert** to assigned MD/RN
2. **Auto-page** charge nurse + on-call specialist (cardiology, neurology, etc.)
3. **Pre-populated order set** (e.g., sepsis bundle, stroke protocol)
4. **Documentation template** auto-loaded
5. **Time-stamped audit log** of detection + response
6. **Escalation** if not addressed within 3 min (charge nurse), 5 min (department head)

### Override Rules
- MD may override AI red flag, BUT:
  - **Must provide written reason** (dropdown + free text)
  - **Must add supervisor co-sign** within 30 min
  - **Override rate tracked** per provider (feedback loop)
  - **>20% override rate** triggers case review

## Pregnancy-Specific Red Flags

| Red Flag | Trigger | Response |
|----------|---------|----------|
| **Ectopic pregnancy** | +hCG + empty uterus + free fluid | Stat OB consult, OR |
| **Placental abruption** | Painful bleeding + tender uterus + fetal distress | Stat OB, delivery |
| **Placenta previa** | Painless bleeding + ultrasound diagnosis | No digital exam, OB consult |
| **Pre-eclampsia severe** | BP >160/110 + proteinuria + end-organ damage | MgSO4, BP control, delivery |
| **Eclampsia** | Pregnancy + seizures | MgSO4 4g IV, airway, delivery |
| **HELLP** | Platelets <100 + AST/ALT >70 + LDH >600 | Stat delivery |
| **Ruptured membranes + preterm labor** | <37 weeks + contractions | Tocolysis, steroids, GBS prophylaxis |

## Pediatric-Specific Red Flags

| Red Flag | Trigger | Response |
|----------|---------|----------|
| **Neonatal sepsis** | Fever + lethargy + poor feeding in <28 days | Full septic workup, ceftriaxone 50mg/kg, admit |
| **Pediatric DKA** | Glucose >200 + pH <7.1 + dehydration | IVF 10-20 mL/kg bolus, insulin 0.05-0.1 U/kg/h |
| **Intussusception** | Sausage mass + currant jelly stool + colicky pain | Air or contrast enema, surgical backup |
| **Pyloric stenosis** | Projectile vomiting + palpable olive + hypochloremic hypokalemia | Correct electrolytes, surgical consult |
| **Meningitis (peds)** | Fever + neck stiffness + altered mental status | LP + ceftriaxone + dexamethasone |
| **Epiglottitis** | Drooling + tripod position + muffled voice | Anesthesia + ENT, prepare for airway, do NOT examine throat |
| **Croup** | Barking cough + stridor at rest + retractions | Nebulized epi, dexamethasone |
| **Bronchiolitis** | Infant + URI + wheezing + retractions + SpO2 <90% | Suction, O2, consider high-flow, admit if severe |
| **Non-accidental injury suspicion** | Inconsistent history, bruises in non-ambulatory, pattern injuries | Skeletal survey, social work, report to authorities |

## CMO Veto — Unacceptable Risks

The following **must not happen**, even with override:
- Administer known teratogen to pregnant patient without LMP + pregnancy test
- Administer known allergen to documented-allergic patient
- Transfuse without dual blood-bank check
- Discharge suicidal patient without psych eval
- Discharge ESI 1 patient without admission
- Order CT without pregnancy check in female 12-55
- Miss critical lab callback >30 min
