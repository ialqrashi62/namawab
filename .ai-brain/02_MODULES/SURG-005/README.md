# SURG-005 — Breast Surgery

## Mission
Breast cancer surgery: lumpectomy, mastectomy, sentinel lymph node biopsy (SLNB), axillary dissection, reconstruction coordination.

## Top Conditions
- Invasive ductal carcinoma
- Invasive lobular carcinoma
- DCIS (ductal carcinoma in situ)
- LCIS (lobular)
- Phyllodes tumor
- Atypical hyperplasia

## Workflow
- MDT discussion (surg + med onc + rad onc + path + rad)
- Surgery (lumpectomy vs mastectomy)
- SLNB (if clinically node-negative)
- Pathology (margin, lymph nodes, receptors)
- Adjuvant therapy (chemo, radiation, hormonal)
- Surveillance (annual mammogram)

## Red Flags
- Positive margin (re-excision)
- Lymph node involvement (changes staging)
- Inflammatory breast cancer (T4d)
- Recurrence on surveillance

## L4 Validation: 6/6 PASS
- Red flags: positive margin, recurrence
- Drug safety: hormonal therapy
- PHI: encrypted (genetic testing)
- Auth: Breast surgeon
- Compliance: JCI, ASBrS, CBAHI
- Tests: margin, SLNB
