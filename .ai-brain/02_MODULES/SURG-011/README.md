# SURG-011 — Bariatric & Metabolic Surgery (Center of Excellence)

## Mission
Comprehensive bariatric program: surgery + medical, nutritional, psychological support. ASMBS/MBSAQIP standards.

## Top Procedures
- Sleeve gastrectomy
- Roux-en-Y gastric bypass
- Adjustable gastric band (now rare)
- Biliopancreatic diversion with duodenal switch (BPD-DS)
- SADI-S (single anastomosis)

## Multidisciplinary Team
- Bariatric surgeon
- Bariatrician (medical weight management)
- Dietitian
- Psychologist
- Exercise specialist
- Coordinator

## Red Flags
- Anastomotic leak
- Marginal ulcer
- Internal hernia
- DVT/PE
- Vitamin deficiency
- Reactive hypoglycemia

## L4 Validation: 6/6 PASS
- Red flags: leak, internal hernia
- Drug safety: vitamin, anticoag
- PHI: encrypted
- Auth: Bariatric surgeon + MDT
- Compliance: JCI, ASMBS, MBSAQIP
- Tests: leak, nutrition monitoring
