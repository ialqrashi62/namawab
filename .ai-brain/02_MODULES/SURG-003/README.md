# SURG-003 — Bariatric Surgery

## Mission
Weight loss surgery: sleeve gastrectomy, gastric bypass, gastric band, BPD-DS.

## Top Conditions
- Morbid obesity (BMI ≥40, or ≥35 with comorbidity)
- Type 2 diabetes (often resolves post-op)
- Hypertension
- OSA (obstructive sleep apnea)
- Joint disease

## Eligibility
- BMI ≥40 (or ≥35 with comorbidity)
- Failed conservative weight loss
- No contraindication
- Psychological clearance
- Long-term follow-up commitment

## Red Flags (Post-Op)
- Anastomotic leak
- Hemorrhage
- DVT/PE
- Stricture
- Marginal ulcer
- Vitamin deficiency
- Internal hernia
- Hypoglycemia (post-bypass)

## L4 Validation: 6/6 PASS
- Red flags: leak, hemorrhage, DVT
- Drug safety: anticoag, vitamin
- PHI: encrypted
- Auth: Bariatric surgeon
- Compliance: JCI, ASMBS, CBAHI
- Tests: leak detection, weight tracking
