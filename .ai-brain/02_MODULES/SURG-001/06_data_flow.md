# SURG-001 — Data Flow

## Pre-Operative
```
1. Surgical decision (clinic or ER)
2. Pre-op workup (labs, ECG, CXR, imaging)
3. Anesthesia consult
4. Medical optimization (DM, HTN, anticoag, anemia)
5. NPO (8h solids, 2h clear fluids)
6. Pre-op antibiotic prophylaxis
7. VTE prophylaxis
8. Site marking (procedure side)
9. Surgical consent
10. Anesthesia consent
11. WHO checklist (timeout planned)
```

## Intra-Operative
```
1. Sign-in (patient, site, procedure, consent)
2. Anesthesia induction
3. Antibiotic re-dose (if long case)
4. Skin prep
5. Draping
6. Time-out (immediately before incision)
7. Procedure
8. Counts (sponges, instruments, sharps)
9. Closing
10. Sign-out (procedure performed, complications, plan)
```

## Post-Operative
```
1. PACU recovery
2. Pain management
3. Diet advancement
4. Mobilization
5. Wound care
6. VTE prophylaxis
7. Discharge planning
8. Follow-up appointment
```

## Complication Management
```
- Fever POD 1-2: atelectasis (most common)
- Fever POD 3-5: SSI
- Fever POD 5+: deep infection, leak
- Tachycardia, hypotension, fever: sepsis
- Drop in Hb: bleed
- Abdominal distension + nausea: ileus
- Chest pain + hypoxia: PE
```

## ERAS Protocol
- Pre-op: carb drink, no prolonged fasting
- Intra-op: short-acting anesthesia, normothermia, euvolemia
- Post-op: early feeding, early mobilization, multimodal analgesia
- Reduces LOS, complications
