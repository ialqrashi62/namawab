# SURG-001 — Wireframes (6 Screens)

## Screen 1: OR Schedule
- Day/Week view
- All ORs
- Color by urgency
- Click procedure for detail

## Screen 2: Pre-Op Clinic
- Patient header
- Diagnosis
- Planned procedure
- Pre-op checklist (consent, lab, ECG, etc.)
- Anesthesia plan
- ASA class
- Save

## Screen 3: Pre-Op Checklist (Day of Surgery)
- NPO confirmed
- Site marked
- Antibiotic ordered
- Consent signed
- Anesthesia plan reviewed
- VTE prophylaxis
- Mark all → green

## Screen 4: Intra-Op Form
- Anesthesia type
- EBL
- Time-out performed
- Counts correct
- Complications
- Specimens
- Surgeon, assistant
- Save

## Screen 5: Post-Op Note
- Procedure performed
- Findings
- Disposition (PACU, ward, ICU)
- Pain management plan
- Diet plan
- Wound care
- Follow-up
- Save

## Screen 6: Complication Tracking
- Date, type
- Clavien-Dindo grade (I-V)
- Treatment
- Outcome
- Save
