- [ ] IPSG.4 — WHO Surgical Safety Checklist (mandatory)
- [ ] IPSG.5 — SSI prevention
- [ ] Site marking
- [ ] Time-out
- [ ] Counts (sponges, instruments, sharps)

- [ ] Pre-op assessment
- [ ] Anesthesia safety
- [ ] Surgical site infection bundle
- [ ] VTE prophylaxis
- [ ] Normothermia
- [ ] Glycemic control
- [ ] Pain management

### Quality
- [ ] SSI rate (clean, clean-contaminated)
- [ ] VTE rate
- [ ] Unplanned return to OR
- [ ] Unplanned readmission (30 days)
- [ ] Mortality (per procedure type)
- [ ] Complication rate (Clavien-Dindo)
- [ ] LOS by procedure
- [ ] OR utilization
- [ ] First-case start on-time
