# PULM-001 — Data Flow

## Asthma Outpatient
```
1. Spirometry (PFT)
2. ACT score
3. Stepwise management
4. Inhaler technique check
5. Action plan
6. Follow-up (3-6 months)
```

## COPD Exacerbation
```
1. Severity assessment
2. CXR, ABG
3. Bronchodilator (SABA + SAMA)
4. Systemic steroid
5. Antibiotic (if infection)
6. O2 (target SpO2 88-92%)
7. NIV (BiPAP) if hypercapnic
8. Discharge planning
```

## PE Workup
```
1. Wells score
2. D-dimer
3. CTPA
4. Anticoagulation
5. Thrombolysis (massive)
6. Filter (if CI to anticoag)
7. Follow-up (3-6 months)
```

## Lung Cancer
```
1. Suspicious CXR or CT
2. CT chest + abdomen
3. PET-CT
4. Biopsy (bronch, CT-guided, EBUS)
5. Staging
6. MDT discussion
7. Treatment (surgery, chemo, rad)
```
