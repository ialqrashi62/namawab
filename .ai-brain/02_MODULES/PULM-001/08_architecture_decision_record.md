# PULM-001 — ADRs

## ADR-001: Multi-Tenant via tenant_id + RLS
**Status:** Accepted
**Decision:** Same as ER-001

## ADR-002: O2 = High-Alert
**Status:** Accepted
**Context:** O2 titration is critical in COPD (hyperoxia → CO2 retention)
**Decision:** O2 order includes target SpO2, titration plan
**Consequence:** Safer O2 management

## ADR-003: TB Notification to MOH
**Status:** Accepted
**Decision:** All TB cases notified within 24h
**Consequence:** Public health compliance

## ADR-004: Lung Cancer = MDT
**Status:** Accepted
**Decision:** All suspicious lung lesions discussed at MDT
**Consequence:** Optimal staging, treatment

## ADR-005: PFT = Required for All Chronic Lung
**Status:** Accepted
**Decision:** PFT at baseline + annually
**Consequence:** Objective monitoring

## ADR-006: AI = Assist, Not Replace
**Status:** Accepted
**Decision:** AI supports PFT interpretation, MDT discussion
**Consequence:** Faster, but human review

## ADR-007: Smoking Cessation = Mandatory
**Status:** Accepted
**Decision:** All smokers offered cessation (5A: ask, advise, assess, assist, arrange)
**Consequence:** Best intervention for COPD

## ADR-008: Home O2 = Strict Criteria
**Status:** Accepted
**Decision:** PaO2 <55 or <60 with cor pulmonale
**Consequence:** Cost-effective, evidence-based

## ADR-009: Sleep Study for OSA
**Status:** Accepted
**Decision:** Polysomnography (PSG) gold standard
**Consequence:** Correct diagnosis

## ADR-010: Pulmonary Rehab
**Status:** Accepted
**Decision:** Refer all symptomatic COPD, ILD
**Consequence:** Better QoL, function
