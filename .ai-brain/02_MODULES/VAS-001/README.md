# VAS-001 — Vascular Surgery

## Top Conditions

- TAA (thoracic)
- Aortic dissection
- Carotid stenosis
- PAD (peripheral artery disease)
- DVT (chronic)

## Red Flags
- Ruptured AAA (hypotension + back pain + pulsatile mass)
- Aortic dissection
- Acute limb ischemia (6 P's)
- Mesenteric ischemia
- Carotid dissection

- Risk prediction (perioperative MACE)
