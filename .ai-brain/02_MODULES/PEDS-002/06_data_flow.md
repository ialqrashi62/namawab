# PEDS-002 — Data Flow

## Admission to NICU
```
1. Birth (L&D or C-section)
2. Initial assessment: APGAR, weight, GA
3. Thermal management (warmer/incubator)
4. Respiratory support if needed
5. NICU admission order
6. Full admission assessment
7. First 24h: routine labs, weight-based orders
8. Family meeting
9. Daily rounds
```

## Ventilator Management
```
1. Respiratory support decision (CPAP vs vent)
2. Surfactant if RDS
3. Initial settings
4. ABG (q6-12h, or PRN)
5. Daily weaning trial
6. Extubation readiness
7. Extubation → NIV/NC
8. Reintubation criteria
```

## Feeding Advancement
```
1. Trophic feeds (1 mL) start day 2-3
2. Advance 1-2 mL/kg/day
3. Full feeds by day 7-10 (preterm)
4. TPN as needed
5. Breast milk preferred
6. Fortification at ~100 mL/kg/day
7. Goal growth 15-20 g/kg/day
```

## ROP Screening
```
1. Eligible: BW <1500g or GA <32w
2. First exam: 4-6 weeks chronological age
3. Continued q1-2 weeks until vascular maturity
4. Treatment: laser or anti-VEGF if stage 3+ or aggressive
```

## Discharge Planning
```
1. Thermoregulation (open cot)
2. Full oral feeds
3. No apnea for 5-7 days
4. Weight gain sustained
5. Parent education complete
6. Car seat challenge (if <37w corrected)
7. Hearing screen, metabolic screen, ROP exam
8. Follow-up appointments
```

## HIE (Therapeutic Hypothermia)
```
1. Eligibility: GA ≥36w, evidence of perinatal asphyxia
2. Within 6h of birth
3. Cooling to 33.5°C (blanket or mattress)
4. Maintain 72h
5. Rewarming 0.5°C/h
6. Continuous EEG
7. MRI day 7-10
8. Multidisciplinary follow-up
```
