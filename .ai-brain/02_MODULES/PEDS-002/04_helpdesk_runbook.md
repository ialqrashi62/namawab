## Helpdesk

### L1 Common Issues
- Cannot log in
- Vitals not saving
- Weight calculation error
- Surfactant order
- Parent communication
- Discharge plan

### L2 Issues
- Weight-based dose wrong
- Vent alarm
- ROP exam missed
- Hearing screen missing
- Follow-up not scheduled

### L3 Issues
- Dose calculation system fail
- Vent integration fail
- RLS violation
- Audit log corruption
- PHI leak

### On-Call
- Neonatologist (24/7)
- NICU charge nurse
- IT support
- Escalation: NICU director → CMO → CTO

### Runbook
- **Dose system fail:** Broselow tape
- **Vent fail:** Manual bagging, call RT
- **Apnea:** Stimulate, caffeine
- **PHI leak:** STOP service, DPO
- **Parent complaint:** NICU director
