# MEDICAL_UX_UI_DASHBOARDS_SKILL_AR

## الهدف
تحليل وتحسين تجربة المستخدم ولوحات التحكم للنظام الطبي.

## مبادئ التصميم
- واجهة عربية/إنجليزية احترافية
- دعم RTL و LTR
- تصميم مناسب للمستشفيات والمراكز الطبية
- تقليل الضغط على المستخدم
- وضوح الإجراءات الطبية الحساسة
- تمييز الحالات الحرجة
- سرعة الوصول للملف الطبي
- لوحة مختلفة حسب الدور
- لا تعرض بيانات طبية حساسة بدون صلاحية

## ما يجب فحصه
- الصفحة الرئيسية
- تسجيل الدخول
- Dashboard
- Sidebar
- Patient profile
- Appointment screens
- EMR screens
- Billing screens
- Insurance screens
- Pharmacy screens
- Lab screens
- Radiology screens
- Admin settings
- Reports pages

## لكل شاشة قيّم:
- الوضوح
- الاحترافية
- سهولة الاستخدام
- ازدحام البيانات
- منطق الأزرار
- الأخطاء المحتملة
- دعم الجوال
- دعم RTL
- حالات التحميل
- حالات الخطأ
- Empty states
- Permissions visibility

- أولويات إعادة التصميم
