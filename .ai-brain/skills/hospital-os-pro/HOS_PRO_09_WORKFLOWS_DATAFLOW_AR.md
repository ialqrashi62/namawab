# HOS_PRO_09_WORKFLOWS_DATAFLOW_AR

## الغرض
بناء سيناريوهات عمل End-to-End وفلو بيانات شامل من دخول المريض حتى الخروج والفوترة والتقارير.

## السيناريوهات الأساسية
1. مريض جديد:
تسجيل → موعد → زيارة → طبيب → مختبر/أشعة → وصفة → فاتورة → خروج.

2. مريض طوارئ:
فرز → كشف/إنعاش → أوامر → تنويم أو خروج.

3. مريض تنويم:
قبول → سرير → أوامر → تمريض → أدوية → نتائج → خروج.

4. عملية جراحية:
طلب عملية → موافقة → تخدير → غرفة عمليات → PACU → تنويم/خروج.

5. ولادة:
قبول → متابعة → ولادة → مولود → NICU عند الحاجة → خروج.

6. وصفة دوائية:
أمر طبي → مراجعة صيدلي → صرف → eMAR → إعطاء تمريضي.

7. طلب مختبر:
طلب → عينة → استلام → نتيجة → اعتماد → إشعار الطبيب.

8. طلب أشعة:
طلب → جدولة → تصوير → PACS → تقرير → اعتماد.

9. نقل دم:
طلب → توافق → صرف → إعطاء → مراقبة تفاعل.

10. مطالبة تأمين:
أهلية → موافقة → ترميز → مطالبة → رد → تسوية.

11. مكافحة عدوى:
بلاغ → تصنيف → عزل → متابعة → إغلاق.

12. حادثة سلامة مريض:
تسجيل → تحقيق → إجراء تصحيحي → إغلاق.

13. مخزون:
طلب قسم → اعتماد → صرف → استلام.

14. CSSD:
استلام أدوات → تعقيم → تسليم.

15. صيانة:
بلاغ → تقييم → إصلاح → إغلاق.

16. طب عن بعد:
حجز → جلسة → أوامر/وصفة → دفع → إغلاق.

17. بوابة مريض:
عرض المواعيد، النتائج، الفواتير، الموافقات.

18. وفاة:
توثيق → موافقات → شهادة → تسليم → أرشفة.

→ Encounter
→ Clinical Assessment
→ Orders
→ Diagnostics / Pharmacy / Procedures
→ Results / Administration
→ Clinical Decision
→ Billing / Insurance
→ Discharge / Follow-up
→ Portal / Reports / Audit
