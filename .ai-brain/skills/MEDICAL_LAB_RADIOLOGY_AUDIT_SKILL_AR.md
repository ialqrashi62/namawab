# مهارة تدقيق المختبر والأشعة (Lab & Radiology Audit)

## Purpose
تدقيق مسارات المختبر والأشعة: كتالوج الفحوصات، جمع العينات، الباركود، إدخال النتائج، التحقق، الاعتماد، تنبيهات النتائج الحرجة، جاهزية تكامل الأجهزة (LIS/HL7/ASTM)؛ وللأشعة: الطلب، جدولة الأجهزة، سير الفني، كتابة وتقرير الاعتماد، جاهزية PACS/DICOM، إشعار النتائج الحرجة.

## When to Use
عند تدقيق وحدات المختبر/الأشعة أو فحص جاهزية تكامل الأجهزة.

## Inputs Needed
مسارات `/api/lab/*`, `/api/radiology/*`, `/api/pathology/*`؛ نماذج lab_*/radiology_*.

## Procedure
1. المختبر: طلب → عينة → باركود → نتيجة → تحقّق → اعتماد. تحقّق أن النتيجة لا تصبح نهائية بلا اعتماد.
2. الأشعة: طلب → جدولة → دراسة → تقرير → اعتماد. تحقّق أن التقرير لا يكون نهائياً قبل اعتماد أخصائي الأشعة.
3. افحص تنبيهات النتائج/النتائج الحرجة وجاهزية LIS/PACS/DICOM.
4. عزل tenant + منع IDOR.

## Safety Rules
قراءة فقط. النتائج/التقارير النهائية تتطلب اعتماداً. لا بيانات حقيقية في التقارير.

## Output Format
سيناريوهات المختبر/الأشعة + تدفّقات + الموديولات الناقصة + مخاطر منطق العمل (ضمن تقارير السيناريوهات/المنطق).

## Done Criteria
مسارات المختبر والأشعة موثّقة، قواعد الاعتماد مُتحقَّق منها، جاهزية التكامل مُقيّمة، اختبارات مطلوبة.
