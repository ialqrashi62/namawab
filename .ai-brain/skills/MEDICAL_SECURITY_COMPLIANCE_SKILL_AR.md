# MEDICAL_SECURITY_COMPLIANCE_SKILL_AR

## الهدف
تحليل مخاطر الأمن والخصوصية والامتثال في النظام الطبي.

## مجالات الفحص
- Authentication
- Authorization
- Role-Based Access Control
- Tenant isolation
- Patient data privacy
- Audit logs
- API protection
- Input validation
- File upload security
- Medical attachments
- Sensitive data exposure
- Database access patterns
- Error messages
- Session handling
- Admin privileges
- Logs and secrets
- Backup and recovery readiness

## مبادئ مهمة
- بيانات المرضى عالية الحساسية.
- أي صلاحية عامة أو مفتوحة تعتبر خطر.
- أي API بدون تحقق صلاحيات خطر.
- أي تسريب في logs أو errors خطر.
- تعدد المستأجرين يحتاج عزل صارم.
- لا يجوز خلط بيانات منشأة مع أخرى.
