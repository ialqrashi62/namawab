# جمانة سوفت — نظام التصميم (UI/UX)

نظام تصميم واجهات جمانة سوفت ERP المتجاوب، والذي يدعم الاتجاهين (RTL/LTR) والوصولية المتقدمة لضمان تجربة مستخدم احترافية.

---

## إرشادات التشغيل الفعال (Progressive Disclosure)

### متى تُفعّل المهارة:
تُفعّل عند تصميم واجهات مستخدم جديدة، أو تعديل الصفحات والتخطيطات الحالية للوحات التحكم الإدارية أو الطبية، أو إدخال عناصر تجميلية وخطوط ونماذج تفاعلية جديدة.

### المدخلات المطلوبة:
- متطلبات الواجهة ومواصفات الألوان ونظام الألوان المعتمد.
- تخطيط العناصر بما يتناسب مع اتجاه RTL العربي.
- ترويسات الحماية وسياسات أمان المتصفح (CSP).

### المخرجات المتوقعة:
- واجهة مستخدم ذات جمالية فائقة ومهيأة للوصولية (a11y).
- كود خالي تماماً من الـ XSS بفضل تهريب البيانات المدخلة قبل عرضها.
- أداء متجاوب وسريع على الهواتف والأجهزة المكتبية.

### بوابات الجودة (Gates):
- **G6** (الحماية والأمان)، **G7** (الاختبار البصري والاستقرار)، **G8** (النشر الخالي من التعطيل).

### شروط التوقف الفوري:
توقف فوراً عند إدخال بيانات المستخدم دون تهريب (`escapeHTML`) مما يعرض النظام لهجمات حقن الكود XSS، أو كسر التوافق البصري باللغة العربية RTL، أو تدهور سرعة استجابة الموقع.

---

## المبادئ الأساسية
- **عربي RTL أساسي** + إنجليزي LTR. تبديل لغة سلس. خطوط عربية واضحة.
- وصولية (a11y): تباين كافٍ، تنقّل لوحة مفاتيح، ARIA، «تخطّي إلى المحتوى» (موجود في الموقع الحيّ).
- اتساق: نظام ألوان/مسافات/مكوّنات موحّد (tokens). داكن/فاتح.

## اللوحة الاحترافية (Dashboard)
- شريط جانبي تنقّل + ترويسة سياق المستأجر (ظاهر حالياً: «جمانة الطبي»، سياق المستأجر).
- بطاقات مؤشّرات (KPIs)، رسوم (Chart.js)، جداول قابلة للفرز/التصفية.
- حالات فارغة/تحميل/خطأ مصمّمة. تأكيد للإجراءات الخطرة.

## الأمان في الواجهة (إلزامي)
- **هرّب كل مخرَج مستخدم** عند الإدراج في DOM (`escapeHTML`) — لا `innerHTML` خام لبيانات المستخدم. راجع [[jumanasoft-security-audit]].
- CSP enforce مفعّل – تجنّب inline handlers الجديدة قدر الإمكان؛ اختبر بصرياً بعد أي تشديد CSP.

## الأداء (= تجربة + SEO)
- Core Web Vitals، lazy-load، تقليل JS، صور محسّنة. راجع [[jumanasoft-observability-deployment]] و [[jumanasoft-seo-geo-growth]].
