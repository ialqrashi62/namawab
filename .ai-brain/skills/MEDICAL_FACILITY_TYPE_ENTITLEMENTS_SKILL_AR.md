# مهارة استحقاقات أنواع المنشآت (Facility-Type Entitlements)

## Purpose
تدقيق وتصميم إعداد المنشآت حسب النوع وتفعيل الموديولات/الميزات/الحدود — على ألا يكون مجرد إخفاء قوائم في الواجهة بل إنفاذ في UI + API + Service + DB.

## When to Use
عند تدقيق onboarding المستأجرين، أو تصميم الخطط/الاستحقاقات، أو فحص تسرّب الوصول لموديولات غير مفعّلة.

## Inputs Needed
نماذج tenant/facility، `FACILITY_ALLOWED` في app.js، مسارات إنشاء المستأجر، جداول الخطط/الاستحقاقات إن وُجدت.

## Procedure
1. أنواع المنشآت العشرة: مدينة طبية، مستشفى كبير/متوسط/صغير، مستوصف، مركز صحي، مركز متخصص، صيدلية فقط، مختبر فقط، أشعة فقط.
2. افحص لكل نوع: نموذج FacilityType، Plan/Edition، ModuleEntitlements، FeatureEntitlements، UsageLimits، RoleTemplates، PermissionTemplates، القوالب الافتراضية (أقسام/شجرة حسابات/كتالوج خدمات/مخزون).
3. تحقّق من الإنفاذ: هل الاستحقاقات مخزّنة في DB (لا الواجهة فقط)؟ هل API يرفض الموديول غير المفعّل؟

## Safety Rules
لا تعتبر إخفاء القائمة إنفاذاً. لا تعديل إنتاج. أي إنفاذ ناقص = خطر يُسجَّل.

## Output Format
`docs/FACILITY_TYPE_ENTITLEMENTS_AUDIT_AR.md` — مصفوفة: نوع المنشأة | الموديول | مفعّل؟ | الحد | add-on؟ | مُنفَّذ API؟ | مُنفَّذ UI؟.

## Done Criteria
كل نوع منشأة مقيّم باستحقاقاته وحالة إنفاذها (DB/API/UI) مع الفجوات.
