# HOS_RBAC_AUDIT_AR
# الصلاحيات والتدقيق في نظام المستشفى

## RBAC الأساسي
لكل شاشة/API/عملية حدد:
- View
- Create
- Update
- Approve
- Cancel
- Delete إذا كان مسموحاً
- Print
- Export
- Override
- Emergency Access
- Sensitive Data Access

## قواعد الصلاحيات
- الطبيب يرى ويحرر ضمن نطاقه السريري.
- التمريض يوثق وينفذ ويراقب ولا يتجاوز أوامر الطبيب.
- الصيدلية تراجع الدواء وتصرف وتمنع المخاطر الدوائية.
- المختبر يسجل النتائج ولا يغير أوامر الطبيب.
- الأشعة تسجل التقارير ولا تغير التشخيص الأصلي إلا كتقرير طبي مستقل.
- الفوترة والتأمين لا يغيران السجل السريري.
- الإدارة ترى مؤشرات وتشغيل حسب الصلاحية.
- السجلات الطبية تدير الملف والترميز والأرشفة.
- الجودة ترى مؤشرات وسجلات تدقيق دون العبث بالبيانات الأصلية.

## Audit Log إلزامي عند:
- إنشاء زيارة.
- تعديل بيانات مريض.
- أمر طبي.
- وصفة.
- صرف دواء.
- نتيجة مختبر.
- تقرير أشعة.
- نقل دم.
- عملية.
- موافقة/إقرار.
- مطالبة تأمين.
- فاتورة.
- إلغاء.
- Override.
- Emergency Access.
- تصدير أو طباعة بيانات حساسة.
