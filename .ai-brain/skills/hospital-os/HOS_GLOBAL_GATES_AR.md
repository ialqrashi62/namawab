# HOS_GLOBAL_GATES_AR
# بوابات الحوكمة والسلامة لنظام المستشفى

## القواعد الصارمة
- لا تعرض أسراراً أو كلمات مرور أو مفاتيح API أو بيانات مرضى حقيقية.
- لا تنفذ Production Deploy أو Migration أو DDL أو Data Write إلا بموافقة صريحة.
- لا تفترض أن الطبيب والممرض والإداري يملكون نفس الصلاحيات.
- لا تسمح للفوترة أو التأمين بتعديل أوامر الطبيب.
- لا تسمح للصيدلية بتغيير التشخيص.
- لا تسمح للمختبر أو الأشعة بتعديل أوامر الطبيب.
- أي قرار سريري عالي الخطورة يحتاج مراجعة بشرية مرخصة.
- أي فشل في بوابة حرجة يوقف المرحلة فوراً.

## بوابات التنفيذ
GATE 0: تحديد النطاق والأقسام.
GATE 1: فحص اكتمال الأقسام.
GATE 2: بناء الشخصيات والأدوار.
GATE 3: بناء تغطية التمريض.
GATE 4: بناء RBAC.
GATE 5: بناء Workflows.
GATE 6: بناء Integrations.
GATE 7: بناء Safety & Compliance.
GATE 8: بناء Test Plan.
GATE 9: بناء Reports & Audit.
GATE 10: فحص عدم وجود إسقاط.
GATE 11: تقرير نهائي.

## الحالة النهائية
- PASS: مكتمل وآمن.
- PARTIAL: مكتمل جزئياً مع نواقص موثقة.
- BLOCKED: متوقف بسبب خطر أو نقص حاسم.
