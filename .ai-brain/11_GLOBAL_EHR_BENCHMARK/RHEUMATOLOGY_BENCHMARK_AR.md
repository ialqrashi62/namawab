# Rheumatology Benchmark — Epic, Cerner, MEDITECH

## Mandatory features

### 1. Disease Activity Scores
- [x] DAS28 (RA) — **shipped** `das28`
- [x] DAPSA (PsA)
- [ ] SLEDAI (SLE)
- [ ] BASDAI / BASFI (ankylosing spondylitis)
- [ ] PASI (psoriasis)
- [ ] ASDAS (axial SpA)

### 2. Treatment
- [ ] DMARDs (MTX, leflunomide, sulfasalazine, HCQ)
- [ ] Biologics (TNF, IL-6, IL-17, IL-23, B-cell, T-cell)
- [ ] JAK inhibitors (tofacitinib, baricitinib)
- [ ] Pre-biologic screening (TB, HepB, HepC, Quantiferon)

### 3. Monitoring
- [ ] Labs: CBC, LFT, Cr
- [ ] Eye exam (HCQ → retinopathy q5y after 5y)
- [ ] Joint count (tender/swollen 28)
- [ ] Patient-reported outcomes (HAQ, RAPID3)

### 4. Imaging
- [ ] X-ray (Sharp score for RA)
- [ ] MRI (synovitis, erosions)
- [ ] Ultrasound (greyscale, Doppler)

### 5. Biologics Eligibility
- [ ] Pre-screening checklist
- [ ] Insurance prior auth
- [ ] Patient assistance programs

### 6. Autoimmune Workup
- [ ] ANA pattern, titer
- [ ] ENA panel
- [ ] Anti-CCP, RF
- [ ] Anti-dsDNA (SLE)
- [ ] Complement C3/C4

### 7. Vasculitis
- [ ] ACR/EULAR classification criteria
- [ ] BVAS score

### 8. Gout
- [ ] 2015 ACR/EULAR criteria
- [ ] ULT dosing (allopurinol, febuxostat)

### 9. Osteoporosis (link bone density)
- [ ] FRAX
- [ ] Bisphosphonate holiday

### 10. Quality
- [ ] Treat-to-target compliance
- [ ] Time to first biologic
