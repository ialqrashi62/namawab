# Neurology Benchmark — Epic, Cerner, MEDITECH

## Mandatory features

### 1. Stroke
- [x] NIHSS (severity) — **shipped** `neurology`
- [ ] mRS (modified Rankin) at discharge
- [ ] ABCD2 (TIA risk)
- [ ] ASPECTS (CT perfusion)
- [ ] Door-to-needle (target < 60 min)
- [ ] Thrombectomy eligibility (LVO)
- [ ] Hemicraniectomy decision support
- [ ] Hemorrhagic stroke (ICH score)

### 2. Epilepsy
- [ ] Seizure classification (ILAE 2017)
- [ ] ASM (anti-seizure med) levels
- [ ] VNS (vagus nerve stim) settings
- [ ] EEG report
- [ ] SUDEP counseling

### 3. Movement Disorders
- [ ] UPDRS (Parkinson's)
- [ ] Hoehn & Yahr staging
- [ ] Tremor rating
- [ ] Dyskinesia diary
- [ ] DBS (deep brain stim) settings

### 4. Multiple Sclerosis
- [ ] EDSS (Expanded Disability Status Scale)
- [ ] MRI lesion tracking
- [ ] DMT (disease-modifying therapy)
- [ ] Relapse tracking
- [ ] PROMs (MSQOL-54)

### 5. Headache
- [ ] MIDAS (migraine disability)
- [ ] HIT-6
- [ ] Botox for chronic migraine

### 6. Dementia
- [ ] MMSE / MoCA
- [ ] CDR (Clinical Dementia Rating)
- [ ] Functional Assessment Staging (FAST)

### 7. Neuromuscular
- [ ] ALS Functional Rating Scale (ALSFRS-R)
- [ ] CMAP / needle EMG

### 8. Multiple Sclerosis DMT
- [ ] Rebif, Copaxone, Tysabri, Ocrevus, Mavenclad, Kesimpta

### 9. Botulinum Toxin
- [ ] Injection mapping
- [ ] Dose tracking

### 10. Telestroke
- [ ] Remote consult
- [ ] Image sharing

## Shipped
- NIHSS (11 items, 0-42 scale)

## Sources
- AHA/ASA Stroke Guidelines 2023
