# Workflows
- **MICU/SICU/Trauma ICU** (مركزة عامة): intake → assessment → plan → followup
- **CCU post-cath/CABG** (قلبية): intake → assessment → plan → followup
- **Neuro/PICU/NICU/Burn/Onc/Renal/Transplant/Obstetric ICU** (تخصصية): intake → assessment → plan → followup
- **Anesthesia OR/Obstetric/Peds/Cardiac** (تخدير): intake → assessment → plan → followup
- **Interventional Pain RF/SCS/Pumps** (ألم تداخلي): intake → assessment → plan → followup
- **PACU** (إفاقة): intake → assessment → plan → followup
- **HBOT** (أكسجين ضغط): intake → assessment → plan → followup
