# 04 UX/UI Stitch — Administrative Operations

## 1. Design Tokens
- **Palette**: executive navy, KPI accent colors, neutral grays.
- **Typography**: admin dashboard fonts.
- **Layout**: dashboard + settings panels.

## 2. Components
- `ExecutiveDashboard`: KPI cards, charts, filters.
- `ReportBuilder`: drag-and-drop report designer.
- `TenantConfigPanel`: feature flags and settings.
- `RoleManager`: roles and permissions matrix.
- `AuditSummary`: top events and trends.

## 3. User Stories
- "As a CEO, I want a dashboard of occupancy, revenue, and quality KPIs."
- "As a Super Admin, I want tenant-level feature flags with change history."

## 4. Wireframe Logic
- Top: executive dashboard.
- Left: admin menu (reports, tenant, roles, settings, audit).
- Center: selected module.
- Right: alerts + recent activity.

## 5. Accessibility
- RTL/LTR, keyboard navigation, high-contrast charts.
