# 04 UX/UI Stitch — Rehabilitation Support Services

## 1. Design Tokens
- **Palette**: support green, equipment blue, home safety amber.
- **Typography**: same as Stitch clinical stations.
- **Layout**: list+drawer.

## 2. Components
- `EquipmentLoanForm`: device, dates, patient, condition.
- `HomeAssessmentChecklist`: rooms, hazards, modifications.
- `CaregiverTrainingLog`: topics, dates, acknowledgments.
- `CommunityReferralCard`: agency, contact, status.

## 3. User Stories
- "As a rehab therapist, I want to track equipment loans and returns."
- "As a social worker, I want home assessment checklists linked to discharge."

## 4. Wireframe Logic
- Left: patient list + support request queue.
- Center: equipment/home/training/referral tabs.
- Right: alerts + discharge plan summary.

## 5. Accessibility
- RTL/LTR, simple checklists, touch-friendly forms.
