# GATE 1 — تحليل الفجوات مقابل المعيار العالمي (Global Gap Analysis)

**التاريخ**: 2026-07-06 | **المرجع**: جرد Gate 0 (`hospital-sidebar-inventory-ar.md`) — 44 قسماً | **المعيار**: منظومات HIS/EHR العالمية (Epic/Cerner/InterSystems نمطياً) + المتطلبات السعودية (CBAHI، NPHIES، ZATCA، وزارة الصحة) | **القرار**: ✅ PASS

## المنهجية

- المقارنة على مستوى **القدرة التشغيلية** (Capability) لا الاسم: القسم يُعد «موجوداً» فقط إذا كانت له شاشة عاملة بمهام سير عمل حقيقية.
- كل إضافة مقترحة مسنودة بمبرر **سريري** (سلامة مرضى) أو **مالي** (دورة إيرادات) أو **امتثالي** (CBAHI/NPHIES/ZATCA) — لا تضخيم بلا قيمة.
- الحالات: `موجود-مكتمل` / `موجود-ناقص` (يشمل الهيكلي placeholder) / `مفقود` / `دمج` (مرشح للدمج في قسم آخر).
