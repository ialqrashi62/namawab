# Memory Update - Deferred Legacy Security Hardening

تحديث الذاكرة المعرفية للنظام:

- **عزل المستأجرين**: يجب عند كتابة أو تعديل أي مسارات أو جداول قديمة/جديدة التأكد من تمرير `requireTenantScope` وحقن وتصفية `tenant_id` في الاستعلامات.
- **مصفوفة الصلاحيات**: تم تحديث مصفوفة الصلاحيات الافتراضية بنجاح لتشمل CME ونقل المرضى والطب عن بعد.
- **تأمين الأسرار**: الكلمات الدلالية وكلمات المرور في ملفات الاختبار يجب أن تنتهي دائماً بـ `_CHANGE_ME` أو ما يماثلها لتفادي اعتراض فاحص الأسرار.
