# نتائج الاختبارات - اختبارات المتصفح الشاملة (E2E Playwright Smoke Tests)

| الفحص / السيناريو | النتيجة | التفاصيل والبيانات |
|---|---|---|
| فحص الدخول الخاطئ (Invalid Login) | PASS | إرجاع 401 عند محاولة تسجيل دخول ببيانات غير مطابقة. |
| فحص الدخول الصحيح (Valid Login) | PASS | قبول الدخول بنجاح وتوليد الجلسة. |
| فحص استدعاء المسارات المحمية | PASS | الوصول للوحة التحكم وقوائم المرضى والمواعيد والفواتير برمز 200. |
| حماية بيانات PHI الحساسة | PASS | حظر طباعة سياق معلومات المرضى في السجلات التشغيلية. |
| فحص الـ Rate Limiter | PASS | الحظر التلقائي برمز 429 عند تجاوز حد المحاولات الـ 20. |
