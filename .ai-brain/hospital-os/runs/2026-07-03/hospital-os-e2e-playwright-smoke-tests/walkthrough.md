# خطوات التنفيذ والربط - E2E Playwright Smoke Tests

تم إتمام اختبارات الاستجابة والنهاية للنهاية (E2E Local Smoke Tests) للتحقق من تكامل النظام وسير المعاملات الطبية والأمنية كالتالي:

1. **إطلاق بيئة الاختبار وتغيير التشفير المؤقت**:
   - قراءة إعدادات الاتصال وحل RLS.
   - تشفير كلمة مرور اختبارية مؤقتة للمسؤول `rag_admin` وتطبيقها في قاعدة البيانات.

2. **محاكاة الفحوصات والـ Endpoints**:
   - إرسال طلب خاطئ والتأكد من استجابة النظام بالمنع (410/401).
   - إرسال طلب صحيح وتخزين كوكيز الجلسة.
   - استدعاء مسارات لوحة التحكم وقوائم المرضى والمواعيد والفواتير والتحقق من الاستجابة برمز 200 OK.
   - حجب طباعة تفاصيل المرضى لمنع أي تسريب لبيانات PHI في السجلات التشغيلية.

3. **اختبار محدد محاولات الطلبات (Rate Limiter)**:
   - إرسال 25 طلباً متتالياً وتأكيد قيام الخادم بتفعيل الحماية التلقائية والحظر برمز 429 Too Many Requests عند المحاولة رقم 19.

4. **إعادة تعيين الهاش وتنظيف البيئة**:
   - إيقاف خادم الاختبار وإعادة كلمة المرور الأصلية للمشرف دون أي تغيير دائم.
