# المهمة

تأكيد معرفة النواقص مقارنة بالأنظمة العالمية، وبدء المشروع على مراحل باستخدام Hospital OS Skills وAuto Pilot وai-brain governance.

## النطاق
- تحويل التقارير السابقة إلى خطة مراحل تنفيذية.
- تحديد أولويات P0/P1/P2/P3.
- تثبيت Phase 1 كنقطة البداية: Safety, Tenant, RBAC, Audit.
- عدم تنفيذ كود أو UI أو DB في هذه المرحلة.

## القيود
- لا Production Deploy.
- لا DDL.
- لا Migration.
- لا Data Write.
- لا أسرار.
- لا PHI.
- لا UI جديد دون Stitch Source أو Stitch Prompt.
