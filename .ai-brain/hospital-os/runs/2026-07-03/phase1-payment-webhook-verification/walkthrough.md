# Walkthrough

1. تم فتح تقرير الموجة السابقة وتحديد أن webhooks/callbacks الخارجية بقيت كخطر.
2. تم فحص مسارات `Moyasar` و`Stripe` الخاصة بتعيين خطط المستأجر.
3. تم إضافة حارس توقيع HMAC fail-closed في الإنتاج.
4. تم إضافة تحقق metadata للـ `tenant_id` و`plan_key`.
5. تم تحديث الاختبار الثابت.
6. تم تشغيل الفحوصات الآمنة.
