## 🎯 Group-Level Clinical Authority (CMO)

### OBGYN Universal Workflow

**Antenatal care schedule (low-risk pregnancy):**

| Visit | Gestational age | Key tasks |
|---|---|---|
| Booking | < 12 weeks | Dating US, bloods (CBC, blood group, Ab, Rubella, Hep B, HIV, syphilis, urine), Pap, GBS |
| 16-18 weeks | Second trimester | Quad screen, anatomy US at 18-20w |
| 20-22 weeks | Anatomy scan | Detailed US, anomaly detection |
| 24-28 weeks | Glucose screen | OGTT 75g; if abnormal, GDM diagnosis |
| 28 weeks | Third trimester start | Anti-D if Rh-, Tdap vaccine |
| 32 weeks | Growth scan | US, position |
| 36 weeks | GBS screen | Vaginal/rectal swab |
| 38-40 weeks | Term | Position check, discuss delivery |
| 41 weeks | Post-term | Consider induction |

**Intrapartum care (WHO recommendations):**
- 1:1 midwifery care in active labor
- Fetal monitoring (intermittent auscultation low-risk; continuous EFM high-risk)
- Partograph for labor progress
- Active management third stage (AMTSL) for postpartum hemorrhage prevention
- Skin-to-skin contact within 1h of birth
- Delayed cord clamping 1-3 min (preterm: 30-60s)
- Exclusive breastfeeding initiation within 1h

**Postpartum care:**
- 24h, 1w, 6w visits
- Mental health screening (EPDS at 6w)
- Family planning counseling
- Lochia monitoring, bleeding
- Cesarean wound check (if applicable)
- Newborn screening, vaccines

### Gynecology Universal Workflow

**Well-woman annual:**
- History (menstrual, sexual, contraceptive, GYN surgeries, family history of breast/ovarian)
- Physical: breast, pelvic
- Pap smear (cervical cancer screening): age 21-65, q3y (or q5y with HPV co-test age 30+)
- Mammogram: age 40-50 per guidelines, q1-2y
- HPV vaccine: catch-up to age 26, shared decision 27-45
- STI screening: chlamydia/gonorrhea < age 25 yearly
- Bone density: age 65+

**Common GYN conditions:**
- Abnormal uterine bleeding → PALM-COEIN (Polyp, Adenomyosis, Leiomyoma, Malignancy, Coagulopathy, Ovulatory, Endometrial, Iatrogenic, Not classified)
- PCOS → Rotterdam criteria (2 of 3: oligo/anovulation, hyperandrogenism, polycystic ovaries)
- Endometriosis → clinical dx, MRI/laparoscopy gold standard
- Infertility → workup after 12mo < 35y, 6mo ≥ 35y
- Menopause → hormone therapy decision (timing hypothesis: < 10y from menopause is favorable)

### Pediatrics Universal Workflow

**Well-child visit schedule:**
- Newborn (3-5d), 1mo, 2mo, 4mo, 6mo, 9mo, 12mo, 15mo, 18mo, 24mo, then yearly
- Vaccines per KSA MOH schedule
- Growth chart (weight, height, head circumference < 3y, BMI > 2y)
- Developmental screening (ASQ-3, M-CHAT at 18mo, 24mo)
- Vision screening (3y+), hearing (newborn, school entry)
- Lead screening (12mo, 24mo if at risk)
- Anemia screening (12mo, 24mo if at risk)
- Autism screening (18mo, 24mo)

**Vaccines (KSA MOH):**
- Birth: HepB, BCG, OPV
- 2mo: DPT, Hib, IPV, PCV, Rota, HepB
- 4mo: DPT, Hib, IPV, PCV, Rota
- 6mo: DPT, Hib, IPV, PCV, HepB, OPV, Influenza
- 9mo: MCV, OPV
- 12mo: MMR, Varicella, PCV booster, HepA
- 18mo: DPT booster, OPV, Hib booster
- 24mo: HepA booster
- 4-6y: DPT booster, OPV, MMR booster, Varicella booster
- 12y: Tdap, HPV (2-3 doses)

**Pediatric vital signs by age:**

| Age | HR (normal) | RR | SBP |
|---|---|---|---|
| Newborn | 100-205 | 30-60 | 60-90 |
| 1mo-1y | 100-180 | 30-53 | 70-100 |
| 1-3y | 98-140 | 22-37 | 80-110 |
| 3-5y | 80-120 | 20-28 | 90-110 |
| 6-12y | 75-118 | 18-25 | 95-115 |
| >12y | 60-100 | 12-20 | 100-120 |

### Neonatology (NICU) Special Considerations

**Apgar score (1 and 5 min):**
| Score | 0 | 1 | 2 |
|---|---|---|---|
| HR | absent | < 100 | ≥ 100 |
| RR | absent | slow, irregular | good cry |
| Muscle tone | limp | some flexion | active motion |
| Reflex irritability | none | grimace | cry, cough |
| Color | blue, pale | acrocyanosis | pink |

**Total: 0-10. < 7 at 5 min = need resuscitation.**

**Neonatal resuscitation (NRP):**
- Initial steps: warm, position, clear airway (if needed), dry, stimulate
- HR < 100: PPV with 21% O2 (term) or 21-30% (preterm)
- HR < 60 after 30s PPV: chest compressions + intubate
- Epinephrine 0.01-0.03 mg/kg IV

**Common NICU conditions:**
- RDS (respiratory distress syndrome) → surfactant
- BPD (bronchopulmonary dysplasia)
- IVH (intraventricular hemorrhage)
- NEC (necrotizing enterocolitis)
- ROP (retinopathy of prematurity)
- PDA (patent ductus arteriosus)

```javascript
// obgyn_engine.js

// Apgar Score
function calculateApgar({ heartRate, respiratoryEffort, muscleTone, reflexIrritability, color }) {
    const score = heartRate + respiratoryEffort + muscleTone + reflexIrritability + color;
    return { score, interpretation: score >= 7 ? 'normal' : score >= 4 ? 'moderately_depressed' : 'critically_depressed' };
}

// Bishop Score (cervical favorability for induction)
function calculateBishop({ dilation, effacement, station, position, consistency }) {
    const score = dilation + effacement + station + position + consistency;
    return { score, favorability: score >= 8 ? 'favorable' : score >= 6 ? 'borderline' : 'unfavorable_induction_likely_failed' };
}

// Edinburgh Postnatal Depression Scale (EPDS)
function calculateEPDS(answers) {
    // 10 questions, 0-3 each, total 0-30
    const total = answers.reduce((sum, a) => sum + a, 0);
    return { score: total, risk: total >= 13 ? 'positive_screen' : total >= 10 ? 'borderline' : 'low' };
}

// Pregnancy dating
function calculateEDD({ lmpDate }) {
    // Naegele's rule: LMP + 280 days, - 3 months, + 7 days
    const lmp = new Date(lmpDate);
    const edd = new Date(lmp);
    edd.setDate(edd.getDate() + 280);
    return { edd_date: edd.toISOString().slice(0, 10) };
}

// GA at any date
function calculateGA({ lmpDate, currentDate }) {
    const lmp = new Date(lmpDate);
    const now = new Date(currentDate);
    const daysDiff = Math.floor((now - lmp) / (1000 * 60 * 60 * 24));
    const weeks = Math.floor(daysDiff / 7);
    const days = daysDiff % 7;
    return { weeks, days, total_days: daysDiff, trimester: weeks < 13 ? 'T1' : weeks < 27 ? 'T2' : 'T3' };
}

// GDM diagnosis (IADPSG 75g OGTT)
function diagnoseGDM({ fasting, oneHour, twoHour }) {
    // 75g OGTT: any one abnormal -> GDM
    // Fasting >= 92, 1h >= 180, 2h >= 153
    const criteria = { fasting: fasting >= 92, oneHour: oneHour >= 180, twoHour: twoHour >= 153 };
    return { gdm: Object.values(criteria).some(v => v), criteria, recommendation: 'IADPSG' };
}

// Pre-eclampsia screening (ACOG)
function screenPreeclampsia({ sbp, dbp, proteinuria, severeFeatures, gaWeeks }) {
    if (sbp >= 160 || dbp >= 110) return { severity: 'severe', features: ['severe_htn'] };
    if (sbp >= 140 || dbp >= 90) {
        if (proteinuria) return { severity: 'preeclampsia', ga: gaWeeks };
    }
    return { severity: 'normal' };
}

module.exports = { calculateApgar, calculateBishop, calculateEPDS, calculateEDD, calculateGA, diagnoseGDM, screenPreeclampsia };
```
