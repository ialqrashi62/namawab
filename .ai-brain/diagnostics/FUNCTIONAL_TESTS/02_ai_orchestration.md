## 1. AI Architecture: The Physiological Brain
Waveform analysis RAG for anomaly detection in ECG/EEG/EMG.

### A. VectorMine Implementation
- **Vector Database:** PGVector storing embeddings of physiological waveforms.
- **Retrieval:** Semantic search to match current waveforms with "Pathological Patterns".

## 2. LangChain Orchestration
- **Chain 1: Waveform Analysis:** `Input (Raw Waveform) -> Vector Search (Similar Patterns) -> LLM (Analysis) -> Output (Suggested Interpretation)`.
- **Chain 2: Functional Trend Predictor:** `Input (Serial Tests) -> Predictive Model -> LLM (Summary) -> Output (Disease Progression Rate)`.
