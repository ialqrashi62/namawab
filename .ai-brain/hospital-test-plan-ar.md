# خطة الاختبار الشاملة وبوابات السلامة والامتثال — NamaMedical (jumanasoft)
## GATE 12 (خطة الاختبار) + GATE 11 (بوابات السلامة والامتثال)

> **الحالة:** وثيقة تخطيط معتمدة للتنفيذ اللاحق — لا تتضمن أي DDL ولا أي لمس لبيئة الإنتاج.
> **النطاق:** نظام معلومات مستشفيات سعودي متعدد المستأجرين (SaaS) — Express monolith + PostgreSQL مع 150 سياسة RLS من نوع FORCE + واجهة Vanilla JS ثنائية الاتجاه (عربي RTL / إنجليزي LTR).
> **المرجعية:** الكتالوج النهائي المعتمد في Gate 2 (10 مجموعات A–J، 75+ قسماً)، وسجل الفجوات العليا (تخدير/PACU، NICU، أهلية NPHIES، OVR، OPD، إدارة الأسرّة، محطات التمريض التخصصية).

## 4. اختبارات سير العمل — الرحلات السبع (Workflow Tests)

كل رحلة تُختبر: (أ) المسار السعيد كاملاً، (ب) الانقطاع في كل خطوة، (ج) التزامن (مستخدمان على نفس السجل)، (د) عبر مستأجرين للتأكد من العزل.

### الرحلة 1 — العيادات الخارجية OPD
تسجيل MPI → التحقق من أهلية NPHIES → موعد → قائمة الانتظار → محطة الطبيب (SOAP + CPOE) → مختبر/أشعة → رجوع النتائج وإقرار الطبيب → وصفة → صرف صيدلية → فاتورة → مطالبة.
**نقاط فحص حرجة:** إغلاق حلقة الأمر-النتيجة (Gate 3)، عدم فوترة خدمة غير منفَّذة، عدم صرف وصفة غير موقَّعة.

### الرحلة 2 — الطوارئ ER
وصول → فرز ESI (1–5) → EWS تلقائي → أوامر طارئة → قرار (خروج/تنويم/إحالة/عمليات) → تسليم SBAR.
**نقاط فحص:** ESI-1 يفتح مسار إنعاش فوري متجاوزاً التسجيل الكامل (تسجيل لاحق)، مريض مجهول الهوية يُنشأ له MPI مؤقت يُدمج لاحقاً بلا فقد بيانات.

### الرحلة 3 — التنويم ADT
قرار تنويم → طلب سرير (إدارة الأسرّة) → دخول → توثيق تمريضي (NEWS2/eMAR) → تحويلات داخلية → قرار خروج → تسوية مالية → خروج → ملخص خروج → قفل EMR.
**نقاط فحص:** لا خروج مالي قبل إقرار كل النتائج الحرجة المعلّقة؛ التحويل يحرّر السرير القديم ويحجز الجديد ذرّياً.

### الرحلة 4 — الجراحة (الأخطر — تشمل فجوتي التخدير وPACU)
جدولة عمليات → تقييم ما قبل التخدير → إقرار موافقة جراحية موقّع → Time-Out (WHO Checklist) → توثيق تخدير أثناء العملية → عدّ الشاش والأدوات → نقل إلى PACU → درجة Aldrete → خروج من الإفاقة → جناح.
**نقاط فحص:** منع بدء العملية بلا موافقة موقّعة وبلا تقييم تخدير مكتمل؛ عدم إغلاق سجل العملية مع عدّ أدوات غير مطابق.

### الرحلة 5 — الولادة وحديثي الولادة
تسجيل حامل → متابعة → مخاض (بارتوغرام) → ولادة → APGAR (دقيقة 1/5/10 من محرك الدرجات) → سجل مولود مرتبط بالأم → NICU عند الحاجة → تطعيمات المولود → خروج مزدوج.
**نقاط فحص:** إصلاح Route-Shadowing في مسار الحمل المزدوج (Gate 6) لا ينتكس؛ المولود كيان مستقل موروث الديموغرافيا لا نسخة من ملف الأم.

### الرحلة 6 — نقل الدم (سلسلة كاملة)
طلب طبيب مع الاستطباب → سحب عينة توافق → فصيلة وتوافق متصالب → حجز وحدة → صرف → تحقق ثنائي بجانب السرير (مريض + وحدة) → بدء نقل مع علامات حيوية → رصد تفاعل → إغلاق/بلاغ OVR عند تفاعل.
**نقاط فحص:** استحالة صرف وحدة غير متوافقة أو منتهية؛ التحقق الثنائي لا يقبل الممرض نفسه مرتين.

### الرحلة 7 — دورة الإيرادات RCM
أهلية NPHIES عند التسجيل → موافقة مسبقة → تقديم الخدمة → ترميز ICD-10-AM/SBS → فاتورة → مطالبة FHIR (Gate 8) → رد/رفض → إعادة تقديم → فاتورة ZATCA Phase-2 → التحصيل → GL.
**نقاط فحص:** Idempotency (Gate 7) — إعادة إرسال نفس المطالبة/الفاتورة لا تنشئ سجلاً مالياً مكرراً؛ الرفض التأميني يرجع لقائمة عمل الترميز لا يضيع.

| المعرّف | فحص عرضي على الرحلات السبع | الخطورة |
|---------|------------------------------|----------|
| WF-X1 | كل انتقال حالة (State) مسموح فقط من حالته السابقة الشرعية (لا قفز من «مجدول» إلى «مفوتَر») | P0 |
| WF-X2 | التزامن: مستخدمان يعدّلان نفس السجل — لا فقد كتابة صامت (قفل تفاؤلي/رسالة تعارض) | P1 |
| WF-X3 | كل رحلة تترك أثر تدقيق متسلسلاً كاملاً يُعاد بناؤه زمنياً | P0 |
| WF-X4 | تنفيذ كل رحلة بمستأجرين متوازيين — صفر تداخل بيانات | P0 |
