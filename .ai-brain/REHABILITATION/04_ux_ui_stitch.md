# 04 UX/UI Stitch — Rehabilitation & Physical Medicine

## 1. Design Tokens
- **Palette**: recovery green accents, progress gradients, alert amber for overdue goals.
- **Typography**: same as Stitch clinical stations.
- **Layout**: 3-column station.

## 2. Components
- `RehabScheduleBoard`: weekly therapy schedule by therapist and modality.
- `GoalTracker`: SMART goals with progress bars.
- `FunctionalScoreChart`: FIM/Barthel/MMT trends over time.
- `TherapyNoteForm`: session notes with exercise counts and patient response.
- `DischargePlanCard`: home program and community handoff.

## 3. User Stories
- "As a physiotherapist, I want to document session notes and see functional score trends."
- "As a physiatrist, I want goal attainment tracking and alerts for stagnant progress."

## 4. Wireframe Logic
- Left: patient list + therapist schedule.
- Center: assessment/session/goal tabs.
- Right: progress charts + alerts + discharge plan.

## 5. Accessibility
- RTL/LTR, high-contrast progress indicators, touch-friendly scoring forms.
