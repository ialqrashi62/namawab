# Stitch → Antigravity Token Saver Skills

هذه الحزمة مخصصة لتطبيق تصميم Stitch الموجود في `748.zip` على المشروع عبر Antigravity IDE بأقل توكنز ممكن.

طريقة الاستخدام المختصرة:
1. فك ضغط ملف Stitch داخل المشروع باسم `748/`.
2. انسخ مجلد هذه المهارات إلى:
   - `.ai-brain/skills/stitch-health-ui/`
   أو
   - `docs/skills/stitch-health-ui/`
3. في Antigravity استخدم البرومنت الموجود في:
   - `AUTO_PILOT_PROMPT_AR.md`
   أو النسخة الإنجليزية:
   - `AUTO_PILOT_PROMPT_EN.md`
4. لا ترسل كل ملفات HTML داخل البرومنت. اطلب من الوكيل قراءة المهارات والملفات محلياً.

الهدف:
- تحويل التصميم إلى Design System ومكونات React/Next.js نظيفة.
- البدء بالصفحة الرئيسية + لوحة التحكم + Shell العام.
- عدم لمس EXE/Desktop/C++ في هذه المهمة.
- توثيق كل تغيير بتقرير عربي.
