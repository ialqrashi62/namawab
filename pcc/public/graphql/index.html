GraphQL executor live — v3.316.20

POST queries as JSON to /graphql/query:

curl -sS -X POST http://localhost:3100/graphql/query \
  -H "Content-Type: application/json" \
  -d '{ "query": "{ stats }" }'

Try it — copy-paste these queries

1. Catalog stats (with sub-selection):

{
  stats {
    totalModules
    totalFunctions
    totalCategories
  }
}

2. List 5 module slugs:

{
  modules(limit: 5)
}

3. Search "cardio" (returns slug string array):

{
  search(q: "cardio", limit: 3)
}

4. Coverage breakdown (raw upstream JSON):

{
  coverage
}

5. Audit log (last 5 entries):

{
  audit(limit: 5)
}

Browser test (GET)

For quick browser testing you can also call GET /graphql/query?query=... (URL-encode the query body). Example: /graphql/query?query={ stats }

Schema

Canonical SDL still served at /graphql/schema.graphql. The executor implements a minimal subset of those types: modules, module(slug), search(q, limit), lookup(fn), stats, coverage, audit(limit, tenant_id), call(module, fn, input, decisionId, tenant_id), and record(module, fn, input, decisionId, tenant_id).
