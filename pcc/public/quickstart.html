🚀 Quick Start

1. Health Check

GET /health Server liveness

2. Browse Catalog

GET /api/v1/pcc-catalog/modules List all 1322 modules
GET /api/v1/pcc-catalog/categories 255 categories
GET /api/v1/pcc-catalog/module/<slug> Module detail with functions

3. Search

GET /api/v1/pcc-catalog/search?q=cardiology Full-text search with scoring
GET /api/v1/pcc-catalog/lookup/<fn> Find modules exposing function

4. Module Operations

GET /api/v1/<slug>/list Module function list
POST /api/v1/<slug>/call/<fn> Invoke a function
POST /api/v1/<slug>/record Record with tenant context

5. Diagnostics

GET /api/v1/pcc-diagnostics/diagnostics Uptime + memory + catalog stats
